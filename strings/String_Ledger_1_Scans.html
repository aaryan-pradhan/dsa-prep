DNA Repetition

O(n)
The ask
Find the length of the longest block of one repeated character.
max (r − l + 1) such that s[l] = s[l+1] = … = s[r]
Key observations
  1. s[i] == s[i−1] means the run extends. Otherwise s[i] starts a new run of length 1.
  2. Update the best after every character, so there is no final flush.
  3. Starting both counters at 1 handles n = 1 with an empty loop.
Brute force → why it dies
naiveFrom every l, extend while the character matches.
costO(n²) on "AAAA…".
dies atn ≤ 10⁶ → 10¹².
thereforeOne pass with a running count: O(n), O(1).

Implementation

The loop starts at i = 1 with count = maxCount = 1. size_t i matches s.size(), which avoids a signed-comparison warning.

// Problem: DNA Repetition (longest run of a single character)
// Link: CSES 1069
// Pattern: single-pass run-length scan — track current run vs previous char, keep a running max
// Time: O(n)  Space: O(1)
//
// Longest maximal substring of a single repeated character.
//
// Example:
//     ATTCGGGA -> 3   (GGG)

#include <iostream>
#include <string>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(0); cout.tie(0);

    string s;
    cin >> s;

    int count = 1, maxCount = 1;
    for (size_t i = 1; i < s.size(); i++) {
        if (s[i] == s[i - 1]) count++;
        else count = 1;
        maxCount = max(maxCount, count);
    }

    cout << maxCount << '\n';
    return 0;
}
GotchaOn a mismatch, reset to 1, not 0. The mismatching character is already a run of length 1.
Recognize"longest block of equal adjacent elements" → running count, reset to 1 on change.
