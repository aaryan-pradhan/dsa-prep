Recognition rules

The judgment calls that separate these problems from each other.

1

To find the middle, use slow and fast pointers, and choose where fast starts. fast = head->next gives the first middle (Merge Sort). fast = head with a guarded double step gives the second middle (Reorder List I).

2

If you need to walk backwards, reverse that part. The same three-pointer reverse appears in Reorder List I (second half) and Reverse Nodes in k-Group (each group).

3

Cut before you recurse or reverse. mid->next = nullptr (Merge Sort, Reorder List I) and tail->next = nullptr (k-Group) give the helper a finite list. Splice afterwards.

4

If the head might change, start from a dummy node. See the merge in Merge Sort and the group splicing in k-Group.

1 · Split & merge

Find the middle, cut there, work on the halves independently, and then zip them back together. The zip is either a comparison merge or a strict alternation.

Merge Sort Linked List

O(N log N)
The ask
Sort a singly linked list in O(N log N) and return the new head.
sort(L) = merge(sort(L[..mid]), sort(L[mid+1..]))
Key observations
  1. There is no index to split on, so slow and fast pointers find the middle in one pass.
  2. Starting fast = head->next lands on the first middle, so a 2-node list splits 1 | 1.
  3. The merge is two sorted lists behind a dummy, and the leftover side is spliced on whole.
Brute force → why it dies
naiveInsertion sort on the list.
costO(N²)
dies atN = 10⁵ → 10¹⁰. Copying to an array and sorting instead breaks the links-only spirit.
thereforeMerge sort on links: O(N log N) time, O(log N) stack.
Diagram
Implementation

mergesort has the base case, then findMid, then cuts with mid->next = nullptr, recurses and merges. The merge moves temp along the chosen side. The two trailing while loops walk the leftover side node by node, where one splice would also work.

// Problem: Sort a Linked List (Merge Sort)
// Pattern: divide and conquer — split at midpoint, recurse, merge two sorted lists
// Time: O(N log N)  Space: O(log N) recursion stack
//
// Sort a singly linked list in O(N log N) using merge sort. Return the new head.
//
// Constraints: 0 ≤ N ≤ 1e5, 0 ≤ node value ≤ 1e9.
//
// Example:
//     [2]           -> [2]
//         [1,3,6,1,7]   -> [1,1,3,6,7]

#include <iostream>
#include <vector>
using namespace std;

struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

ListNode* findMid(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head->next;

    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }

    return slow;
}

ListNode* merge(ListNode* left, ListNode* right) {
    if (!left) return right;
    if (!right) return left;

    ListNode* dummy = new ListNode(-1);
    ListNode* temp = dummy;
    while (left && right) {
        if (left->val < right->val) {
            temp->next = left;
            temp = left;
            left = left->next;
        } else {
            temp->next = right;
            temp = right;
            right = right->next;
        }
    }

    while (left) {
        temp->next = left;
        temp = left;
        left = left->next;
    }

    while (right) {
        temp->next = right;
        temp = right;
        right = right->next;
    }

    return dummy->next;
}

ListNode* mergesort(ListNode* head) {
    if (head == nullptr || head->next == nullptr) {
        return head;
    }

    ListNode* mid = findMid(head);

    ListNode* left = head;
    ListNode* right = mid->next;
    mid->next = nullptr;

    left = mergesort(left);
    right = mergesort(right);

    return merge(left, right);
}

ListNode* GetList(vector<int>& num) {
    ListNode* head = nullptr;
    ListNode* cur = nullptr;
    for (int x : num) {
        ListNode* temp = new ListNode(x);
        if (!cur) { head = cur = temp; }
        else { cur->next = temp; cur = temp; }
    }
    return head;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(0); cout.tie(0);

    int n; cin >> n;
    vector<int> num(n);
    for (int i = 0; i < n; i++) cin >> num[i];

    ListNode* head = GetList(num);
    head = mergesort(head);

    while (head) { cout << head->val << " "; head = head->next; }
    cout << "\n";
    return 0;
}
GotchaWith fast = head, a 2-node list returns mid = the second node. The right half is then empty and the left half is the whole list again, so the recursion never ends. Start from head->next.
Recognize"sort a linked list in N log N" → slow and fast split, recurse, merge with a dummy.

Reorder List I

O(N)
The ask
Rewire L1 → L2 → … → Ln into L1 → Ln → L2 → Ln−1 → … using only link changes.
first half ⋈ reverse(second half), alternating
Key observations
  1. You need the tail side walked backwards, so reverse the second half.
  2. Split at the second middle. The first half is then as long as the second or longer.
  3. Interleave while second is non-null. The leftover part of the first half stays attached automatically.
Brute force → why it dies
naiveFor each step, walk to the current tail and move it.
costO(N²)
dies atN = 10⁶ → 10¹². A node array fixes the time but costs O(N) space.
thereforeSplit, reverse, interleave: O(N) time, O(1) space.
Diagram
Implementation

middleNode advances slow only after a successful first step of fast, which lands on the second middle. Each merge round saves both next pointers before overwriting either.

// Problem: Reorder List I
// Pattern: split + reverse second half + merge alternately
// Time: O(N)  Space: O(1)
//
// Given the head of a singly linked list, reorder it in place from
// L1 -> L2 -> ... -> Ln to L1 -> Ln -> L2 -> Ln-1 -> L3 -> Ln-2 -> ....
// Node values may not be changed — only links may be rewired.
//
// Constraints: 0 ≤ length ≤ 1e6, 0 ≤ node value ≤ 1e9.
//
// Example:
//     [3]           -> [3]
//         [1,2,3,4]     -> [1,4,2,3]
//         [1,2,3,4,5]   -> [1,5,2,4,3]

#include <iostream>
#include <vector>
using namespace std;

struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

ListNode* reverseList(ListNode* head) {
    ListNode* prev = NULL;
    ListNode* cur = head;
    ListNode* next_ = NULL;

    while (cur != NULL) {
        next_ = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next_;
    }
    return prev;
}

ListNode* middleNode(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;

    while (fast) {
        fast = fast->next;
        if (fast) {
            slow = slow->next;
            fast = fast->next;
        }
    }
    return slow;
}

void reorderList(ListNode* head) {
    if (!head || !head->next) return;

    ListNode* mid = middleNode(head);
    ListNode* second = mid->next;
    mid->next = nullptr;
    second = reverseList(second);

    ListNode* first = head;
    while (second) {
        ListNode* tmp1 = first->next;
        ListNode* tmp2 = second->next;
        first->next = second;
        second->next = tmp1;
        first = tmp1;
        second = tmp2;
    }
}

ListNode* GetList(vector<int>& num) {
    ListNode* head = nullptr;
    ListNode* cur = nullptr;
    for (int x : num) {
        ListNode* temp = new ListNode(x);
        if (!cur) { head = cur = temp; }
        else { cur->next = temp; cur = temp; }
    }
    return head;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(0); cout.tie(0);

    int n; cin >> n;
    vector<int> num(n);
    for (int i = 0; i < n; i++) cin >> num[i];

    ListNode* head = GetList(num);
    reorderList(head);

    while (head) { cout << head->val << " "; head = head->next; }
    cout << "\n";
    return 0;
}
GotchaSet mid->next = nullptr before reversing. Otherwise the first half still points into nodes the reversal has turned around, and the interleave creates a cycle.
Recognize"interleave the front and back of a singly linked list in place" → split, reverse the back, zip.

2 · Group reversal

Reverse fixed-size pieces and splice each one back between the previous group's tail and the next group's head. A dummy node makes the first group behave like the rest.

Reverse Nodes in k-Group

O(N)
The ask
Reverse every block of K consecutive nodes. K divides N.
prev→[h … t]→next becomes prev→[t … h]→next
Key observations
  1. Walk K−1 steps to the group's tail, save tail->next, and cut.
  2. After reversing, the old head is the group's last node.
  3. Splice with prev->next = newHead and head->next = nextGroup, then set prev = head.
  4. K = 1 returns early, although the loop would also handle it.
Brute force → why it dies
naiveCopy the values into an array, reverse the chunks, write them back.
costO(N) time, O(N) extra space.
dies atNot on time at N = 10⁶. It fails the O(1)-space, relink-nodes requirement.
thereforeCut, reverse, splice each group: O(N) time, O(1) space.
Diagram
Implementation

reverse is the plain three-pointer loop on the cut-off group. In reverseList, after the reversal head still points to the same node, which is now the group's tail. So the same variable serves as both the splice point and the next prev.

linked_list/Reverse_Nodes_In_K_Group.cppverbatim
// Problem: Reverse Nodes in k-Group
// Pattern: group-bounded in-place reversal
// Time: O(N)  Space: O(1)
//
// Given a singly linked list of length N and an integer K, reverse the nodes
// in groups of size K and return the head. K divides N exactly (no partial
// final group to worry about).
//
// Constraints: 1 ≤ N ≤ 1e6, 1 ≤ K ≤ N, 0 ≤ node values ≤ 1e9, N % K == 0.
//
// Example:
//     [1,2,3,4,5,6], K=3 -> [3,2,1,6,5,4]
//         [1,3,2],       K=3 -> [2,3,1]

#include <iostream>
#include <vector>
using namespace std;

struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

ListNode* reverse(ListNode* head) {
    ListNode* prev = NULL;
    ListNode* cur = head;
    ListNode* next_ = NULL;

    while (cur != NULL) {
        next_ = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next_;
    }
    return prev;
}

ListNode* reverseList(ListNode* head, int K) {
    if (head == nullptr || K == 1) return head;

    ListNode* dummy = new ListNode(0, head);
    ListNode* prev = dummy;

    while (head) {
        ListNode* tail = head;
        for (int i = 1; i < K; i++) tail = tail->next;

        ListNode* nextGroup = tail->next;
        tail->next = nullptr;
        ListNode* newHead = reverse(head);

        prev->next = newHead;
        head->next = nextGroup;

        prev = head;
        head = nextGroup;
    }
    return dummy->next;
}

ListNode* GetList(vector<int>& num) {
    ListNode* head = nullptr;
    ListNode* cur = nullptr;
    for (int x : num) {
        ListNode* temp = new ListNode(x);
        if (!cur) { head = cur = temp; }
        else { cur->next = temp; cur = temp; }
    }
    return head;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(0); cout.tie(0);

    int n; cin >> n;
    vector<int> num(n);
    for (int i = 0; i < n; i++) cin >> num[i];
    int K; cin >> K;

    ListNode* head = GetList(num);
    head = reverseList(head, K);

    while (head) { cout << head->val << " "; head = head->next; }
    cout << "\n";
    return 0;
}
GotchaSave nextGroup = tail->next before cutting. After the cut and reversal nothing points to it any more. Link head, not newHead, to nextGroup.
Recognize"reverse a linked list in blocks or between positions" → dummy, cut, reverse, splice, advance prev.
