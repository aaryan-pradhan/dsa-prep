0 · How to practise

  1. Effort, not outcome. Solving the problem is not the goal; trying hard is what improves you. Remove distractions.
  2. Switch approach when one stalls, even if it gave "progress".
  3. Solutions come from experiments (often in the wrong direction) plus noticing things.
  4. Stuck? One hint at a time. After the solution ask: how could I have found this? why didn't I?
  5. Level: practise just above your comfort level; move up when it gets comfortable.

1 · Small, special, random cases

Solve a smaller version first (fewer objects, lower dimension, fewer constraints). Then try special cases (e.g. equal piles), then random ones. The pattern in the small case usually works in general.

Lighter box

10 boxes of 100 coins each. 9 boxes have 10 g coins, 1 box has 9 g coins. Find the light box with one weighing (the scale shows the total weight).

Key idea

Take a different number of coins from each box, so every possible light box gives a different total.

Solution
  1. Take \(k\) coins from box \(k\), for \(k = 1,\dots,10\). That is 55 coins. (construction)
  2. If every coin were 10 g, the total would be 550 g.
  3. If box \(j\) is light, each of its \(j\) coins is 1 g short, so \(W = 550 - j\). (1, 2)
  4. So \(j = 550 - W\), and different \(j\) give different \(W\). (3)

∎

Two piles of stones

Piles of 1933 and 3800 stones. A move removes \(\ge 1\) stones from one pile. The player who takes the last stone wins. Alice moves first. Who wins?

Key idea

Special case: with equal piles the second player wins by copying the first player's move on the other pile.

Solution

Claim. Alice wins.

  1. Alice takes \(3800 - 1933 = 1867\) stones from the big pile, leaving \((1933, 1933)\).
  2. Invariant: after each of Alice's moves the piles are equal. (1; she copies Bob's move on the other pile)
  3. If Bob can move, the pile he did not touch still has the stones Alice needs to copy him. So Alice can always reply. (2)
  4. Stones strictly decrease, so the game ends. By 3, the last stone is taken by Alice.

∎

2 · Invariants

Invariant: a quantity that no allowed operation changes. If it differs between the start and the target, the target cannot be reached. The trigger is "repeated operations: can state X be reached?"

Make all equal

Six numbers around a circle: \(1,0,1,0,0,0\). A move adds 1 to two neighbouring numbers. Can all six become equal?

Key idea

Alternating sum \(Q = a - b + c - d + e - f\). Two neighbours always have opposite signs in \(Q\).

Solution

Claim. No.

  1. Neighbours (including \(f, a\)) have opposite signs in \(Q\), so a move changes \(Q\) by \(+1 - 1 = 0\). (6 is even)
  2. At the start, \(Q = 1 - 0 + 1 - 0 + 0 - 0 = 2\).
  3. If all six equal \(t\), then \(Q = 3t - 3t = 0\).
  4. \(2 \ne 0\), so this can never happen. (1, 2, 3)

∎

Reaching zero

\(1,2,\dots,50\) are on a board. A move replaces \(a, b\) with \(|a - b|\). Can a single 0 be left at the end?

Key idea

The parity of the sum never changes.

Solution

Claim. No.

  1. A move changes the sum \(S\) to \(S - a - b + |a - b| = S - 2\min(a,b)\). So the parity of \(S\) never changes.
  2. At the start, \(S = \tfrac{50\cdot51}{2} = 1275\), which is odd.
  3. A board holding only 0 has an even sum. This contradicts 1 and 2.

∎

3 · Monovariants

Monovariant: a quantity that moves in only one direction (e.g. strictly increases). You use it to show that a state can never repeat, or that a process must end.

Return configuration

Finitely many stones sit in boxes along an infinite line. A move takes 2 stones from one box and puts one in each neighbouring box. Can you return to the start after \(\ge 1\) moves?

Key idea

Number the boxes with integers. \(Q = \sum_{\text{stones}} (\text{box number})^2\). Every move adds exactly 2 to \(Q\).

Solution

Claim. No.

  1. Moving two stones out of box \(n\) into boxes \(n-1\) and \(n+1\) gives \[\Delta Q = (n-1)^2 + (n+1)^2 - 2n^2 = 2.\]
  2. After \(k \ge 1\) moves, \(Q\) has grown by \(2k > 0\). (1)
  3. The same configuration has the same \(Q\), so it cannot come back. (2)

∎

Infection spread

\(n\times n\) board. A cell becomes infected when \(\ge 2\) of its side-neighbours are infected. Show that fewer than \(n\) infected cells at the start can never infect the whole board.

Key idea

The perimeter of the infected region never increases.

Solution
  1. Infect cells one at a time. (any simultaneous step can be ordered this way)
  2. A new cell with \(k \ge 2\) infected neighbours adds \(4 - k\) edges to the perimeter and removes \(k\) edges. So \(\Delta\text{perimeter} = 4 - 2k \le 0\).
  3. At the start there are \(m < n\) cells, so perimeter \(\le 4m < 4n\).
  4. The full board has perimeter \(4n\). This is more than the start, which contradicts 2.

∎

⚠ Course gap: it states that the perimeter can't increase without showing the \(4 - 2k\) count (step 2).

4 · Pigeonhole principle

  1. If \(n+1\) objects go into \(n\) boxes, some box holds \(\ge 2\) objects.
  2. If more than \(kn\) objects go into \(n\) boxes, some box holds \(\ge k+1\) objects.
  3. If infinitely many objects go into finitely many boxes, some box holds infinitely many.

What to find: the boxes.

Same number of friends

\(n \ge 2\) people. Friendship is mutual. Show that two people have the same number of friends.

Key idea

Friend counts lie in \(\{0,\dots,n-1\}\), but \(0\) and \(n-1\) cannot both occur.

Solution
  1. Each count lies in \(\{0,1,\dots,n-1\}\). That is \(n\) boxes.
  2. If someone has \(n-1\) friends, they are friends with everyone, so nobody has 0. So \(0\) and \(n-1\) are never both used.
  3. So at most \(n-1\) boxes are used by \(n\) people, and two people share a box. (PHP)

∎

Ant cover

51 ants on a \(1\times1\) table. Show that a \(\tfrac15\times\tfrac15\) card can be placed to cover \(\ge 3\) ants.

Key idea

Split the table into 25 small squares. \(51 > 2\cdot25\).

Solution
  1. Cut the table into 25 closed squares of side \(\tfrac15\). Assign each ant to one square that contains it.
  2. \(51 > 2\cdot25\), so some square holds \(\ge 3\) ants. (generalised PHP)
  3. Put the card exactly on that square.

∎

Arrows on a grid

\(100\times100\) board with walls all round, except the right side of the top-right cell. Each cell has an arrow (↑↓←→). Each second the insect steps along its cell's arrow (if a wall blocks it, it stays), and that arrow then turns 90° clockwise. Can the insect stay on the board forever?

Key idea

Infinite pigeonhole: some cell is visited infinitely often. Its arrow cycles through all four directions, so this spreads to every neighbour, and so to every cell.

Solution

Claim. No. It always leaves.

  1. Suppose it stays forever. Then there are infinitely many steps on \(10^4\) cells, so some cell \(C\) is visited infinitely often. (infinite PHP)
  2. Each visit turns \(C\)'s arrow, so the arrow points at each neighbour of \(C\) infinitely often, and the insect moves there. So every neighbour of \(C\) is visited infinitely often.
  3. The board is connected, so repeating 2 shows that every cell is visited infinitely often, including the top-right cell.
  4. That cell's arrow eventually points right, and the insect exits. This contradicts 1.

∎

5 · Proof by colouring

Colour the cells so that every piece or move covers or changes colours in a fixed way. Then compare colour counts. The chessboard colouring is the usual choice; for \(1\times k\) pieces, colour \((i+j) \bmod k\).

Mutilated chessboard

Remove two opposite corners from an \(8\times8\) board. Can 31 dominoes cover the remaining 62 cells?

Key idea

Every domino covers 1 black cell and 1 white cell. Opposite corners have the same colour.

Solution

Claim. No.

  1. Opposite corners \((1,1)\) and \((8,8)\) have the same colour. (\(i+j\) both even)
  2. So what is left has 30 cells of one colour and 32 of the other.
  3. 31 dominoes would cover 31 of each colour. (each covers one of each)
  4. \(30 \ne 31\). This contradicts 2 and 3.

∎

Corner-to-corner walk

Walk on an \(8\times8\) board, stepping between side-adjacent cells, visiting each cell exactly once. Can you start and end at opposite corners?

Key idea

Every step changes colour, and there are 63 steps (odd).

Solution

Claim. No.

  1. Visiting 64 cells takes 63 steps.
  2. Each step flips the colour. After an odd number of steps you are on the other colour. (1)
  3. Opposite corners have the same colour. This contradicts 2.

∎

Unequal neighbours

An \(m\times n\) grid of integers. You may add 1 to any cell, at most once per cell. Can you always make every pair of side-neighbours different?

Key idea

Chessboard colouring: make black cells even and white cells odd.

Solution

Claim. Yes, always.

  1. Colour the grid like a chessboard. Side-neighbours have different colours.
  2. Add 1 to each black cell that is odd and to each white cell that is even. Now black cells are even and white cells odd.
  3. Neighbours then have different parities, so they are different. (1, 2)

∎

\(6\times6\) with \(1\times4\) tiles

Can \(1\times4\) tiles cover a \(6\times6\) board?

Key idea

Give cell \((i,j)\) the colour \((i+j) \bmod 4\). Every \(1\times4\) tile covers one cell of each colour.

Solution

Claim. No.

  1. 4 consecutive cells in a row or a column have 4 consecutive values of \(i+j\), so they cover each colour once.
  2. So a tiling would use each colour equally often: 9 each.
  3. Counting on \(6\times6\) (\(i,j\) from 0): colour 1 appears 10 times and colour 3 appears 8 times. This contradicts 2.

∎

6 · Induction

  1. Weak: prove \(P(n_0)\). Prove \(P(n) \Rightarrow P(n+1)\).
  2. Strong: prove \(P(n_0)\). Prove that \(P(n_0),\dots,P(n)\) together give \(P(n+1)\).
  3. Step 2: for odd \(n\) only, prove \(P(1)\) and \(P(n) \Rightarrow P(n+2)\).

When to use it: small cases show a pattern, or the \((n+1)\) case reduces to the \(n\) case.

Sum \(1 + \dots + n\)

Prove that \(\displaystyle 1 + 2 + \dots + n = \frac{n(n+1)}{2}\).

Key idea

Weak induction: add \(n+1\) to both sides.

Solution
  1. \(n = 1\): \(1 = \tfrac{1\cdot2}{2}\).
  2. Assume the formula for \(n\). Then \[1+\dots+n+(n+1) = \frac{n(n+1)}{2} + (n+1) = \frac{(n+1)(n+2)}{2}.\]

∎

Gas cans on a circular track

\(N\) cans on a one-way loop hold, in total, exactly one lap's worth of fuel. You start with an empty tank. Show that some start point lets you finish the lap.

Key idea

Some can \(i\) holds enough fuel to reach the next can. Merge can \(i+1\) into can \(i\) and induct on \(N\).

Solution
  1. Let the lap have length 1. Can \(i\) holds fuel \(x_i\), and the gap to the next can is \(y_i\). \(\sum x_i = \sum y_i = 1\).
  2. Some \(i\) has \(x_i \ge y_i\). (otherwise \(\sum x < \sum y\))
  3. \(N = 1\): start at the can. (base)
  4. Step: move the fuel of can \(i+1\) into can \(i\). This gives \(N-1\) cans, still totalling 1. By hypothesis, some start works for them.
  5. That start also works originally. Reaching can \(i\) with tank \(\ge 0\) and picking up \(x_i \ge y_i\) gets you to can \(i+1\), which then gives \(x_{i+1}\). So at every point the tank holds at least as much as in the merged version. (2)

∎

Two-colouring regions cut by lines

\(n\) lines cut the plane into regions. Show that two colours suffice so that regions sharing an edge differ.

Key idea

Add one line and swap every colour on one side of it.

Solution
  1. \(n = 1\): colour the two half-planes differently.
  2. Given a good colouring for \(n\) lines, add line \(n+1\) and swap the colours of every region on its right.
  3. Two regions on the same side still differ (swapping keeps "different" different). Two regions sharing an edge along the new line are halves of one old region, and exactly one of them was swapped, so they now differ.

∎

Splitting 1000 coins

Split a pile into \(x + y\) and score \(xy\). Keep splitting until every pile is 1. Show that the total does not depend on the choices, and find it.

Key idea

Small cases give \(0, 1, 3, 6 \to \tfrac{n(n-1)}{2}\). Prove it by strong induction.

Solution

Claim. \(f(n) = \tfrac{n(n-1)}{2}\), so \(f(1000) = 499500\).

  1. \(f(1) = 0\).
  2. For \(n \ge 2\) the first split is \(x + y = n\), so \(f(n) = xy + f(x) + f(y)\), with \(x, y < n\).
  3. By hypothesis, \[f(n) = xy + \frac{x(x-1)}{2} + \frac{y(y-1)}{2} = \frac{(x+y)^2 - (x+y)}{2} = \frac{n(n-1)}{2},\] whatever \(x\) is.

∎  (Or directly: each score counts the pairs of coins that get separated, and every one of the \(\binom{n}{2}\) pairs is separated exactly once.)

⚠ Course says "simplifying" and skips the algebra. The key step is \(xy + \tfrac{x^2+y^2}{2} = \tfrac{(x+y)^2}{2}\).

Water pistols (\(n\) odd)

\(n\) people, all pairwise distances distinct. Each person shoots the nearest person. If \(n\) is odd, show that someone stays dry.

Key idea

The closest pair \(A, B\) shoot each other. Remove them and use induction on odd \(n\).

Solution
  1. \(n = 1\): nobody shoots.
  2. Take \(n = k+2\). Let \(A, B\) be the closest pair. They shoot each other.
  3. If one of the other \(k\) people shoots \(A\) or \(B\), then at most \(k-1\) shots fall on those \(k\) people, so one of them is dry.
  4. Otherwise the \(k\) people shoot only among themselves, exactly as in the \(k\)-person game. By hypothesis someone is dry.

∎

7 · Symmetry

Pair each object with its mirror image. Either it hands you information for free (pairs sum to a constant, halves of the work are equal), or it is the whole argument (copy-strategies in games).

Placing coins

Players take turns placing identical coins on a rectangular table, with no overlaps. The last player able to place a coin wins. Alice goes first. Who wins?

Key idea

Alice takes the centre, then mirrors every move of Bob's through the centre.

Solution

Claim. Alice wins.

  1. Alice places her first coin centred on the table's centre \(O\).
  2. After each of Alice's moves, the set of coins is symmetric about \(O\). (induction)
  3. Bob places a legal coin at \(P\). Its mirror position \(P'\) was free before Bob's move. (2: the position was symmetric)
  4. Bob's coin does not overlap \(P'\). If it did, a coin would overlap its own mirror image, so it would contain \(O\), which is already covered. So Alice can play at \(P'\).
  5. So Alice always has a move. The table is finite, so the game ends, and Bob is the one stuck.

∎

Sum of five-digit palindromes

Find the sum of all numbers \(\overline{abcba}\) with \(a \ne 0\).

Key idea

Pair \(\overline{abcba}\) with \(\overline{a'b'c'b'a'}\), where \(a' = 10-a,\ b' = 9-b,\ c' = 9-c\). Each pair sums to 110000.

Solution

Claim. \(49\,500\,000\).

  1. \(\overline{abcba} = 10001a + 1010b + 100c\). There are \(9\cdot10\cdot10 = 900\) of them.
  2. The map in the key idea sends palindromes to palindromes (\(a' \in 1..9\)), and applying it twice gives back the original.
  3. No palindrome is its own partner: that would need \(b = 9-b\), i.e. \(b = 4.5\). So the 900 split into 450 pairs.
  4. Each pair sums to \(10001\cdot10 + 1010\cdot9 + 100\cdot9 = 110000\). (1)
  5. Total \(= 450 \cdot 110000 = 49\,500\,000\).

∎

⚠ Course says "n-th + n-th-from-last = 110000" without proof. Steps 2–3 give the explicit pairing that justifies it.

Average median of subsets

\(S = \{1,\dots,100\}\). Take the median of every non-empty subset. What is the average?

Key idea

Reflect \(x \mapsto 101 - x\). That sends a subset with median \(m\) to one with median \(101 - m\).

Solution

Claim. \(50.5\).

  1. Let \(r(B) = \{101 - x : x \in B\}\). \(r\) is a bijection on the non-empty subsets. (\(r\circ r = \mathrm{id}\))
  2. Reflection reverses the order, so \(\operatorname{med} r(B) = 101 - \operatorname{med} B\).
  3. \(\displaystyle\sum_B \operatorname{med} B = \sum_B \operatorname{med} r(B) = \sum_B (101 - \operatorname{med} B)\). (1: re-indexing; 2)
  4. So \(2\sum_B \operatorname{med} B = 101\cdot(\text{number of subsets})\), and the average is \(\tfrac{101}{2} = 50.5\).

∎

⚠ Course pairs \(B\) with \(r(B)\) but only treats \(B = S\) as self-paired. Many subsets are their own reflection (e.g. \(\{1,100\}\)). Summing over the bijection, as in step 3, handles all of them at once.
