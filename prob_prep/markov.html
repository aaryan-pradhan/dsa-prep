Markov Chains

QuantProf revision · each problem: the idea in plain words with a live diagram, then a numbered proof.

1 · Definition

  1. \((X_n)\) on a finite set \(S\) is a Markov chain if \[P(X_{n+1} = j \mid X_n = i, \text{past}) = P(X_{n+1} = j \mid X_n = i) = p_{ij}.\] Markov property: only the present matters.
  2. Transition matrix \(P = (p_{ij})\): row \(i\) gives where you go from \(i\), so every row sums to 1.
  3. If the next step depends on the last two states, use pairs (previous, current) as the states. The chain on pairs is Markov.

2 · Probability of a path

\[P(X_0=i_0, \dots, X_n=i_n) = P(X_0=i_0)\, p_{i_0 i_1} \cdots p_{i_{n-1} i_n}.\] This is the chain rule with each conditional cut down by the Markov property.

Path B → A → C

Each day a traveller moves between three cities A, B, C according to a Markov chain with the transition matrix below.
(Row = today's city, column = tomorrow's city, both in the order A, B, C.)
On day 0 the traveller is in A, B, C with probabilities 0.9, 0.05, 0.05.\[P = \begin{pmatrix} .5 & .3 & .2 \\ .1 & .6 & .3 \\ .4 & .2 & .4 \end{pmatrix}\]

Question: what is the probability that the traveller is in B on day 0, in A on day 1 and in C on day 2?

Key idea

Multiply the start probability by the two transitions.

Picture

Follow the path and multiply. Start in B: 0.05. Then B → A: 0.1. Then A → C: 0.2.

Each factor only needs the city you are in now (that is the Markov property), so the answer is \(0.05 \times 0.1 \times 0.2 = 0.001\).

Solution

Setup. The city chain has states A, B, C (in that order) with the transition matrix \(P\) above, and \(X_0 \sim (0.9, 0.05, 0.05)\). \(p_{ij}\) = row \(i\), column \(j\) of \(P\).

  1. \(P(X_0 = B, X_1 = A, X_2 = C) = P(X_0 = B)\,P(X_1 = A \mid X_0 = B)\,P(X_2 = C \mid X_1 = A, X_0 = B)\).Why: chain rule.
  2. The last factor is \(P(X_2 = C \mid X_1 = A) = p_{AC}\), and the middle one is \(p_{BA}\).Why: Markov property: only the present state matters.
  3. \(= 0.05\cdot p_{BA}\cdot p_{AC} = 0.05\cdot0.1\cdot0.2 = \) \(0.001\).Why: \(p_{BA}\) is row B, column A \(= 0.1\); \(p_{AC}\) is row A, column C \(= 0.2\).

Conclusion. The path B → A → C has probability 0.001. ∎

3 · n-step transitions (Chapman–Kolmogorov)

\[T_{ij}(n) = \sum_k T_{ik}(n-1)\,p_{kj}.\] This is total probability over the state at time \(n-1\). In matrix form \(T(n) = T(n-1)P\), so \(T(n) = P^n\).

City chain: \(T_{12}(2)\), \(P^2\), and \(T_{13}(3)\)

The same city chain, with the cities numbered 1 = A, 2 = B, 3 = C. \(T_{ij}(n)\) is the probability of being in city \(j\) after \(n\) days, starting from city \(i\).

Question: (a) find \(T_{12}(2)\); (b) compute the two-day transition matrix \(P^2\); (c) find \(T_{13}(3)\).

Key idea

Row 1 of \(P\) times column \(j\) of \(P\) (then of \(P^2\)).

Picture

To be in B after two days, you must pass through some city on day 1. Add up the three routes:

A → A → B: \(.5 \times .3\) · A → B → B: \(.3 \times .6\) · A → C → B: \(.2 \times .2\). Total 0.37.

Doing this for every start and end city is exactly multiplying the matrix \(P\) by itself: \(P^2\). Three days is \(P^3\).

Solution

Setup. Same chain, states 1 = A, 2 = B, 3 = C. \(T_{ij}(n) = P(X_n = j \mid X_0 = i)\).

  1. \(T_{12}(2) = \sum_k p_{1k}p_{k2} = p_{11}p_{12} + p_{12}p_{22} + p_{13}p_{32} = .5\cdot.3 + .3\cdot.6 + .2\cdot.2 = .15 + .18 + .04 = \) \(0.37\).Why: total probability over the middle state \(k\) (see the figure below).
  2. The same computation for every entry (row \(i\) of \(P\) times column \(j\) of \(P\)) gives \[P^2 = \begin{pmatrix} .36 & .37 & .27 \\ .23 & .45 & .32 \\ .38 & .32 & .30 \end{pmatrix}.\]Why: for example, entry (1,1) is \(.5\cdot.5 + .3\cdot.1 + .2\cdot.4 = .25 + .03 + .08 = .36\).
  3. \(T_{13}(3) = (\text{row 1 of } P^2)\cdot(\text{column 3 of } P) = .36\cdot.2 + .37\cdot.3 + .27\cdot.4 = .072 + .111 + .108 = \) \(0.291\).Why: \(P^3 = P^2P\) (Chapman–Kolmogorov). Row 1 of \(P^3\) is \((.325, .384, .291)\).

Conclusion. 0.37 and 0.291. ∎

4 · Classifying states

  1. Accessible \(i \to j\): \(P^n_{ij} > 0\) for some \(n \ge 1\), i.e. there is a path of positive-probability steps. Communicate \(i \leftrightarrow j\): both directions.
  2. Recurrent \(i\): every \(j\) with \(i \to j\) also has \(j \to i\). (In a finite chain this is the same as returning to \(i\) with probability 1.)
  3. Transient: not recurrent. Absorbing: \(p_{ii} = 1\).

5 · Decomposition

  1. Recurrent class: a recurrent \(i\) together with everything accessible from it. All of these states communicate, and the chain can never leave the class.
  2. \(S = (\text{one or more recurrent classes}) \cup (\text{transient states})\).
  3. Periodic class: it splits into \(S_1 \to S_2 \to \cdots \to S_d \to S_1\) with \(d > 1\). Test: if some \(n\) has \(P^n_{ij} > 0\) for all \(j\) in the class, the class is aperiodic.
  4. Irreducible: a single class and no transient states.

Every transient state reaches a recurrent state

A Markov chain has finitely many states. A state \(r\) is recurrent if every state reachable from \(r\) can also reach \(r\) back; otherwise it is transient.

Question: prove that from every transient state some recurrent state can be reached.

Key idea

In the graph of positive transitions, walk from \(t\) into a sink strongly connected component. Nothing leaves a sink, so its states are recurrent.

Picture

Follow arrows downhill. Group states that can reach each other. Arrows between groups never loop back (otherwise the groups would merge), so following arrows you must finally reach a group with no exit.

Inside a no-exit group, wherever you go you can come back. That is exactly "recurrent".

Solution

Setup. A finite chain. \(t\) is a transient state. Recall: \(r\) is recurrent if every state accessible from \(r\) can also reach \(r\).

Claim. From \(t\) some recurrent state \(r\) is accessible.

  1. Draw an edge \(i \to j\) whenever \(p_{ij} > 0\), and group the states into strongly connected components (maximal sets of states that can all reach each other).Why: standard graph decomposition.
  2. Shrink each component to a point. The result has no cycles, and finitely many points.Why: a cycle through two components would merge them into one.
  3. So following edges from \(t\)'s component, we eventually reach a component \(C\) with no outgoing edges (a sink).Why: in a finite graph with no cycles, every path ends.
  4. Every \(r \in C\) is recurrent.Why: if \(r \to j\), then \(j \in C\) because \(C\) has no exits; and every state of \(C\) can reach \(r\) because \(C\) is strongly connected. That is the definition of recurrent.
  5. And \(t \to r\).Why: step 3 gives a path from \(t\) into \(C\).

Conclusion. Every transient state leads into a sink class, whose states are recurrent. ∎

⚠ Course argues with “transient states are visited only finitely often”, a probabilistic fact it never proved and that doesn't match its graph definition of “transient”. The sink-component argument uses only the definitions.

6 · Steady state

  1. Stationary \(\pi\): \(\pi = \pi P\) and \(\sum_i \pi_i = 1\). Every finite chain has one. It is unique iff there is exactly one recurrent class.
  2. Convergence theorem: if there is one recurrent class and it is aperiodic, then \(P(X_n = j \mid X_0 = i) \to \pi_j\) for every \(i\).
  3. If the class is periodic, the limit can fail to exist (\(A \rightleftarrows B\) deterministically). But with one recurrent class, the fraction of time spent in \(j\) still \(\to \pi_j\).
  4. \(\pi_i p_{ij}\) = the long-run fraction of steps that are \(i \to j\).

Two-state chain \(P = \begin{pmatrix} .7 & .3 \\ .5 & .5 \end{pmatrix}\)

A Markov chain has two states, 1 and 2. From 1 it stays with probability 0.7 and moves to 2 with probability 0.3. From 2 it moves to 1 with probability 0.5 and stays with probability 0.5.

Question: find its stationary distribution: the long-run fraction of time spent in each state.

Key idea

Balance: the flow \(1\to2\) equals the flow \(2\to1\).

Picture

In the long run, traffic 1 → 2 equals traffic 2 → 1. Otherwise one state would keep piling up.

Traffic 1 → 2 is (time in 1) × 0.3; traffic 2 → 1 is (time in 2) × 0.5. So \(0.3\pi_1 = 0.5\pi_2\), and \(\pi_1 + \pi_2 = 1\).

Solution

Setup. \(P = \begin{pmatrix} .7 & .3 \\ .5 & .5 \end{pmatrix}\). We want \(\pi = (\pi_1, \pi_2)\) with \(\pi = \pi P\) and \(\pi_1 + \pi_2 = 1\).

  1. The first equation of \(\pi = \pi P\) is \(\pi_1 = 0.7\pi_1 + 0.5\pi_2\), i.e. \(0.3\pi_1 = 0.5\pi_2\): the flow \(1 \to 2\) equals the flow \(2 \to 1\).Why: subtract \(0.7\pi_1\) from both sides.
  2. So \(\pi_2 = 0.6\,\pi_1\).Why: divide by 0.5.
  3. \(\pi_1 + 0.6\pi_1 = 1\) gives \(\pi_1 = \tfrac{1}{1.6} = \) \(0.625\) and \(\pi_2 = 0.375\).Why: the probabilities sum to 1.

Conclusion. \(\pi = (0.625, 0.375)\). ∎

7 · Absorption probabilities

rec(i) \(= a_i = P(\text{eventually absorbed in } s \mid \text{at } i \text{ now})\). Condition on the next step: \[\text{rec}(i) = \sum_j p_{ij}\,\text{rec}(j) \quad \text{for transient } i.\] Base: \(\text{rec}(s) = 1\), and \(\text{rec}(t) = 0\) for every other absorbing \(t\). For recurrent classes, collapse each class into a single absorbing node first.

Absorbing states 3, 4

A chain has states 1, 2, 3, 4. States 3 and 4 are absorbing: once there, it stays forever. From state 1 it moves to 1, 2, 3, 4 with probabilities 0.5, 0.3, 0.2, 0. From state 2 it moves to 1, 2, 3, 4 with probabilities 0.4, 0.4, 0, 0.2.

Question: starting from state 1, and starting from state 2, what is the probability of ending up in state 3?

Picture

Stand at a state, take one step, and average the answers from where you land.

Landing on 3 gives answer 1, landing on 4 gives 0, landing on 1 or 2 gives that state's (unknown) answer. That is one equation per unknown state; solve them.

Solution

Form 1 (i → end) · Turn = one step of the chain. Hit 3 → ends (1). Hit 4 → ends (0). Otherwise next turn from the new state.

  1. LEVEL. rec(i, s) = P(the chain is absorbed at 3), given it is at s ∈ {1, 2} before step i. The answers are rec(1, 1) and rec(1, 2).Why: only the current state matters.
  2. CHOICE. From 1: to 1, 2, 3, 4 with .5, .3, .2, 0. From 2: to 1, 2, 3, 4 with .4, .4, 0, .2.Why: the given rows.
  3. CHECK. Land on 3: ends, value 1. Land on 4: ends, value 0. Land on 1 or 2: continue.Why: 3 and 4 are absorbing.
  4. MOVE. \(\text{rec}(i,1) = .5\,\text{rec}(i{+}1,1) + .3\,\text{rec}(i{+}1,2) + .2\cdot1\). \(\text{rec}(i,2) = .4\,\text{rec}(i{+}1,1) + .4\,\text{rec}(i{+}1,2) + .2\cdot0\).Why: law of total probability over the step.
  5. MEMORYLESS. rec(i+1, s) = rec(i, s) = as.Why: Markov property: the next step depends only on the current state, and the transition probabilities are the same at every step. So the future from (i+1, s) is exactly the future from (i, s).
  6. SOLVE. Second equation: .6a2 = .4a1, so a2 = ⅔a1. First: .5a1 = .3a2 + .2 = .2a1 + .2, so .3a1 = .2 and a1 = ⅔; a2 = ⅔·⅔ = \(\tfrac49\).Why: move each self-loop term left; .3·⅔a1 = .2a1.

Answer. Absorption at 3 has probability ⅔ from 1 and \(\tfrac49\) from 2. ∎

⚠ Course's matrix has row 4 \(= (0, .2, 0, 1)\), which sums to 1.2. An absorbing row must be \((0,0,0,1)\). The answer is unaffected.

Two recurrent classes \(C_1 = \{3,4\}\), \(C_2 = \{5,6,7\}\)

A chain has two transient states, 1 and 2, and two closed groups of states, \(C_1 = \{3, 4\}\) and \(C_2 = \{5, 6, 7\}\): once the chain enters a group, it never leaves it.
From 1: to 2 with probability 0.2, into \(C_1\) with 0.2, into \(C_2\) with 0.6.
From 2: to 1 with probability 0.2, into \(C_1\) with 0.4, into \(C_2\) with 0.4.

Question: let \(a_1\), \(a_2\) be the probabilities of ending up in \(C_1\) when starting from 1 and from 2. Find \(a_1 + a_2\).

Picture

Once inside a class you never leave, so each class acts like one absorbing state. Squash \(C_1\) and \(C_2\) to single points, then do the usual one-step averaging from 1 and from 2.

Solution

Form 1 (i → end) · Turn = one step. Enter C1 → ends (1). Enter C2 → ends (0). Otherwise next turn.

  1. LEVEL. rec(i, s) = P(the chain ends up in C1), given it is at s ∈ {1, 2} before step i. The answer is a1 + a2 = rec(1, 1) + rec(1, 2).Why: once the chain enters a class it never leaves, so where it lands inside a class never matters: each class acts as one absorbing node.
  2. CHOICE. From 1: to 2 (.2), into C1 (.2), into C2 (.6). From 2: to 1 (.2), into C1 (.4), into C2 (.4).Why: given.
  3. CHECK. Into C1: ends, 1. Into C2: ends, 0. To the other transient state: continue.Why: closed classes.
  4. MOVE. \(\text{rec}(i,1) = .2\,\text{rec}(i{+}1,2) + .2\cdot1 + .6\cdot0\). \(\text{rec}(i,2) = .2\,\text{rec}(i{+}1,1) + .4\cdot1 + .4\cdot0\).Why: law of total probability over the step.
  5. MEMORYLESS. rec(i+1, s) = rec(i, s) = as.Why: Markov property: the next step depends only on the current state, and the transition probabilities are the same at every step. So the future from (i+1, s) is exactly the future from (i, s).
  6. SOLVE. a1 = .2(.2a1 + .4) + .2 = .04a1 + .28, so .96a1 = .28 and a1 = \(\tfrac{7}{24}\). a2 = .2·\(\tfrac7{24}\) + .4 = \(\tfrac{7}{120} + \tfrac{48}{120} = \tfrac{11}{24}\). Sum \(= \tfrac{18}{24} = \) 0.75.Why: substitute the second equation into the first; \(\tfrac{.28}{.96} = \tfrac{7}{24}\).

Answer. \(a_1 + a_2 = 0.75\). ∎

8 · Expected time to absorption

rec(i) \(= t_i = \mathbb{E}[\text{steps to absorption} \mid \text{at } i \text{ now}]\). One step costs 1, then condition on where it went: \[\text{rec}(i) = 1 + \sum_j p_{ij}\,\text{rec}(j) \quad \text{for transient } i,\] with \(\text{rec} = 0\) on absorbing states (or collapsed classes).

Rows \(1 \to (.7,.1,.2,0)\), \(2 \to (.4,.3,0,.3)\)

A chain has states 1, 2, 3, 4, where 3 and 4 are absorbing. From state 1 it moves to 1, 2, 3, 4 with probabilities 0.7, 0.1, 0.2, 0. From state 2 it moves to 1, 2, 3, 4 with probabilities 0.4, 0.3, 0, 0.3.

Question: let \(t_1\), \(t_2\) be the expected numbers of steps until absorption, starting from 1 and from 2. Find \(t_1 + t_2\).

Picture

Same one-step averaging, but every step costs 1.

Time from here = 1 (this step) + the average of the times from wherever you land. Absorbing states need 0 more steps.

Solution

Form 1 (i → end) · Turn = one step, costing 1. Absorbed → ends (0 more). Otherwise next turn.

  1. LEVEL. rec(i, s) = the expected number of steps still to come until absorption, given the chain is at s ∈ {1, 2} before step i. The answer is t1 + t2 = rec(1, 1) + rec(1, 2).Why: only the current state matters.
  2. CHOICE. From 1: to 1, 2, 3, 4 with .7, .1, .2, 0. From 2: .4, .3, 0, .3.Why: given.
  3. CHECK. Each step costs 1. Land on 3 or 4: ends, 0 more. Land on 1 or 2: continue.Why: 3 and 4 absorb.
  4. MOVE. \(\text{rec}(i,1) = 1 + .7\,\text{rec}(i{+}1,1) + .1\,\text{rec}(i{+}1,2)\). \(\text{rec}(i,2) = 1 + .4\,\text{rec}(i{+}1,1) + .3\,\text{rec}(i{+}1,2)\).Why: law of total expectation over the step.
  5. MEMORYLESS. rec(i+1, s) = rec(i, s) = ts.Why: Markov property: the next step depends only on the current state, and the transition probabilities are the same at every step. So the future from (i+1, s) is exactly the future from (i, s).
  6. SOLVE. Rearranged: .3t1 − .1t2 = 1 and −.4t1 + .7t2 = 1. The first gives t2 = 3t1 − 10; then −.4t1 + .7(3t1 − 10) = 1, i.e. 1.7t1 = 8, t1 = \(\tfrac{80}{17}\); t2 = \(\tfrac{240}{17} - \tfrac{170}{17} = \tfrac{70}{17}\). Sum \(= \tfrac{150}{17} \approx\) 8.82353.Why: move the t terms left; substitution.

Answer. \(t_1 + t_2 = \tfrac{150}{17}\). ∎

Two classes again

A chain has two transient states, 1 and 2. From 1 it moves to 2 with probability 0.3 and is otherwise absorbed (into some closed group). From 2 it moves to 1 with probability 0.1 and is otherwise absorbed.

Question: let \(t_1\), \(t_2\) be the expected numbers of steps until absorption, starting from 1 and from 2. Find \(t_1 + t_2\).

Picture

Time from here = 1 + the average time from where you land. Being absorbed adds nothing more; the only way to continue is to hop to the other transient state.

Solution

Form 1 (i → end) · Turn = one step, costing 1. Absorbed → ends. Move to the other transient state → next turn.

  1. LEVEL. rec(i, s) = the expected number of steps still to come until absorption, given the chain is at s ∈ {1, 2} before step i. The answer is t1 + t2.Why: only the current state matters.
  2. CHOICE. From 1: to 2 (.3), otherwise absorbed (.7). From 2: to 1 (.1), otherwise absorbed (.9).Why: given.
  3. CHECK. Each step costs 1. Absorbed: ends, 0 more.Why: no more time after absorption.
  4. MOVE. \(\text{rec}(i,1) = 1 + .3\,\text{rec}(i{+}1,2)\). \(\text{rec}(i,2) = 1 + .1\,\text{rec}(i{+}1,1)\).Why: law of total expectation over the step.
  5. MEMORYLESS. rec(i+1, s) = rec(i, s) = ts.Why: Markov property: the next step depends only on the current state, and the transition probabilities are the same at every step. So the future from (i+1, s) is exactly the future from (i, s).
  6. SOLVE. t1 = 1 + .3(1 + .1t1) = 1.3 + .03t1, so .97t1 = 1.3 and t1 = \(\tfrac{130}{97}\). t2 = 1 + \(\tfrac{13}{97} = \tfrac{110}{97}\). Sum \(= \tfrac{240}{97} \approx\) 2.47423.Why: substitution.

Answer. \(t_1 + t_2 = \tfrac{240}{97}\). ∎

9 · First passage & return times

  1. First passage to \(s\): \(t_s = 0\) and \(t_i = 1 + \sum_j p_{ij}\,t_j\) for \(i \ne s\).
  2. Return time: \(t^*_s = 1 + \sum_j p_{sj}\,t_j\).
  3. Kac: in an irreducible chain, \(t^*_i = 1/\pi_i\). (Sketch: you visit \(i\) once every \(t^*_i\) steps on average, so the long-run fraction of time in \(i\) is \(1/t^*_i\), and that fraction is \(\pi_i\).)
  4. Random walk on a graph: if \(p_{ij} > 0 \iff p_{ji} > 0\) and \(p_{ij} = 1/d_i\), then \(\pi \propto d\). Proof: \[(dP)_j = \sum_i d_i \cdot \frac{\mathbb{1}[i \sim j]}{d_i} = \#\text{neighbours of } j = d_j.\]

\(p_{11} = .8,\ p_{12} = .2,\ p_{21} = .6,\ p_{22} = .4\)

A two-state chain moves 1 → 1 with probability 0.8, 1 → 2 with 0.2, 2 → 1 with 0.6, and 2 → 2 with 0.4.

Question: (a) starting from state 2, what is the expected number of steps to reach state 1? (b) Starting from state 1, what is the expected number of steps until it is back in state 1?

Key idea

First-step analysis. Check (b) with Kac.

Picture

(a) Waiting to reach 1 from 2: each step costs 1; with 0.6 you arrive, with 0.4 you are back where you started. So \(t_2 = 1 + 0.4\,t_2\).

(b) Returning to 1: take one step. With 0.8 you are already back; with 0.2 you are in 2 and still need \(t_2\).

Check (Kac): a state you spend \(\tfrac34\) of your time in is revisited every \(\tfrac43\) steps on average.

Solution

Setup. A two-state chain with \(p_{11} = .8\), \(p_{12} = .2\), \(p_{21} = .6\), \(p_{22} = .4\).

  1. (a) \(t_2\) = expected time from 2 to reach 1: \(t_2 = 1 + .6\cdot0 + .4\,t_2\), so \(.6\,t_2 = 1\) and \(t_2 = \) \(\tfrac53 \approx 1.67\).Why: first-step analysis; arriving at 1 ends the wait.
  2. (b) Return time to 1: \(t_1^* = 1 + .8\cdot0 + .2\,t_2 = 1 + .2\cdot\tfrac53 = \) \(\tfrac43 \approx 1.33\).Why: take one step; if it stays at 1 you are back, and if it goes to 2 you then need \(t_2\) more.
  3. Check with Kac: \(.2\pi_1 = .6\pi_2\) gives \(\pi_2 = \tfrac13\pi_1\), so \(\pi_1 = \tfrac34\), and \(1/\pi_1 = \tfrac43\) ✓.Why: flow balance, and the mean return time is \(1/\pi_i\).

Conclusion. \(\tfrac53\) and \(\tfrac43\). ∎

Five bulbs: return to all-off

Five light bulbs are all off. Every second, one of the five bulbs is chosen at random and switched (off becomes on, on becomes off).

Question: starting from all off, what is the expected number of seconds until all five are off again?

Key idea

Return-time recipe (works for any "how long until it comes back to where it started" question): (1) name the states, (2) find the long-run share of time \(\pi_s\) spent in the start state, (3) Kac: expected return time \(= 1/\pi_s\). The only real work is step 2, and a symmetry shortcut usually does it.

Picture

Why every pattern gets the same share. Put 1000 walkers on each of the 32 patterns and let every walker take one step. A pattern sends its 1000 walkers out, 200 to each of its 5 neighbours. It also receives 200 from each of its 5 neighbours: 1000 back in. Every pattern still holds 1000, so "all 32 equally likely" never changes. That is what stationary means: \(\pi_s = \tfrac1{32}\).

Why share \(\tfrac1{32}\) means return time 32 (Kac). In a long run of \(T\) seconds you are at all-off about \(T/32\) times. \(T/32\) visits spread over \(T\) seconds means the gaps between visits average \(32\).

Solution

  1. STATES. The state is the on/off pattern of the 5 bulbs: \(N = 2^5 = 32\) states. Start state \(s\) = all off.Why: the pattern is all the future depends on.
  2. MOVES. From any state the chain moves to one of the 5 patterns that differ in exactly one bulb, each with probability \(\tfrac15\). Every move can be undone.Why: one of 5 bulbs is chosen uniformly; toggling the same bulb again returns to the start.
  3. \(\pi\) SHORTCUT. Check: do the arrows into each state carry total probability 1? Here each state has 5 incoming arrows of \(\tfrac15\): \(5 \cdot \tfrac15 = 1\). So the uniform \(\pi_j = \tfrac1N\) is stationary: \((\pi P)_j = \sum_{i \sim j}\tfrac{1}{32}\cdot\tfrac15 = \tfrac{1}{32}\cdot5\cdot\tfrac15 = \tfrac{1}{32}\).Why: inflow to \(j\) = \(\tfrac1N \times\) (sum of incoming probabilities) = \(\tfrac1N \times 1\) = what \(j\) already had. If the check fails but the move is "go to a uniformly random neighbour" on a graph, use \(\pi_v = d_v / \sum_u d_u\) instead (degree over total degree).
  4. KAC. The chain is irreducible, so the expected return time to all-off is \(1/\pi_s = \) \(32\) seconds.Why: any pattern reaches any other by toggling the bulbs where they differ; Kac needs that, otherwise \(\pi\) is not unique.

Conclusion. It takes 32 seconds on average to return to all-off. ∎
