1 · Definition

  1. (Xₙ) on a finite set S is a Markov chain if P(Xₙ₊₁ = j | Xₙ = i, past) = P(Xₙ₊₁ = j | Xₙ = i) = pᵢⱼ. Markov property: only the present matters.
  2. Transition matrix P = (pᵢⱼ): row i gives where you go from i, so every row sums to 1.
  3. If the next step depends on the last two states, use pairs (previous, current) as the states. The chain on pairs is Markov.

2 · Probability of a path

P(X₀=i₀, …, Xₙ=iₙ) = P(X₀=i₀)·p_{i₀i₁}⋯p_{iₙ₋₁iₙ}. This is the chain rule with each conditional cut down by the Markov property.

Path B → A → C

City chain P = [[.5,.3,.2],[.1,.6,.3],[.4,.2,.4]] (order A,B,C). X₀ ~ (.9, .05, .05).

Key idea

Multiply the start probability by the two transitions.

Solution

.05 · p_BA · p_AC = .05 · .1 · .2 = 0.001. ∎

3 · n-step transitions (Chapman–Kolmogorov)

Tᵢⱼ(n) = Σₖ Tᵢₖ(n−1)pₖⱼ. This is total probability over the state at time n−1. In matrix form T(n) = T(n−1)P, so T(n) = Pⁿ.

City chain: T₁₂(2), P², and T₁₃(3)

Key idea

Row 1 of P times column j of P (then of P²).

Solution
  1. T₁₂(2) = .5·.3 + .3·.6 + .2·.2 = 0.37.
  2. P² = [[.36,.37,.27],[.23,.45,.32],[.38,.32,.30]].
  3. P³ has row 1 = (.325, .384, .291), so T₁₃(3) = 0.291. (computed)

∎

4 · Classifying states

  1. Accessible i → j: Pⁿᵢⱼ > 0 for some n ≥ 1, i.e. there is a path of positive-probability steps. Communicate i ↔ j: both directions.
  2. Recurrent i: every j with i → j also has j → i. (In a finite chain this is the same as returning to i with probability 1.)
  3. Transient: not recurrent. Absorbing: pᵢᵢ = 1.

5 · Decomposition

  1. Recurrent class: a recurrent i together with everything accessible from it. All of these states communicate, and the chain can never leave the class.
  2. S = (one or more recurrent classes) ∪ (transient states).
  3. Periodic class: it splits into S₁ → S₂ → ⋯ → S_d → S₁ with d > 1. Test: if some n has Pⁿᵢⱼ > 0 for all j in the class, the class is aperiodic.
  4. Irreducible: a single class and no transient states.

Every transient state reaches a recurrent state

(Finite chain.)

Key idea

In the graph of positive transitions, walk from t into a sink strongly connected component. Nothing leaves a sink, so its states are recurrent.

Solution
  1. Draw an edge i → j when pᵢⱼ > 0. Group the states into strongly connected components (maximal sets of mutually communicating states).
  2. The components form a directed acyclic graph with finitely many nodes, so from t's component some path ends at a component C with no outgoing edges (a sink).
  3. Let r ∈ C. If r → j then j ∈ C (C has no exits), so j → r (C is strongly connected). So r is recurrent by definition, and t → r.

∎

⚠ Course argues with "transient states are visited only finitely often", a probabilistic fact it never proved and that doesn't match its graph definition of "transient". The sink-component argument uses only the definitions.

6 · Steady state

  1. Stationary π: π = πP and Σπᵢ = 1. Every finite chain has one. It is unique iff there is exactly one recurrent class.
  2. Convergence theorem: if there is one recurrent class and it is aperiodic, then P(Xₙ = j | X₀ = i) → πⱼ for every i.
  3. If the class is periodic, the limit can fail to exist (A ⇄ B deterministically). But with one recurrent class, the fraction of time spent in j still → πⱼ.
  4. πᵢpᵢⱼ = the long-run fraction of steps that are i → j.

Two-state chain P = [[.7,.3],[.5,.5]]

Key idea

Balance: the flow 1→2 equals the flow 2→1.

Solution
  1. π₁·.3 = π₂·.5, so π₂ = .6π₁.
  2. π₁ + .6π₁ = 1, so π₁ = 0.625 and π₂ = 0.375.

∎

7 · Absorption probabilities

aᵢ = P(eventually absorbed in s | X₀ = i). Then a_s = 1, a_t = 0 for every other absorbing t, and aᵢ = Σⱼ pᵢⱼaⱼ for transient i (first-step analysis). For recurrent classes, collapse each class into a single absorbing node first.

Absorbing states 3, 4

Rows: 1 → (.5,.3,.2,0), 2 → (.4,.4,0,.2). P(absorbed at 3)?

Key idea

Two linear equations in a₁, a₂.

Solution
  1. a₁ = .5a₁ + .3a₂ + .2 and a₂ = .4a₁ + .4a₂.
  2. The second gives a₂ = ⅔a₁. The first gives .3a₁ = .2.
  3. a₁ = 2/3, a₂ = 4/9.

∎

⚠ Course's matrix has row 4 = (0, .2, 0, 1), which sums to 1.2. An absorbing row must be (0,0,0,1). The answer is unaffected.

Two recurrent classes C₁ = {3,4}, C₂ = {5,6,7}

From 1: to 2 w.p. .2, to C₁ w.p. .2, to C₂ w.p. .6. From 2: to 1 w.p. .2, to C₁ w.p. .4, to C₂ w.p. .4. Report a₁ + a₂ for C₁.

Key idea

Collapse each class to a single node.

Solution
  1. a₁ = .2a₂ + .2 and a₂ = .2a₁ + .4.
  2. a₁ = .04a₁ + .28, so a₁ = 7/24 and a₂ = 11/24. Sum = 0.75.

∎

8 · Expected time to absorption

tᵢ = E[steps to absorption | X₀ = i]. t = 0 on absorbing states (or collapsed classes), and tᵢ = 1 + Σⱼ pᵢⱼtⱼ for transient i.

Rows 1 → (.7,.1,.2,0), 2 → (.4,.3,0,.3)

Report t₁ + t₂.

Key idea

Solve the two linear equations.

Solution
  1. .3t₁ − .1t₂ = 1 and −.4t₁ + .7t₂ = 1.
  2. t₂ = 3t₁ − 10, so 1.7t₁ = 8: t₁ = 80/17 and t₂ = 70/17.
  3. Sum = 150/17 ≈ 8.82353.

∎

Two classes again

From 1: to 2 w.p. .3, otherwise absorbed. From 2: to 1 w.p. .1, otherwise absorbed. Report t₁ + t₂.

Key idea

Only the transient-to-transient moves add time.

Solution

t₁ = 1 + .3t₂ and t₂ = 1 + .1t₁, so t₁ = 130/97 and t₂ = 110/97. Sum = 240/97 ≈ 2.47423. ∎

9 · First passage & return times

  1. First passage to s: t_s = 0 and tᵢ = 1 + Σⱼ pᵢⱼtⱼ for i ≠ s.
  2. Return time: t*_s = 1 + Σⱼ p_sⱼtⱼ.
  3. Kac: in an irreducible chain, t*ᵢ = 1/πᵢ. (Sketch: you visit i once every t*ᵢ steps on average, so the long-run fraction of time in i is 1/t*ᵢ, and that fraction is πᵢ.)
  4. Random walk on a graph: if pᵢⱼ > 0 ⇔ pⱼᵢ > 0 and pᵢⱼ = 1/dᵢ, then π ∝ d. Proof: (dP)ⱼ = Σᵢ dᵢ·1[i~j]/dᵢ = #neighbours of j = dⱼ.

p₁₁ = .8, p₁₂ = .2, p₂₁ = .6, p₂₂ = .4

(a) E[time from 2 to 1]. (b) E[return time to 1].

Key idea

First-step analysis. Check (b) with Kac.

Solution
  1. (a) t₂ = 1 + .4t₂, so t₂ = 5/3 ≈ 1.67.
  2. (b) t*₁ = 1 + .2·5/3 = 4/3 ≈ 1.33.
  3. Check: π₁·.2 = π₂·.6 gives π₁ = ¾, and 1/π₁ = 4/3 ✓.

∎

Five bulbs: return to all-off

Each second a uniformly chosen bulb is toggled.

Key idea

This is a random walk on the 5-cube. Every vertex has degree 5, so π is uniform on the 32 states.

Solution
  1. 32 states. Each has 5 neighbours, each chosen w.p. 1/5, and every move can be undone.
  2. By the graph theorem π = 1/32 for every state. By Kac, the expected return time = 32 seconds.

∎
