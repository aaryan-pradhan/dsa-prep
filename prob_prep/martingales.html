1 · Stochastic processes

A stochastic process is a family \(\{X_t : t \in T\}\) of random variables. It is discrete-time if \(T = \{0,1,2,\dots\}\) and continuous-time if \(T = [0,\infty)\). One realisation \(t \mapsto X_t(\omega)\) is a sample path. Markov chains are one kind of stochastic process.

2 · Martingales

  1. Martingale: \(\mathbb{E}|X_n| < \infty\) and \(\mathbb{E}[X_{n+1} \mid X_0,\dots,X_n] = X_n\), a fair game. Submartingale: \(\ge\). Supermartingale: \(\le\).
  2. Taking expectations: \(\mathbb{E}[X_n] = \mathbb{E}[X_0]\) for every fixed \(n\).
  3. Examples: a sum of independent mean-0 steps. A product of independent mean-1 factors: \(\mathbb{E}[Z_{n+1} \mid \text{past}] = Z_n\,\mathbb{E}[X_{n+1}] = Z_n\).

3 · Optional stopping

  1. Stopping time \(T\): whether \(\{T = n\}\) happened can be decided from \(X_0,\dots,X_n\) alone. "The first time \(Z\) hits 10" is one; "the last time \(Z > 0\)" is not.
  2. Stopped process \(Z_{\min(n,T)}\) is again a martingale. Before \(T\) it moves fairly, and after \(T\) it is frozen.
  3. OST: \(\mathbb{E}[Z_T] = \mathbb{E}[Z_0]\) if \(T < \infty\) a.s. and at least one of these holds: \[\text{(a) } |Z_{\min(n,T)}| \le c \ \ \forall n; \qquad \text{(b) } T \le c; \qquad \text{(c) } \mathbb{E}[T] < \infty \ \text{and}\ \mathbb{E}\big[|Z_{n+1} - Z_n| \,\big|\, \text{past}\big] \le c.\]
  4. It can fail without them: the fair walk with \(T\) = the first hit of \(+10\) has \(\mathbb{E}[Z_T] = 10 \ne 0\). There, \(\mathbb{E}[T] = \infty\) and the walk is unbounded below.
  5. Finite \(\mathbb{E}[T]\) trick: if from every position there is probability \(\ge p\) of stopping within \(N\) steps, then \(T \le N \cdot \text{Geometric}(p)\), so \(\mathbb{E}[T] \le N/p\).

⚠ Course's condition (a) bounds \(Z_i\) itself; what is needed is a bound on the stopped process, plus \(T < \infty\). Always check a condition before applying OST.

Fair walk from 0 to +4 or −8

\(P(\text{ends at } +4)\)?

Key idea

The stopped walk is bounded, so \(\mathbb{E}[X_T] = 0\).

Solution
  1. \(|X_{\min(n,T)}| \le 8\) and \(T < \infty\) a.s., so OST (a) applies. (finite-\(\mathbb{E}[T]\) trick with \(N = 12\))
  2. \(4p - 8(1-p) = 0\), so \(p = \) \(\tfrac{2}{3}\).

∎

Stop and bet on the next card being red

52 cards are revealed one by one. You may stop at any point, and you win if the next card is red. What is the best possible \(P(\text{win})\)?

Key idea

\(X_n = \dfrac{\text{reds left}}{\text{cards left}}\) is a martingale, and \(P(\text{win}) = \mathbb{E}[X_T]\).

Solution
  1. With \(m = 52 - n\) cards and \(r\) reds left: \[\mathbb{E}[X_{n+1} \mid \text{past}] = \frac{r}{m}\cdot\frac{r-1}{m-1} + \frac{m-r}{m}\cdot\frac{r}{m-1} = \frac{r}{m}.\]
  2. Given the past at time \(T\), \(P(\text{win}) = X_T\). So \(P(\text{win}) = \mathbb{E}[X_T]\).
  3. \(T \le 51\), so OST (b) gives \(\mathbb{E}[X_T] = X_0 = \tfrac12\). Every strategy gives \(\tfrac12\).

∎

2-D walk: expected exit time from the radius-10 disc

Key idea

\(Z_n = X_n^2 + Y_n^2 - n\) is a martingale, so \(\mathbb{E}[T] = \mathbb{E}[X_T^2 + Y_T^2]\).

Solution
  1. One step changes exactly one coordinate by \(\pm 1\): \(\mathbb{E}[X^2 + Y^2 \text{ after} \mid \text{past}] = X^2 + Y^2 + 1\). So \(Z_n\) is a martingale.
  2. Let \(T = \min\{n : X_n^2 + Y_n^2 \ge 100\}\), the exit time. Before \(T\) the walk is in a finite set, so \(\mathbb{E}[T] < \infty\) (trick) and the steps of \(Z\) are bounded. OST (c) applies.
  3. \(\mathbb{E}[T] = \mathbb{E}[X_T^2 + Y_T^2]\). On exit \(X_T^2 + Y_T^2 \ge 100\), and it can overshoot. For example, \((9,4) \to (10,4)\) has \(r^2 = 116\).
  4. Solving the exact linear system on the 305 interior lattice points gives \(\mathbb{E}[T] \approx\) \(104.69\). It is not 100.

∎

⚠ Course error. It defines \(T\) as the first time \(x^2 + y^2 = 100\) exactly and claims the walk stays inside the disc until then, which gives 100. But a lattice walk can jump past the circle without landing on it (the circle has only 12 lattice points). So that \(T\) is not the exit time, and its expectation is not 100. The identity \(\mathbb{E}[T] = \mathbb{E}[R_T^2]\) is right; the value \(R_T^2 = 100\) is not.

4 · Wald's identity

If \(X_1, X_2, \dots\) are i.i.d. with \(\mathbb{E}|X| < \infty\), \(T\) is a stopping time with \(\mathbb{E}[T] < \infty\), and \(S_T = X_1 + \dots + X_T\), then \[\mathbb{E}[S_T] = \mathbb{E}[T]\,\mathbb{E}[X].\] (It is OST applied to \(S_n - n\,\mathbb{E}[X]\).)

Biased walk to +6

Steps are \(+1\) w.p. \(\tfrac23\) and \(-1\) w.p. \(\tfrac13\). \(\mathbb{E}[\text{time to reach } +6]\)?

Key idea

\(S_T = 6\) exactly, and \(\mathbb{E}[X] = \tfrac13\).

Solution

\(\mathbb{E}[T] < \infty\) because of the positive drift. Then \(6 = \mathbb{E}[T]\cdot\tfrac13\), so \(\mathbb{E}[T] = \) \(18\). ∎

Roll until the first value repeats: \(\mathbb{E}[\text{sum}]\)

Key idea

\(T = 1 + \text{Geometric}(\tfrac16)\), so \(\mathbb{E}[T] = 7\). \(T\) is a stopping time for the i.i.d. rolls.

Solution
  1. \(\mathbb{E}[S_T] = 7 \cdot 3.5 = \) \(\tfrac{49}{2} = 24.5\).
  2. Check: given the first roll \(x\), the \(\approx 5\) non-matching rolls have mean \(\tfrac{21-x}{5}\) each, so \(\mathbb{E}[S \mid x] = x + (21-x) + x = 21 + x\). Averaging gives \(24.5\) ✓.

∎

Fair walk, boundaries \(-4\) and \(+8\)

(a) \(P(\text{hit } +8 \text{ first})\). (b) \(\mathbb{E}[T]\).

Key idea

(a) \(S_n\), then (b) \(S_n^2 - n\).

Solution
  1. (a) \(8p - 4(1-p) = 0\), so \(p = \) \(\tfrac13\).
  2. (b) \(\mathbb{E}[T] = \mathbb{E}[S_T^2] = 64\cdot\tfrac13 + 16\cdot\tfrac23 = \) \(32\). (In general, \(ab\) for boundaries \(-a\) and \(+b\).)

∎

Biased walk (\(p = \tfrac23\)), boundaries \(-4\) and \(+8\)

(a) \(P(\text{hit } +8 \text{ first})\). (b) \(\mathbb{E}[T]\).

Key idea

(a) \((q/p)^S = (\tfrac12)^S\). (b) \(S - n/3\).

Solution
  1. (a) \(r\cdot 2^{-8} + (1-r)\cdot 2^{4} = 1\), so \[r = \frac{15}{16 - 1/256} = \frac{256}{273} \approx 0.93773.\] \(\tfrac{256}{273}\)
  2. (b) \(\mathbb{E}[S_T] = 8r - 4(1-r) = \tfrac{660}{91}\), so \(\mathbb{E}[T] = 3\cdot\tfrac{660}{91} = \) \(\tfrac{1980}{91} \approx 21.75824\).

∎

\(\mathbb{E}[\text{tosses until HHTTHTT}]\)

Key idea

Before each toss a new gambler bets $1 on the pattern, doubling on every correct symbol. (Total wealth) \(- n\) is a martingale. At time \(T\) only the gamblers whose matched part is both a prefix and a suffix of the pattern still hold money.

Solution
  1. All bets are fair and $1 enters per toss, so \(M_n = W_n - n\) is a martingale. \(\mathbb{E}[T] < \infty\), and the increments are bounded before \(T\). So OST gives \(\mathbb{E}[W_T] = \mathbb{E}[T]\).
  2. A gambler still alive at \(T\) has matched a prefix of the pattern that also ends at \(T\), i.e. a prefix that is also a suffix.
  3. HHTTHTT: no proper prefix equals a suffix (H/T, HH/TT, HHT/HTT, …). So only the full match survives: \(W_T = 2^7\).
  4. \(\mathbb{E}[T] = \) \(128\). (Contrast HH: the prefixes that are also suffixes are HH and H, giving \(4 + 2 = 6\).)

∎
