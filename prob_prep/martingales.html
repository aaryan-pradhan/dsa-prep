1 · Stochastic processes

A stochastic process is a family {X_t : t ∈ T} of random variables. It is discrete-time if T = {0,1,2,…} and continuous-time if T = [0,∞). One realisation t ↦ X_t(ω) is a sample path. Markov chains are one kind of stochastic process.

2 · Martingales

  1. Martingale: E|Xₙ| < ∞ and E[Xₙ₊₁ | X₀..Xₙ] = Xₙ, a fair game. Submartingale: ≥. Supermartingale: ≤.
  2. Taking expectations: E[Xₙ] = E[X₀] for every fixed n.
  3. Examples: a sum of independent mean-0 steps. A product of independent mean-1 factors: E[Zₙ₊₁ | past] = Zₙ·E[Xₙ₊₁] = Zₙ.

3 · Optional stopping

  1. Stopping time T: whether {T = n} happened can be decided from X₀..Xₙ alone. "The first time Z hits 10" is one; "the last time Z > 0" is not.
  2. Stopped process Z_{min(n,T)} is again a martingale. Before T it moves fairly, and after T it is frozen.
  3. OST: E[Z_T] = E[Z₀] if T < ∞ a.s. and at least one of these holds: (a) |Z_{min(n,T)}| ≤ c for all n; (b) T ≤ c; (c) E[T] < ∞ and E[|Zₙ₊₁ − Zₙ| | past] ≤ c.
  4. It can fail without them: the fair walk with T = the first hit of +10 has E[Z_T] = 10 ≠ 0. There, E[T] = ∞ and the walk is unbounded below.
  5. Finite E[T] trick: if from every position there is probability ≥ p of stopping within N steps, then T ≤ N·Geometric(p), so E[T] ≤ N/p.

⚠ Course's condition (a) bounds Zᵢ itself; what is needed is a bound on the stopped process, plus T < ∞. Always check a condition before applying OST.

Fair walk from 0 to +4 or −8

P(ends at +4)?

Key idea

The stopped walk is bounded, so E[X_T] = 0.

Solution
  1. |X_{min(n,T)}| ≤ 8 and T < ∞ a.s., so OST (a) applies. (finite-E[T] trick with N = 12)
  2. 4p − 8(1−p) = 0, so p = 2/3.

∎

Stop and bet on the next card being red

52 cards are revealed one by one. You may stop at any point, and you win if the next card is red. What is the best possible P(win)?

Key idea

Xₙ = (reds left)/(cards left) is a martingale, and P(win) = E[X_T].

Solution
  1. E[Xₙ₊₁ | past] = (r/m)·(r−1)/(m−1) + ((m−r)/m)·r/(m−1) = r/m, with m = 52 − n.
  2. Given the past at time T, P(win) = X_T. So P(win) = E[X_T].
  3. T ≤ 51, so OST (b) gives E[X_T] = X₀ = ½. Every strategy gives 1/2.

∎

2-D walk: expected exit time from the radius-10 disc

Key idea

Zₙ = Xₙ² + Yₙ² − n is a martingale, so E[T] = E[X_T² + Y_T²].

Solution
  1. One step changes exactly one coordinate by ±1: E[X² + Y² after | past] = X² + Y² + 1. So Zₙ is a martingale.
  2. Let T = min{n : Xₙ² + Yₙ² ≥ 100}, the exit time. Before T the walk is in a finite set, so E[T] < ∞ (trick) and the steps of Z are bounded. OST (c) applies.
  3. E[T] = E[X_T² + Y_T²]. On exit X_T² + Y_T² ≥ 100, and it can overshoot. For example, (9,4) → (10,4) has r² = 116.
  4. Solving the exact linear system on the 305 interior lattice points gives E[T] ≈ 104.69. It is not 100.

∎

⚠ Course error. It defines T as the first time x² + y² = 100 exactly and claims the walk stays inside the disc until then, which gives 100. But a lattice walk can jump past the circle without landing on it (the circle has only 12 lattice points). So that T is not the exit time, and its expectation is not 100. The identity E[T] = E[R_T²] is right; the value R_T² = 100 is not.

4 · Wald's identity

If X₁, X₂, … are i.i.d. with E|X| < ∞, T is a stopping time with E[T] < ∞, and S_T = X₁ + … + X_T, then E[S_T] = E[T]·E[X]. (It is OST applied to Sₙ − nE[X].)

Biased walk to +6

Steps are +1 w.p. ⅔ and −1 w.p. ⅓. E[time to reach +6]?

Key idea

S_T = 6 exactly, and E[X] = ⅓.

Solution

E[T] < ∞ because of the positive drift. Then 6 = E[T]·⅓, so E[T] = 18. ∎

Roll until the first value repeats: E[sum]

Key idea

T = 1 + Geometric(1/6), so E[T] = 7. T is a stopping time for the i.i.d. rolls.

Solution
  1. E[S_T] = 7·3.5 = 49/2 = 24.5.
  2. Check: given the first roll x, the ≈5 non-matching rolls have mean (21−x)/5 each, so E[S | x] = x + (21−x) + x = 21 + x. Averaging gives 24.5 ✓.

∎

Fair walk, boundaries −4 and +8

(a) P(hit +8 first). (b) E[T].

Key idea

(a) Sₙ, then (b) Sₙ² − n.

Solution
  1. (a) 8p − 4(1−p) = 0, so p = 1/3.
  2. (b) E[T] = E[S_T²] = 64·⅓ + 16·⅔ = 32. (In general, a·b for boundaries −a and +b.)

∎

Biased walk (p = ⅔), boundaries −4 and +8

(a) P(hit +8 first). (b) E[T].

Key idea

(a) (q/p)^S = (½)^S. (b) S − n/3.

Solution
  1. (a) r·2⁻⁸ + (1−r)·2⁴ = 1, so r = 15/(16 − 1/256) = 256/273 ≈ 0.93773.
  2. (b) E[S_T] = 8r − 4(1−r) = 660/91, so E[T] = 3·660/91 = 1980/91 ≈ 21.75824.

∎

E[tosses until HHTTHTT]

Key idea

Before each toss a new gambler bets $1 on the pattern, doubling on every correct symbol. (Total wealth) − n is a martingale. At time T only the gamblers whose matched part is both a prefix and a suffix of the pattern still hold money.

Solution
  1. All bets are fair and $1 enters per toss, so Mₙ = Wₙ − n is a martingale. E[T] < ∞, and the increments are bounded before T. So OST gives E[W_T] = E[T].
  2. A gambler still alive at T has matched a prefix of the pattern that also ends at T, i.e. a prefix that is also a suffix.
  3. HHTTHTT: no proper prefix equals a suffix (H/T, HH/TT, HHT/HTT, …). So only the full match survives: W_T = 2⁷.
  4. E[T] = 128. (Contrast HH: the prefixes that are also suffixes are HH and H, giving 4 + 2 = 6.)

∎
