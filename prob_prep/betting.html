1 · Plain expected value

Fair price = E[payout]. Write the payout as a random variable, then use linearity and indicators.

Known urn (10B, 10W), $10 for the right colour

Key idea

P(win) = ½ whichever colour you call.

Solution

10·½ = $5. ∎

Secret urn, unknown mix

Key idea

Call your colour with a fair coin flip. Then P(win) = ½ whatever the mix is.

Solution
  1. Let the fraction of black be p (fixed, unknown). Call black or white with probability ½ each, independently.
  2. P(win) = ½p + ½(1−p) = ½ for every p.
  3. Fair fee = $5, guaranteed whatever the friend chose.

∎

⚠ Course assumes p ~ U[0,1]. Nothing justifies that: an adversarial friend could pick p = 0 against a fixed call of "black". Randomising the call (step 1) gives ½ with no assumption.

$10 per red card before the first spade

Key idea

A red card precedes all 13 spades with probability 1/14.

Solution
  1. X = Σ over the 26 reds of I(red before every spade). Each red is equally likely to be anywhere in the order of {it, 13 spades}.
  2. E[X] = 26/14 = 13/7. Fair fee = 130/7 ≈ $18.57.

∎

2 · Present vs future

  1. At each decision: stop if (value now) ≥ E[value of continuing optimally]; otherwise continue.
  2. With a fixed number of steps, work backwards from the last step.
  3. One-step look-ahead ("stop as soon as stopping beats exactly one more step") is optimal when the problem is monotone: once stopping is better, it stays better.

Dice game: up to 2 rolls, then up to 3

Key idea

V₁ = 3.5. Keep a roll iff it beats the value of the rolls you still have left.

Solution
  1. 2 rolls: keep 4–6 (> 3.5), otherwise reroll. V₂ = ½·5 + ½·3.5 = 4.25.
  2. 3 rolls: keep 5–6 (> 4.25), otherwise play the 2-roll game. V₃ = ⅓·5.5 + ⅔·4.25 = 14/3 ≈ 4.67.

∎

Push your luck with a d10

1–9 adds that many $ to your total; 10 loses everything and ends the game. You may quit after any roll. At what total should you quit?

Key idea

One more roll changes the expected total from x to 0.9(x + 5).

Solution
  1. E[after one roll] = (9/10)(x + 5). This is ≤ x ⇔ x ≥ 45.
  2. Monotone: your total only goes up while you play, so once x ≥ 45 it stays ≥ 45. So one-step look-ahead is optimal.
  3. Quit at the first total ≥ $45 (at exactly 45 you are indifferent).

∎

⚠ Course compares with just one more roll but never says why that is enough. Step 2 is the reason.

3 · Optimal parameters

Describe a family of strategies with a parameter θ (a threshold, a fraction), compute E(θ) or P(θ), then maximise. First argue that the optimum lies in that family.

Secretary problem, n = 6

Maximise P(hiring the best).

Key idea

Skip the first k candidates, then hire the first one who is best so far. The best candidate is hired iff the best of the first i−1 is among the skipped k.

Solution
  1. Only a best-so-far candidate can be the overall best. Given that the i-th is best so far, P(best overall) = (1/6)/(1/i) = i/6, which increases with i. Also, the chance that a later best-so-far appears doesn't depend on the ranks so far. So a threshold rule is optimal.
  2. With threshold k ≥ 1: P(k) = Σ_{i=k+1}^{6} (1/6)·k/(i−1).
  3. P(1) = 137/360 ≈ .381, P(2) = 77/180 ≈ .428, P(3) = 47/120 ≈ .392, P(4) = .3, P(5) = 1/6.
  4. Best: skip 2, giving P = 77/180 ≈ 0.428. (For large n: skip n/e, giving ≈ 1/e.)

∎

⚠ Course asserts the threshold form without justifying it (step 1). It also contains a typo: "P(5) = 1/6 + 1/6 = 1/6".

Paid redraws from 1..100

$1 per draw (with replacement). You keep the last number drawn. E[net] under optimal play?

Key idea

Draws are i.i.d. and the history doesn't matter, so the optimal rule is a threshold x: stop at the first draw ≥ x.

Solution
  1. The number of draws is Geometric(p) with p = (101−x)/100, so the mean cost is 100/(101−x). The final draw is uniform on {x..100}, with mean (x+100)/2.
  2. E(x) = (x+100)/2 − 100/(101−x). Setting the derivative to 0 gives (101−x)² = 200, so x ≈ 86.9.
  3. Integers: E(86) ≈ 86.333, E(87) ≈ 86.357, E(88) ≈ 86.308. So x* = 87 and E = ≈ $86.36.
  4. Consistency: the value V ≈ 86.36 says stop iff draw ≥ V, i.e. ≥ 87. ✓

∎

4 · Dynamic programming

State = everything that decides the future. V(state) = max over actions of E[reward + V(next state)]. Fill the table from the terminal states.

Guess the colour of each draw (3W, 3B)

$1 per correct guess. Optimal expected total?

Key idea

Always guess the majority colour of what remains. DP over (w,b).

Solution
  1. E(w,b) = max over the guess of [P(correct)·1 + the expected E of the next state]. E(w,0) = w and E(0,b) = b.
  2. Filling the 4×4 table gives E(3,3) = 41/10 = 4.1. (exact DP)

∎

+1 red, −1 black, quit any time (4R, 4B)

Key idea

State (b,r) = cards remaining. The current total is b − r. Take the max of quitting and drawing.

Solution
  1. E(b,r) = max{b − r, (b/(b+r))E(b−1,r) + (r/(b+r))E(b,r−1)}.
  2. Edges: E(0,r) = 0 (only reds remain; your total is −r, so draw them all to finish at 0). E(b,0) = b (only blacks remain; quit now).
  3. Filling the table gives E(4,4) = 1. (exact DP)

∎

5 · Lessons from the past

Symmetry, small cases and induction still work. For guessing games, choose the best answer separately for each observation: that maximises the total probability of being right.

Is X₁ the min, the median or the max?

Three i.i.d. U[0,1]. You see only X₁ = x.

Key idea

Given x: P(min) = (1−x)², P(median) = 2x(1−x), P(max) = x². Pick the largest.

Solution
  1. (1−x)² ≥ 2x(1−x) ⇔ x ≤ ⅓, and x² ≥ 2x(1−x) ⇔ x ≥ ⅔.
  2. Rule: guess min if x ≤ ⅓, median if ⅓ < x < ⅔, max if x ≥ ⅔. This is optimal because it maximises the probability of being right for every x.
  3. P = 2∫₀^{⅓}(1−x)² dx + ∫_{⅓}^{⅔} 2x(1−x) dx = 38/81 + 13/81 = 17/27 ≈ 0.63.

∎

⚠ Course optimises only over symmetric thresholds (α, 1−α) and assumes the optimum lies in that family. The comparison for each x (step 1) proves it.

Alternate guessing a secret in 1..100

After each wrong guess, both players hear "higher" or "lower". You go first. P(you win)?

Key idea

Let Wₙ = n·pₙ (the expected number of secrets the first player wins). Then Wₙ = maxₖ [n − W_{k−1} − W_{n−k}], and the solution is Wₙ = ⌈n/2⌉.

Solution
  1. Guess k: it is right w.p. 1/n. Otherwise the opponent moves first on k−1 or n−k numbers. So n·pₙ = maxₖ [1 + (k−1) − W_{k−1} + (n−k) − W_{n−k}].
  2. Induction hypothesis: Wₘ = ⌈m/2⌉ for all m < n. Let a = k−1 and b = n−k, so a + b = n − 1.
  3. n even: a + b is odd, so ⌈a/2⌉ + ⌈b/2⌉ = n/2 for every k. So Wₙ = n/2.
  4. n odd: a + b is even. The ceilings sum to (n−1)/2 (both even, e.g. k = 1) or (n+1)/2 (both odd). The max gives Wₙ = (n+1)/2.
  5. pₙ = ⌈n/2⌉/n, so p₁₀₀ = 1/2. (DP-checked for n ≤ 100)

∎

⚠ Course's induction ends with "a similar check yields ½". The substitution Wₙ = n·pₙ (steps 1–4) makes every case a one-line parity count.
