1 · Plain expected value

Fair price \(= \mathbb{E}[\text{payout}]\). Write the payout as a random variable, then use linearity and indicators.

Known urn (10B, 10W), $10 for the right colour

Key idea

\(P(\text{win}) = \tfrac12\) whichever colour you call.

Solution

\(10 \cdot \tfrac12 = \) $5. ∎

Secret urn, unknown mix

Key idea

Call your colour with a fair coin flip. Then \(P(\text{win}) = \tfrac12\) whatever the mix is.

Solution
  1. Let the fraction of black be \(p\) (fixed, unknown). Call black or white with probability \(\tfrac12\) each, independently.
  2. \(P(\text{win}) = \tfrac12 p + \tfrac12(1-p) = \tfrac12\) for every \(p\).
  3. Fair fee = $5, guaranteed whatever the friend chose.

∎

⚠ Course assumes \(p \sim U[0,1]\). Nothing justifies that: an adversarial friend could pick \(p = 0\) against a fixed call of "black". Randomising the call (step 1) gives \(\tfrac12\) with no assumption.

$10 per red card before the first spade

Key idea

A red card precedes all 13 spades with probability \(\tfrac{1}{14}\).

Solution
  1. \(X = \sum_{\text{26 reds}} \mathbb{1}[\text{red before every spade}]\). Each red is equally likely to be anywhere in the order of \(\{\text{it}, 13 \text{ spades}\}\).
  2. \(\mathbb{E}[X] = \tfrac{26}{14} = \tfrac{13}{7}\). Fair fee \(= \tfrac{130}{7} \approx\) $18.57.

∎

2 · Present vs future

  1. At each decision: stop if (value now) \(\ge \mathbb{E}[\text{value of continuing optimally}]\); otherwise continue.
  2. With a fixed number of steps, work backwards from the last step.
  3. One-step look-ahead ("stop as soon as stopping beats exactly one more step") is optimal when the problem is monotone: once stopping is better, it stays better.

Dice game: up to 2 rolls, then up to 3

Key idea

\(V_1 = 3.5\). Keep a roll iff it beats the value of the rolls you still have left.

Solution
  1. 2 rolls: keep 4–6 (\(> 3.5\)), otherwise reroll. \(V_2 = \tfrac12\cdot 5 + \tfrac12\cdot 3.5 = \) \(4.25\).
  2. 3 rolls: keep 5–6 (\(> 4.25\)), otherwise play the 2-roll game. \(V_3 = \tfrac13\cdot 5.5 + \tfrac23\cdot 4.25 = \) \(\tfrac{14}{3} \approx 4.67\).

∎

Push your luck with a d10

1–9 adds that many $ to your total; 10 loses everything and ends the game. You may quit after any roll. At what total should you quit?

Key idea

One more roll changes the expected total from \(x\) to \(0.9(x + 5)\).

Solution
  1. \(\mathbb{E}[\text{after one roll}] = \tfrac{9}{10}(x + 5)\). This is \(\le x \iff x \ge 45\).
  2. Monotone: your total only goes up while you play, so once \(x \ge 45\) it stays \(\ge 45\). So one-step look-ahead is optimal.
  3. Quit at the first total \(\ge\) $45 (at exactly 45 you are indifferent).

∎

⚠ Course compares with just one more roll but never says why that is enough. Step 2 is the reason.

3 · Optimal parameters

Describe a family of strategies with a parameter \(\theta\) (a threshold, a fraction), compute \(\mathbb{E}(\theta)\) or \(P(\theta)\), then maximise. First argue that the optimum lies in that family.

Secretary problem, \(n = 6\)

Maximise \(P(\text{hiring the best})\).

Key idea

Skip the first \(k\) candidates, then hire the first one who is best so far. The best candidate is hired iff the best of the first \(i-1\) is among the skipped \(k\).

Solution
  1. Only a best-so-far candidate can be the overall best. Given that the \(i\)-th is best so far, \(P(\text{best overall}) = \dfrac{1/6}{1/i} = \dfrac{i}{6}\), which increases with \(i\). Also, the chance that a later best-so-far appears doesn't depend on the ranks so far. So a threshold rule is optimal.
  2. With threshold \(k \ge 1\): \[P(k) = \sum_{i=k+1}^{6} \frac{1}{6}\cdot\frac{k}{i-1}.\]
  3. \(P(1) = \tfrac{137}{360} \approx .381,\ P(2) = \tfrac{77}{180} \approx .428,\ P(3) = \tfrac{47}{120} \approx .392,\ P(4) = .3,\ P(5) = \tfrac16\).
  4. Best: skip 2, giving \(P = \) \(\tfrac{77}{180} \approx 0.428\). (For large \(n\): skip \(n/e\), giving \(\approx 1/e\).)

∎

⚠ Course asserts the threshold form without justifying it (step 1). It also contains a typo: "\(P(5) = \tfrac16 + \tfrac16 = \tfrac16\)".

Paid redraws from 1..100

$1 per draw (with replacement). You keep the last number drawn. \(\mathbb{E}[\text{net}]\) under optimal play?

Key idea

Draws are i.i.d. and the history doesn't matter, so the optimal rule is a threshold \(x\): stop at the first draw \(\ge x\).

Solution
  1. The number of draws is \(\text{Geometric}(p)\) with \(p = \tfrac{101-x}{100}\), so the mean cost is \(\tfrac{100}{101-x}\). The final draw is uniform on \(\{x,\dots,100\}\), with mean \(\tfrac{x+100}{2}\).
  2. \[E(x) = \frac{x+100}{2} - \frac{100}{101-x}.\] Setting the derivative to 0 gives \((101-x)^2 = 200\), so \(x \approx 86.9\).
  3. Integers: \(E(86) \approx 86.333,\ E(87) \approx 86.357,\ E(88) \approx 86.308\). So \(x^* = 87\) and \(E = \) \(\approx\) $86.36.
  4. Consistency: the value \(V \approx 86.36\) says stop iff draw \(\ge V\), i.e. \(\ge 87\). ✓

∎

4 · Dynamic programming

State = everything that decides the future. \(V(\text{state}) = \max_{\text{action}} \mathbb{E}[\text{reward} + V(\text{next state})]\). Fill the table from the terminal states.

Guess the colour of each draw (3W, 3B)

$1 per correct guess. Optimal expected total?

Key idea

Always guess the majority colour of what remains. DP over \((w,b)\).

Solution
  1. \(E(w,b) = \max_{\text{guess}} \big[P(\text{correct}) + \mathbb{E}[E(\text{next state})]\big]\). \(E(w,0) = w\) and \(E(0,b) = b\).
  2. Filling the \(4\times4\) table gives \(E(3,3) = \) \(\tfrac{41}{10} = 4.1\). (exact DP)

∎

+1 red, −1 black, quit any time (4R, 4B)

Key idea

State \((b,r)\) = cards remaining. The current total is \(b - r\). Take the max of quitting and drawing.

Solution
  1. \[E(b,r) = \max\Big\{\,b - r,\ \ \frac{b}{b+r}E(b-1,r) + \frac{r}{b+r}E(b,r-1)\Big\}.\]
  2. Edges: \(E(0,r) = 0\) (only reds remain; your total is \(-r\), so draw them all to finish at 0). \(E(b,0) = b\) (only blacks remain; quit now).
  3. Filling the table gives \(E(4,4) = \) \(1\). (exact DP)

∎

5 · Lessons from the past

Symmetry, small cases and induction still work. For guessing games, choose the best answer separately for each observation: that maximises the total probability of being right.

Is \(X_1\) the min, the median or the max?

Three i.i.d. \(U[0,1]\). You see only \(X_1 = x\).

Key idea

Given \(x\): \(P(\text{min}) = (1-x)^2,\ P(\text{median}) = 2x(1-x),\ P(\text{max}) = x^2\). Pick the largest.

Solution
  1. \((1-x)^2 \ge 2x(1-x) \iff x \le \tfrac13\), and \(x^2 \ge 2x(1-x) \iff x \ge \tfrac23\).
  2. Rule: guess min if \(x \le \tfrac13\), median if \(\tfrac13 < x < \tfrac23\), max if \(x \ge \tfrac23\). This is optimal because it maximises the probability of being right for every \(x\).
  3. \[P = 2\int_0^{1/3}(1-x)^2\,dx + \int_{1/3}^{2/3} 2x(1-x)\,dx = \frac{38}{81} + \frac{13}{81} = \frac{17}{27} \approx 0.63.\] \(\tfrac{17}{27}\)

∎

⚠ Course optimises only over symmetric thresholds \((\alpha, 1-\alpha)\) and assumes the optimum lies in that family. The comparison for each \(x\) (step 1) proves it.

Alternate guessing a secret in 1..100

After each wrong guess, both players hear "higher" or "lower". You go first. \(P(\text{you win})\)?

Key idea

Let \(W_n = n\,p_n\) (the expected number of secrets the first player wins). Then \(W_n = \max_k \big[n - W_{k-1} - W_{n-k}\big]\), and the solution is \(W_n = \lceil n/2 \rceil\).

Solution
  1. Guess \(k\): it is right w.p. \(\tfrac1n\). Otherwise the opponent moves first on \(k-1\) or \(n-k\) numbers. So \[n\,p_n = \max_k \big[1 + (k-1) - W_{k-1} + (n-k) - W_{n-k}\big].\]
  2. Induction hypothesis: \(W_m = \lceil m/2 \rceil\) for all \(m < n\). Let \(a = k-1\) and \(b = n-k\), so \(a + b = n - 1\).
  3. \(n\) even: \(a + b\) is odd, so \(\lceil a/2 \rceil + \lceil b/2 \rceil = n/2\) for every \(k\). So \(W_n = n/2\).
  4. \(n\) odd: \(a + b\) is even. The ceilings sum to \(\tfrac{n-1}{2}\) (both even, e.g. \(k = 1\)) or \(\tfrac{n+1}{2}\) (both odd). The max gives \(W_n = \tfrac{n+1}{2}\).
  5. \(p_n = \lceil n/2 \rceil / n\), so \(p_{100} = \) \(\tfrac12\). (DP-checked for \(n \le 100\))

∎

⚠ Course's induction ends with "a similar check yields \(\tfrac12\)". The substitution \(W_n = n\,p_n\) (steps 1–4) makes every case a one-line parity count.
