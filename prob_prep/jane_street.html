Gold Thief Lvl 1

A thief has five gold bars. The ten weights of all possible pairs of bars are 21, 22, …, 30 pounds.

Question: what is the total weight of the five bars?

Key idea

Every bar is in exactly 4 of the 10 pairs, so the ten pair sums add up to 4 × (total).

Picture

Count each bar's appearances. A bar pairs with each of the other 4 bars once. Adding all ten pair weights counts every bar 4 times: 4 × total = 21 + 22 + … + 30 = 255.

The widget checks the data: the only five weights that could give these sums don't actually give them.

Solution

Setup. Weights \(w_1, \dots, w_5\). Total \(S = w_1 + \dots + w_5\). The ten numbers \(w_i + w_j\) (\(i < j\)) are 21, 22, …, 30.

Claim. \(S = \tfrac{255}{4} = 63.75\) (and no five bars actually fit the data).

  1. \(\sum_{i<j} (w_i + w_j) = 4S\).Why: bar \(i\) appears in the pairs \(\{i, j\}\) for the 4 other bars \(j\), so \(w_i\) is added exactly 4 times.
  2. \(21 + 22 + \dots + 30 = \tfrac{10 \cdot (21 + 30)}{2} = 255\).Why: 10 terms, average \(\tfrac{21+30}{2} = 25.5\).
  3. \(4S = 255\), so \(S = \tfrac{255}{4} = 63.75\).Why: steps 1 and 2 are the same sum.
  4. Check the data. Sort \(a \le b \le c \le d \le e\). The two smallest pair sums are \(a + b = 21\) and \(a + c = 22\). The two largest are \(d + e = 30\) and \(c + e = 29\).Why: any pair other than \(\{a, b\}\) contains a weight \(\ge c\) together with one \(\ge a\), so its sum is \(\ge a + c\). The same argument from the top gives \(d + e\), then \(c + e\).
  5. \(c = S - (a + b) - (d + e) = 63.75 - 21 - 30 = 12.75\). Then \(a = 22 - c = 9.25\), \(b = 21 - a = 11.75\), \(e = 29 - c = 16.25\), \(d = 30 - e = 13.75\).Why: \(S = (a + b) + c + (d + e)\), then step 4 one equation at a time.
  6. But \(b + c = 11.75 + 12.75 = 24.5\) is not a whole number, and every pair sum should be one of 21, …, 30. So no five weights give exactly these ten sums.Why: steps 4–5 force the weights; any valid set would have to be this one.

Answer. The intended answer is \(S = 63.75\): it is what step 3 forces for any set with these sums. ∎

⚠ Course stops at \(S = \tfrac{255}{4}\) and never checks that such bars exist. They don't (steps 4–6). The data is inconsistent; 63.75 is still what QuantProf accepts.

Least Multiple Of 15 Lvl 2

Only the digits 0 and 1 may be used.

Question: what is the smallest positive multiple of 15 written with only 0s and 1s?

Key idea

15 = 3 × 5: the last digit must be 0, and the number of 1s must be a multiple of 3.

Picture

Split 15 into 3 and 5. Divisible by 5 → ends in 0 (5 is not allowed). Divisible by 3 → digit sum divisible by 3, and the digit sum is just the number of 1s. So you need at least three 1s and a final 0: the smallest such number is 1110.

Solution

Setup. \(n > 0\), every digit of \(n\) is 0 or 1, and \(15 \mid n\).

Claim. \(n = 1110\).

  1. \(15 \mid n \iff 3 \mid n\) and \(5 \mid n\).Why: \(15 = 3 \cdot 5\) with 3 and 5 coprime.
  2. \(5 \mid n\) means the last digit is 0 or 5, so here it is 0.Why: divisibility rule for 5; 5 is not an allowed digit.
  3. \(3 \mid n\) means the digit sum is divisible by 3. The digit sum equals the number of 1s, so there are 3, 6, 9, … ones.Why: divisibility rule for 3; each 1 adds 1 and each 0 adds 0.
  4. So \(n\) has at least three 1s plus a final 0: at least 4 digits.Why: \(n > 0\) rules out zero ones; steps 2 and 3.
  5. The only 4-digit number with three 1s and last digit 0 is 1110, and \(1110 = 15 \cdot 74\).Why: the three other places must all be 1. Any number with more digits is larger.

Conclusion. The smallest multiple of 15 written in 0s and 1s is 1110. ∎

Line Switch Lvl 2

100 people stand in a pizza line (positions 1 to 100). A second, identical line opens. Anyone who moves there is placed uniformly at random among the people who move. Everyone is rational and wants the earliest expected position.

Question: what is the smallest position in the original line from which switching gives a better expected position?

Key idea

If the switchers are exactly positions N to 100, the new line has 101 − N people, and person N's expected spot there is \(\tfrac{102-N}{2}\). Switch when \(\tfrac{102-N}{2} < N\).

Picture

Compare two numbers. Stay: you keep spot N (nobody in front of you leaves). Switch: you land uniformly among the 101 − N switchers, on average at spot \(\tfrac{102-N}{2}\). The staying line rises with N and the switching line falls, and they cross at N = 34.

Solution

Setup. Let N be the smallest position that switches. Everyone behind N switches too: they would stay at a later spot than N but land in the same random new line. So positions N, …, 100 switch and positions 1, …, N−1 stay.

Claim. N = 35.

  1. If person N stays, their position is N.Why: the N − 1 people in front of them all stay; only people behind leave.
  2. If person N switches, the new line has \(100 - N + 1 = 101 - N\) people, and person N's spot is uniform on \(\{1, \dots, 101 - N\}\).Why: positions N to 100 switch; each switcher is placed uniformly at random.
  3. Expected spot after switching \(= \tfrac{1 + (101 - N)}{2} = \tfrac{102 - N}{2}\).Why: the average of 1, 2, …, m is \(\tfrac{1+m}{2}\).
  4. Switching is better \(\iff \tfrac{102 - N}{2} < N \iff 102 - N < 2N \iff N > 34\).Why: steps 1 and 3; multiply by 2, add N to both sides, divide by 3.
  5. At N = 34 the two are equal (\(\tfrac{68}{2} = 34\)), so switching is not better. At N = 35: \(\tfrac{67}{2} = 33.5 < 35\), better.Why: step 4 is a strict inequality.

Conclusion. The first position where switching pays is 35. ∎

Game Of Discarding Cards Lvl 3

A standard 52-card deck is turned over two cards at a time, 26 pairs in all. Two blacks go to the dealer's pile, two reds go to the player's pile, and a red–black pair is discarded. The player wins $10 if their pile ends up bigger than the dealer's; otherwise (ties included) they get nothing.

Question: what is the fair value of the game?

Key idea

Discards remove one red and one black, so the reds kept always equal the blacks kept: the piles always tie.

Picture

Look for what never changes. Every discarded pair takes one red and one black. So the reds left over (the player's pile) and the blacks left over (the dealer's pile) are 26 − d each, where d is the number of discarded pairs. The player can never be ahead.

Solution

Setup. 26 red and 26 black cards, dealt in 26 pairs. d = the number of red–black pairs (discarded).

Claim. The fair value is $0.

  1. The discarded cards are d reds and d blacks.Why: each discarded pair is one red and one black.
  2. The player's pile holds every red that was not discarded: 26 − d cards.Why: a red is either in a red–red pair (player) or a red–black pair (discard).
  3. The dealer's pile holds every black that was not discarded: 26 − d cards.Why: the same argument for blacks.
  4. The piles are equal in every deal, so the player never has more cards and never wins.Why: steps 2 and 3; a tie pays nothing.

Conclusion. The payoff is always 0, so the game is worth $0. ∎

3 Bus Stops Lvl 3

A bus carries an unknown number of people. At each stop, \(\tfrac34\) of the passengers get off and then 7 people get on. This happens at 3 stops.

Question: what is the smallest possible number of people on the bus after the 3 stops?

Key idea

After 3 stops there are \(\tfrac{x + 588}{64}\) people, which is more than 9 for any \(x \ge 0\). So at least 10, and x = 52 gives exactly 10.

Picture

A quarter stay, then 7 board, three times. The starting count x shrinks to x/64, but the 7s pile up to 588/64 ≈ 9.19. Since people come in whole numbers, 10 is the floor, and x = 52 hits it: 52 → 20 → 12 → 10.

Solution

Setup. x = people at the start. A stop turns n people into \(\tfrac n4 + 7\), and n must be a multiple of 4 (people are whole).

Claim. 10 people.

  1. After stop 1: \(\tfrac x4 + 7\).Why: \(\tfrac34\) leave, so \(\tfrac14\) stay; then 7 board.
  2. After stop 2: \(\tfrac14\big(\tfrac x4 + 7\big) + 7 = \tfrac{x}{16} + \tfrac{7}{4} + 7 = \tfrac{x}{16} + \tfrac{35}{4}\).Why: apply the stop to step 1.
  3. After stop 3: \(\tfrac14\big(\tfrac{x}{16} + \tfrac{35}{4}\big) + 7 = \tfrac{x}{64} + \tfrac{35}{16} + 7 = \tfrac{x + 140 + 448}{64} = \tfrac{x + 588}{64}\).Why: apply the stop to step 2; \(\tfrac{35}{16} = \tfrac{140}{64}\) and \(7 = \tfrac{448}{64}\).
  4. Since \(x \ge 0\), the final count is at least \(\tfrac{588}{64} \approx 9.19\), so at least 10.Why: the final count is a whole number.
  5. x = 52 works: 52 → 13 + 7 = 20 → 5 + 7 = 12 → 3 + 7 = 10.Why: 52, 20 and 12 are all multiples of 4, so every stop is whole.

Conclusion. The smallest possible final count is 10. ∎

Strange Party Lvl 3

At a party, \(\tfrac{5}{12}\) of the people are adults. A bus with 50 people arrives, and now \(\tfrac{11}{25}\) of the people are adults.

Question: what is the smallest possible number of adults before the bus came?

Key idea

Whole numbers of adults force 12 | p and 25 | p + 50, i.e. 300 | p. So p = 300 and there were 125 adults.

Picture

Fractions of people must be whole. \(\tfrac5{12}p\) is whole only if 12 divides p; \(\tfrac{11}{25}(p + 50)\) is whole only if 25 divides p + 50, i.e. 25 divides p. The smallest p is 300, and the bus then has to bring 29 adults, which is possible.

Solution

Setup. p = people before the bus, so \(\tfrac{5p}{12}\) adults. After the bus: p + 50 people, \(\tfrac{11(p+50)}{25}\) adults. The bus brought a adults, \(0 \le a \le 50\).

Claim. 125 adults.

  1. 12 | p.Why: \(\tfrac{5p}{12}\) is a whole number and gcd(5, 12) = 1.
  2. 25 | p.Why: \(\tfrac{11(p+50)}{25}\) is whole and gcd(11, 25) = 1, so 25 | p + 50; and 25 | 50.
  3. 300 | p, so p ≥ 300.Why: steps 1–2; 12 and 25 are coprime, so lcm = 300.
  4. p = 300 is possible: 125 adults before; after the bus 350 people and \(\tfrac{11 \cdot 350}{25} = 154\) adults, so a = 154 − 125 = 29.Why: 0 ≤ 29 ≤ 50, so the bus can carry 29 adults and 21 children.
  5. Adults before = \(\tfrac{5 \cdot 300}{12} = 125\).Why: the number of adults grows with p, and p = 300 is the smallest possible.

Conclusion. At least 125 adults were there before the bus. ∎

⚠ Course never checks that the bus can actually supply the new adults (a = 29 must be between 0 and 50). Step 4 does.

Truth Lvl 4

A sheet has 100 statements. Statement n says: "At most n − 1 of these 100 statements are true."

Question: how many of the statements are true?

Key idea

If T statements are true, then exactly statements T+1, …, 100 are true, which is 100 − T of them. So T = 100 − T.

Picture

Assume a count, then check it against itself. Suppose T are true. Statement n is true exactly when T ≤ n − 1, which holds for n = T+1 to 100: that is 100 − T statements. Only T = 50 matches its own count.

Solution

Setup. S_n = "at most n − 1 of the statements are true", n = 1, …, 100. T = the actual number of true statements.

Claim. T = 50.

  1. S_n is true \(\iff T \le n - 1 \iff n \ge T + 1\).Why: the definition of S_n.
  2. So the true statements are S_{T+1}, …, S_{100}: there are 100 − T of them.Why: step 1.
  3. That count must be T: T = 100 − T, so T = 50.Why: T is the number of true statements.
  4. Check: with T = 50, S_51 to S_100 say "at most 50 to 99 are true", which is correct, and S_1 to S_50 say "at most 0 to 49", which is false. That is 50 true statements.Why: step 1 with T = 50.

Conclusion. Exactly 50 statements are true. ∎

Count Regions I Lvl 5

n straight lines are drawn in the plane. One line makes 2 regions.

Question: what is the largest possible number of regions? Give it for n = 10.

Key idea

The k-th line crosses the earlier k − 1 lines in at most k − 1 points, so it is cut into at most k pieces, and each piece splits one region in two: it adds at most k regions.

Picture

Add the lines one at a time. A new line that crosses every old line at a fresh point is cut into k pieces, and each piece splits a region. Start from 1 region: 1 + 1 + 2 + … + n = 1 + n(n+1)/2. For n = 10 that is 56.

Solution

Setup. R(n) = the largest number of regions made by n lines. R(0) = 1 (the whole plane).

Claim. \(R(n) = 1 + \tfrac{n(n+1)}{2}\), so R(10) = 56.

  1. The k-th line meets each earlier line at most once, so it has at most k − 1 crossing points.Why: two different lines meet in at most one point.
  2. Those points cut the k-th line into at most k pieces, and each piece splits exactly one existing region into two. So the k-th line adds at most k regions.Why: a piece runs through one region from boundary to boundary and divides it.
  3. Equality holds when no two lines are parallel and no three meet at a point.Why: then the k-th line has exactly k − 1 different crossing points, so exactly k pieces.
  4. \(R(n) = 1 + (1 + 2 + \dots + n) = 1 + \tfrac{n(n+1)}{2}\).Why: start from R(0) = 1 and add k for the k-th line (steps 2–3).
  5. \(R(10) = 1 + 55 = 56\).Why: \(\tfrac{10 \cdot 11}{2} = 55\).

Conclusion. 10 lines make at most 56 regions. ∎

Rational Number Lvl 5

a and b are positive integers with \(0.48 \le \tfrac ab \le 0.52\).

Question: for which b does such an a exist? Give the 50th smallest such b.

Key idea

The interval is \(\tfrac12 \pm \tfrac1{50}\). Even b: take a = b/2. Odd b: the closest a/b is \(\tfrac1{2b}\) away from ½, so b ≥ 25.

Picture

How close can a/b get to ½? Exactly, if b is even. If b is odd, 2a − b is odd, so a/b misses ½ by at least 1/(2b), which is within 1/50 only when b ≥ 25. The valid b are 2, 4, …, 24 (twelve of them) and then every b from 25 up, so the 50th is 25 + 37 = 62.

Solution

Setup. b works \(\iff\) some positive integer a has \(\left|\tfrac ab - \tfrac12\right| \le \tfrac1{50}\), because 0.48 = ½ − 1/50 and 0.52 = ½ + 1/50.

Claim. b works \(\iff\) b is even or b ≥ 25; the 50th is 62.

  1. Even b works: a = b/2 gives exactly ½.Why: ½ is inside the interval.
  2. For odd b: \(\left|\tfrac ab - \tfrac12\right| = \tfrac{|2a - b|}{2b} \ge \tfrac{1}{2b}\), with equality at a = (b ± 1)/2.Why: 2a − b is odd, so it is at least 1 in size.
  3. So odd b works \(\iff \tfrac1{2b} \le \tfrac1{50} \iff b \ge 25\).Why: step 2; the best a is available and positive.
  4. The valid b in order: 2, 4, …, 24 (12 values), then 25, 26, 27, … (all of them).Why: steps 1 and 3.
  5. The 50th is the 38th number from 25 on: 25 + 37 = 62.Why: 50 − 12 = 38.

Conclusion. The 50th smallest valid b is 62. ∎

3 Consecutive Heads II Lvl 2

A fair coin is flipped 6 times. "Exactly 3 consecutive heads" means some block of heads has length exactly 3: HHHTTT and HHHTHH count, HHTHHT and HHHHTT do not.

Question: what is the probability of getting exactly 3 consecutive heads at some point?

Key idea

Choose where the block of 3 starts (4 places). Its neighbours must be T; the other flips are free.

Picture

Place the block, fence it with tails, fill the rest freely. Start 1: HHHT + 2 free flips = 4. Start 2: THHHT + 1 free = 2. Start 3: 2 by the same count. Start 4: 4. Two such blocks would need 3 + 1 + 3 = 7 flips, so no sequence is counted twice: 12 of 64.

Solution

Setup. 6 fair flips: all \(2^6 = 64\) sequences are equally likely. A good sequence has a maximal block of heads of length exactly 3, starting at flip \(s \in \{1, 2, 3, 4\}\).

Claim. \(P = \tfrac{12}{64} = \tfrac{3}{16} = 0.1875\).

  1. A block of exactly 3 heads at flips \(s, s+1, s+2\) means: those three are H, and flip \(s-1\) (if it exists) and flip \(s+3\) (if it exists) are T.Why: otherwise the block would be longer than 3.
  2. A sequence cannot have two such blocks.Why: two blocks of 3 plus the T between them need at least 7 flips.
  3. \(s = 1\): HHHT, then flips 5 and 6 are free: \(2^2 = 4\).Why: step 1; there is no flip 0.
  4. \(s = 2\): THHHT, then flip 6 is free: 2.Why: step 1 fixes flips 1 to 5.
  5. \(s = 3\): flip 2 is T, flips 3–5 are H, flip 6 is T, and flip 1 is free: 2.Why: the mirror image of \(s = 2\).
  6. \(s = 4\): flip 3 is T, flips 4–6 are H, flips 1 and 2 are free: 4.Why: the mirror image of \(s = 1\).
  7. \(P = \tfrac{4 + 2 + 2 + 4}{64} = \tfrac{12}{64} = \tfrac{3}{16}\).Why: the four cases are disjoint (step 2) and cover every good sequence; favourable over equally likely.

Conclusion. The probability is \(\tfrac{3}{16} = 0.18750\). ∎

⚠ Course says that for the block at flips 2–4, "the 1st and 5th spots must be heads". They must be tails (step 1); the count of 2 is still right.

Increasing Birthdays Lvl 2

Seven people, all of different ages, sit at random around a circular table with 7 seats.

Question: what is the probability that the ages increase all the way round, either clockwise or counterclockwise?

Key idea

Wherever the youngest sits, the other six seats are forced, and there are 2 directions: 7 × 2 good seatings out of 7!.

Picture

Fix the youngest, then everything is forced. Put the youngest in any of the 7 seats. "Increasing clockwise" now fixes all 6 remaining seats, and so does "increasing counterclockwise". That gives 14 good seatings out of 5040.

Solution

Setup. Number the seats 0 to 6 clockwise. A random seating is one of the \(7! = 5040\) equally likely assignments of people to seats.

Claim. \(P = \tfrac{1}{360} \approx 0.00278\).

  1. Seatings with ages increasing clockwise: the youngest can be in any of the 7 seats, and then the \(k\)-th youngest must be \(k-1\) seats clockwise from them. That is 7 seatings.Why: each later person's seat is forced by the one before.
  2. Increasing counterclockwise: 7 more seatings, by the same argument.Why: the mirror image of step 1.
  3. No seating is both.Why: clockwise puts the second youngest 1 seat clockwise of the youngest, and counterclockwise puts them 1 seat counterclockwise. With 7 seats these are different seats.
  4. \(P = \tfrac{7 + 7}{5040} = \tfrac{14}{5040} = \tfrac{1}{360}\).Why: favourable over equally likely; \(5040 / 14 = 360\).

Conclusion. The probability is \(\tfrac{1}{360} \approx 0.00278\). ∎

Grid Arrangement IV Lvl 4

The numbers 1 to 9 are placed at random in a 3 × 3 grid, one per cell.

Question: what is the probability that every row sum and every column sum is odd?

Key idea

Only parity matters: five odd numbers, four even. All six sums are odd exactly when the odd numbers fill a full row plus a full column (a "cross"): 9 crosses out of \(\binom95 = 126\) patterns.

Picture

Mark the 5 odd numbers as 1s. Each row needs 1 or 3 of them, and five 1s across three rows can only split as 3 + 1 + 1. The same holds for columns. The lone 1s in the other rows must sit in the full column, so the 1s form a cross: 3 rows × 3 columns = 9 choices.

Solution

Setup. Replace each number by its parity: five 1s (the odd numbers 1, 3, 5, 7, 9) and four 0s. Every set of 5 cells for the 1s is equally likely: there are \(\binom95 = 126\) of them, each coming from 5! · 4! placements.

Claim. \(P = \tfrac{9}{126} = \tfrac{1}{14} \approx 0.07143\).

  1. A row sum is odd \(\iff\) the row has 1 or 3 odd numbers.Why: the sum's parity is the number of odd entries mod 2.
  2. The rows hold 3, 1, 1 odd numbers in some order.Why: each row has 1 or 3 (step 1) and they add to 5; 1+1+1 = 3 and 3+3+1 = 7, so only 3+1+1 works.
  3. Likewise one column is all odd and the other two have one each.Why: step 2 for columns.
  4. Let R be the full row and C the full column. C has an odd number in every row. The two rows other than R have only one odd number each, so it is the one in column C. The odd cells are exactly row R plus column C.Why: steps 2 and 3; 3 + 3 − 1 = 5 cells.
  5. Every cross (R, C) works: row R has 3 odd numbers, the other rows 1 each; column C has 3, the others 1 each. There are 3 · 3 = 9 crosses.Why: check each line against step 1.
  6. \(P = \tfrac{9}{126} = \tfrac{1}{14}\).Why: favourable over equally likely parity patterns.

Conclusion. The probability is \(\tfrac{1}{14} \approx 0.07143\). ∎

Bulbs In A Grid Lvl 5

A 3 × 3 grid of light bulbs; each bulb is on with probability ½, independently.

Question: what is the probability that no two side-by-side bulbs are both on?

Key idea

Split on the centre bulb. Centre on: its 4 neighbours are off and the 4 corners are free (16). Centre off: the 8 outer bulbs form a ring, and a ring of 8 has 47 good patterns. 63 of 512.

Picture

The centre touches four bulbs; the rest is a ring. With the centre on, only the corners are left and none of them touch each other: 2⁴ = 16. With the centre off, the outer 8 bulbs go round in a circle: count on/off patterns of a ring of 8 with no two neighbours on.

Solution

Setup. All \(2^9 = 512\) on/off patterns are equally likely. A pattern is good if no two bulbs sharing a side are both on. \(a_k\) = the number of good patterns of a row (path) of k bulbs.

Claim. \(P = \tfrac{63}{512} \approx 0.12305\).

  1. \(a_1 = 2\), \(a_2 = 3\), and \(a_k = a_{k-1} + a_{k-2}\).Why: Form 1 along the row: the last bulb is off (any good row of k − 1 before it), or on (then the one before is off, and any good row of k − 2 before that).
  2. \(a_3 = 5, a_4 = 8, a_5 = 13, a_6 = 21, a_7 = 34\).Why: step 1, one term at a time.
  3. Centre on: its 4 side-neighbours must be off; the 4 corners touch only those neighbours, so they are free: \(2^4 = 16\) patterns.Why: a corner's two neighbours are both edge-middle bulbs, which are off.
  4. Centre off: the 8 outer bulbs form a ring (1-2-3-6-9-8-7-4-1). Ring bulb 1 off: the other 7 form a row, \(a_7 = 34\). Ring bulb 1 on: its two ring neighbours are off, and the other 5 form a row, \(a_5 = 13\). Total 47.Why: removing one bulb from a ring leaves a row; step 2.
  5. \(P = \tfrac{16 + 47}{512} = \tfrac{63}{512}\).Why: the two cases are disjoint; favourable over equally likely.

Conclusion. The probability is \(\tfrac{63}{512} \approx 0.12305\). ∎

1 Leftward Jump Lvl 6

Seven stones in a row are numbered 1 to 7. A frog starts on stone 1 and visits every other stone exactly once, in a uniformly random order.

Question: what is the probability that exactly one of its jumps goes to the left?

Key idea

Array + bitmask. Put the stones left to visit in a sorted array a = {2,3,4,5,6,7}. A path with one left jump is A sorted, then B sorted. Pick A with a bitmask: 2⁶ = 64 masks, and B is whatever is left, so it's forced. Keep the mask only if the joint drops: A.back() > B.front(). The only masks that fail are the 7 prefix masks, so 64 − 7 = 57, and the answer is 57/720.

Picture

Two climbs, one drop, checked at one joint. Both halves are sorted, so every step inside a half goes right. The only step that can go left is A.back() → B.front(). The first jump 1 → anything always goes right, because 1 is the smallest stone.

Solution

Setup. a = {2,3,4,5,6,7}, n = 6. The path is 1 followed by a uniformly random order of a: 6! = 720 equally likely orders. A left jump is a step to a smaller number.

Claim. \(P = \tfrac{57}{720} = \tfrac{19}{240} \approx 0.0792\).

  1. SHAPE. An order with exactly one left jump is two increasing runs: A sorted, then B sorted.Why: between drops the path only climbs, and there is one drop.
  2. ENCODE. Choose A with a mask over a; B is the complement. Walking a in index order and pushing each element into A or B gives both already sorted. That is 2⁶ = 64 masks, and each mask builds exactly one order A + B.Why: there's one way to sort A and one way to sort B, so B adds no choices.
  3. CHECK. The order has one left jump ⇔ A and B are both non-empty and A.back() > B.front().Why: every step inside a sorted half goes right, so the joint is the only candidate. If there's no joint, or the joint climbs, the order is just 2 3 4 5 6 7.
  4. BAD MASKS. The check fails exactly for the prefix masks A = a[0..k-1], k = 0, …, 6: ∅, {2}, {2,3}, …, {2,…,7}. That is 7 masks, and all of them build 2 3 4 5 6 7.Why: A.back() < B.front() means everything in A is smaller than everything in B. In a sorted array that means A is a prefix.
  5. NO DOUBLE COUNT. Any order with one left jump gives back exactly one mask: A = everything before the drop.Why: the drop position is unique, so the split is unique.
  6. COUNT. 64 − 7 = 57 good orders, so \(P = \tfrac{57}{720}\).Why: favourable over equally likely.

Code (brute force over masks; it prints 57/720):

#include <bits/stdc++.h>
using namespace std;
int main() {
    vector<int> a = {2, 3, 4, 5, 6, 7};
    int n = a.size(), good = 0;
    for (int mask = 0; mask < (1 << n); mask++) {
        vector<int> A, B;                          // a is sorted, so A and B come out sorted
        for (int i = 0; i < n; i++) (mask >> i & 1 ? A : B).push_back(a[i]);
        if (!A.empty() && !B.empty() && A.back() > B.front()) good++;   // one drop, at the joint
    }
    int total = 720;                               // 6!
    cout << good << "/" << total << endl;          // 57/720
}

  4. \(r_{t+1} - r_t = -\tfrac{t^2 + 63t + 110}{2(t+31)(t+32)}\): positive up to t = −2, negative from t = −1. So t = −1 is best.Why: \(t^2 + 63t + 110 < 0\) for −61.2 < t < −1.8.
  5. \(r_{-1} = \tfrac{9 \cdot 12}{2 \cdot 30} = \tfrac95\), and indeed accepting k ≥ −1 means k ≥ −r = −1.8.Why: consistent with step 2: accept exactly when k beats −r.

Answer. A accepts any roll of −1 or more; A's expected return is \(\tfrac95 = 1.8\). ∎

Deck Choice I Lvl 6

You write numbers from 1 to 100 (repeats allowed) on 100 cards. A friend sees the deck and names n. The top card of the shuffled deck is shown; if it is n, you pay n, otherwise nothing.

Question: with the best deck, what is the friend's best expected payout?

Key idea

With \(k_n\) cards showing n, the friend gets \(\max_n \tfrac{n k_n}{100}\). Bound each \(k_n \le \lfloor M/n \rfloor\); the smallest M with \(\sum_n \lfloor M/n \rfloor \ge 100\) is 28, so 0.28.

Picture

Make every number equally unattractive. Cap each number's "value" n·k_n at M. The caps allow \(\sum \lfloor M/n \rfloor\) cards; you need 100 cards. At M = 27 the caps allow only 95; at M = 28 they allow 101.

Solution

Setup. \(k_n\) = number of cards showing n, \(\sum k_n = 100\). Naming n pays \(\tfrac{n k_n}{100}\) on average. M = \(\max_n n k_n\).

Claim. 0.28.

  1. Every n has \(n k_n \le M\), so \(k_n \le \lfloor M/n \rfloor\) and \(100 \le \sum_{n=1}^{100}\lfloor M/n \rfloor\).Why: \(k_n\) is a whole number.
  2. \(\sum_n \lfloor 27/n \rfloor = 95 < 100\), so M ≥ 28.Why: step 1 fails at M = 27.
  3. M = 28 is possible: \(k_n = \lfloor 28/n \rfloor\) for n ≤ 28 gives 101 cards; remove one card showing 1.Why: removing a card only lowers \(n k_n\).
  4. The friend's best payout is \(\tfrac{28}{100} = 0.28\).Why: the friend gets \(\tfrac{M}{100}\) with the smallest possible M.

Conclusion. The friend can get at most 0.28. ∎

Deck Choice II Lvl 6

You build a deck of any size with labels from 1–5 (repeats allowed; not all labels needed). The opponent sees it and names i. A random card is drawn; if it shows i you pay i.

Question: how should you build the deck, and what is your expected loss?

Key idea

With proportions \(p_i\), the opponent takes \(\max_i i p_i = M\). From \(p_i \le M/i\) and \(\sum p_i = 1\): \(M \ge 1/(1 + \tfrac12 + \dots + \tfrac15) = \tfrac{60}{137}\), achieved by counts 60 : 30 : 20 : 15 : 12.

Picture

Make every bet pay the same. Put fewer high cards: proportions ∝ 1/i make every i·p_i equal. Here the deck size is free, so the cap is exact (unlike Deck Choice I). A uniform deck would let the opponent name 5 and take 1 per game.

Solution

Setup. \(p_i\) = fraction of cards labelled i; naming i costs you \(i p_i\) on average. M = \(\max_i i p_i\).

Claim. Counts 60, 30, 20, 15, 12 (137 cards); loss \(\tfrac{60}{137} \approx 0.43796\).

  1. \(p_i \le M/i\) for every i, so \(1 = \sum p_i \le M\big(1 + \tfrac12 + \tfrac13 + \tfrac14 + \tfrac15\big) = M\cdot\tfrac{137}{60}\).Why: the proportions add to 1.
  2. So \(M \ge \tfrac{60}{137}\).Why: divide by \(\tfrac{137}{60}\).
  3. Counts 60, 30, 20, 15, 12 out of 137 give \(i p_i = \tfrac{60}{137}\) for every i.Why: 1·60 = 2·30 = 3·20 = 4·15 = 5·12 = 60.

Conclusion. Use proportions 1 : ½ : ⅓ : ¼ : ⅕; the expected loss is \(\tfrac{60}{137} \approx 0.43796\). ∎

Dice Placement I Lvl 6

A die is rolled 3 times. After each roll you must place it in the hundreds, tens or units place (each used once, no moving later). You win the 3-digit number.

Question: what is the best strategy and its expected value?

Key idea

Work backwards. With two places left, put the roll in the bigger place iff it is ≥ 4 (above the mean 3.5). First roll: 5–6 → hundreds, 3–4 → tens, 1–2 → units. Value 504.

Picture

Compare each roll with what you expect later. The last roll is worth 3.5 on average. With two places left, a roll above 3.5 deserves the bigger place. For the first roll, compare its three placements using the two-place value.

Solution

Form 1 (i → end) · Level = roll i; state = the places still free. Base case: no places left, value 0.

  1. Two places a > b left, roll x: big place gives \(ax + \tfrac72 b\), small place gives \(bx + \tfrac72 a\). Big is better \(\iff (a - b)(x - \tfrac72) \ge 0 \iff x \ge 4\).Why: the last roll averages 7/2.
  2. Value of two places: \(\tfrac16\big[\sum_{x=1}^3 (bx + \tfrac72a) + \sum_{x=4}^6 (ax + \tfrac72b)\big] = \tfrac{17a + 11b}{4}\).Why: 1 + 2 + 3 = 6, 4 + 5 + 6 = 15: \(\tfrac16(6b + \tfrac{21}2a + 15a + \tfrac{21}2 b)\).
  3. First roll x: hundreds \(100x + \tfrac{181}{4}\); tens \(10x + \tfrac{1711}{4}\); units \(x + \tfrac{1810}{4}\).Why: step 2 with (a, b) = (10, 1), (100, 1), (100, 10).
  4. Units is best for x = 1, 2; tens for x = 3, 4; hundreds for x = 5, 6.Why: units beats tens iff 9x < 24.75 (x ≤ 2); tens beats hundreds iff 90x < 382.5 (x ≤ 4).
  5. \(E = \tfrac16\big[(1 + 2) + 2\cdot\tfrac{1810}{4} + (30 + 40) + 2\cdot\tfrac{1711}{4} + (500 + 600) + 2\cdot\tfrac{181}{4}\big] = \tfrac16(1173 + 1851) = 504\).Why: \(\tfrac{2(1810 + 1711 + 181)}{4} = 1851\).

Answer. Expected value 504 with the rule above. ∎

Card Prediction II Lvl 6

A shuffled deck of 26 red and 26 black cards is turned over one card at a time. At any moment with at least 2 cards left you may stop and name a colour; you win if the next two cards are both that colour.

Question: what is the best strategy and its winning probability?

Key idea

Stopping now and naming red wins with P(next two red) = P(last two red), since the remaining cards are in random order. So every strategy is a bet on the last two cards, and the best you can do is win when they match: 25/51.

Picture

The next two cards are no better than the last two. Whatever you have seen, the unseen cards are shuffled, so "the next two" and "the last two" have the same distribution. Waiting to the end and naming the colour of the final two (when they match) is optimal.

Solution

Setup. At any time, r red and b black cards remain, in uniformly random order.

Claim. Wait until 2 cards remain; name their colour if they match. P = \(\tfrac{25}{51} \approx 0.49020\).

  1. Stopping now and naming red wins with \(\tfrac{r(r-1)}{(r+b)(r+b-1)}\) = P(the last two cards of the deck are red).Why: the remaining cards are in random order, so any two fixed positions have the same distribution.
  2. So any strategy wins exactly when the last two cards of the deck are both the colour it names, which is at most P(the last two cards match).Why: step 1 at every stopping time: the win chance equals that of a bet on the last two cards.
  3. Waiting to the end achieves this bound: with 2 cards left you have seen the other 50, so you know both. If they match, name their colour and win.Why: 26 − (reds seen) and 26 − (blacks seen) tell you the last two exactly.
  4. P(the last two match) = \(\tfrac{2\binom{26}{2}}{\binom{52}{2}} = \tfrac{2\cdot325}{1326} = \tfrac{25}{51}\).Why: the last two cards are a uniform pair of the 52.

Conclusion. No strategy beats \(\tfrac{25}{51} \approx 0.49020\), and waiting to the end achieves it. ∎

⚠ Course compares stopping now with waiting to the end and then says "the same comparison applies at every stage", which does not rule out cleverer mixed stopping rules. Step 2 does: every stopping rule is a bet on the last two cards.

You stop at about 45, which takes about 45/5 = 9 safe rolls. You survive 9 rolls with \(0.9^9 \approx 0.39\), so the value is about 45 × 0.39 ≈ 17.5 (exact 17.68).

Five Light Bulbs Lvl 4

Five light bulbs are all off. Every second, one of the five bulbs is chosen at random and switched (off becomes on, on becomes off).

Question: starting from all off, what is the expected number of seconds until all five are off again?

Key idea

Return-time recipe (works for any "how long until it comes back to where it started" question): (1) name the states, (2) find the long-run share of time \(\pi_s\) spent in the start state, (3) Kac: expected return time \(= 1/\pi_s\). The only real work is step 2, and a symmetry shortcut usually does it.

Picture

Why every pattern gets the same share. Put 1000 walkers on each of the 32 patterns and let every walker take one step. A pattern sends its 1000 walkers out, 200 to each of its 5 neighbours. It also receives 200 from each of its 5 neighbours: 1000 back in. Every pattern still holds 1000, so "all 32 equally likely" never changes. That is what stationary means: \(\pi_s = \tfrac1{32}\).

Why share \(\tfrac1{32}\) means return time 32 (Kac). In a long run of \(T\) seconds you are at all-off about \(T/32\) times. \(T/32\) visits spread over \(T\) seconds means the gaps between visits average \(32\).

Solution

  1. STATES. The state is the on/off pattern of the 5 bulbs: \(N = 2^5 = 32\) states. Start state \(s\) = all off.Why: the pattern is all the future depends on.
  2. MOVES. From any state the chain moves to one of the 5 patterns that differ in exactly one bulb, each with probability \(\tfrac15\). Every move can be undone.Why: one of 5 bulbs is chosen uniformly; toggling the same bulb again returns to the start.
  3. \(\pi\) SHORTCUT. Check: do the arrows into each state carry total probability 1? Here each state has 5 incoming arrows of \(\tfrac15\): \(5 \cdot \tfrac15 = 1\). So the uniform \(\pi_j = \tfrac1N\) is stationary: \((\pi P)_j = \sum_{i \sim j}\tfrac{1}{32}\cdot\tfrac15 = \tfrac{1}{32}\cdot5\cdot\tfrac15 = \tfrac{1}{32}\).Why: inflow to \(j\) = \(\tfrac1N \times\) (sum of incoming probabilities) = \(\tfrac1N \times 1\) = what \(j\) already had. If the check fails but the move is "go to a uniformly random neighbour" on a graph, use \(\pi_v = d_v / \sum_u d_u\) instead (degree over total degree).
  4. KAC. The chain is irreducible, so the expected return time to all-off is \(1/\pi_s = \) \(32\) seconds.Why: any pattern reaches any other by toggling the bulbs where they differ; Kac needs that, otherwise \(\pi\) is not unique.

Conclusion. It takes 32 seconds on average to return to all-off. ∎
