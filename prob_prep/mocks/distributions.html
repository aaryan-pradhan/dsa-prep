1 · Uniform

U1 · Max of Three Uniforms Lvl 2

(MIT 18.600 S2011 Midterm 2 #2) Let X₁, X₂, and X₃ be independent uniform random variables on [0, 1].

Question: (a) Write X = max{X₁, X₂, X₃}. Compute P{X ≤ a} for a ∈ [0, 1]. (b) Compute the probability density function for X on the interval [0, 1]. (c) Compute the variance of the first variable X₁. (d) Compute the following covariance: Cov(X₁ + X₂, X₂ + X₃).

Key idea

A max is ≤ a iff every variable is ≤ a: multiply. Covariance is bilinear, and independent pairs contribute 0.

Picture

All three must land below a. Each does with chance a, so the chance is a³; its slope 3a² is the density.

Solution

Claim. (a) a³ · (b) 3a² · (c) 1/12 · (d) 1/12.

  1. \(P\{X \le a\} = P\{X_1 \le a\}\,P\{X_2 \le a\}\,P\{X_3 \le a\} = a^3\).Why: max ≤ a iff all three are ≤ a; independence.
  2. \(f_X(a) = \tfrac{d}{da} a^3 = 3a^2\).Why: the density is the derivative of the CDF.
  3. \(\text{Var}(X_1) = E[X_1^2] - E[X_1]^2 = \tfrac13 - \tfrac14 = \tfrac1{12}\).Why: \(E[X_1^2] = \int_0^1 x^2\,dx = \tfrac13\).
  4. \(\text{Cov}(X_1 + X_2, X_2 + X_3) = \text{Cov}(X_2, X_2) = \text{Var}(X_2) = \tfrac1{12}\).Why: expand bilinearly; the other three terms pair independent variables, so they are 0.

Answer. a³, 3a², 1/12, 1/12. ∎

U2 · Min of n Uniforms Lvl 2

(MIT 18.600 F2012 Midterm 2 #3) Suppose that X₁, X₂, …, Xₙ are independent uniform random variables on [0, 1].

Question: (a) Write Y = min{X₁, X₂, …, Xₙ}. Compute the cumulative distribution function F_Y(a) and the density function f_Y(a) for a ∈ [0, 1]. (b) Compute P(X₁ < .3) and P(max{X₁, X₂, …, Xₙ} < .3). (c) Compute the expectation E[X₁ + X₂ + … + Xₙ].

Key idea

For a min, go through the complement: min > a iff all are > a, chance (1 − a)ⁿ.

Picture

The min is small unless every variable is big. Shown for n = 5: the CDF rises fast and the density piles up near 0.

Solution

Claim. (a) 1 − (1 − a)ⁿ and n(1 − a)ⁿ⁻¹ · (b) 0.3 and 0.3ⁿ · (c) n/2.

  1. \(F_Y(a) = 1 - P\{\text{all } X_i > a\} = 1 - (1-a)^n\).Why: min > a iff every \(X_i > a\); independence.
  2. \(f_Y(a) = n(1-a)^{n-1}\).Why: differentiate \(F_Y\).
  3. \(P(X_1 < .3) = 0.3\); \(P(\max < .3) = 0.3^n\).Why: max < .3 iff all are.
  4. \(E[X_1 + \dots + X_n] = n \cdot \tfrac12\).Why: linearity.

Answer. 1 − (1 − a)ⁿ, n(1 − a)ⁿ⁻¹, 0.3, 0.3ⁿ, n/2. ∎

U3 · Coin-Chosen Numbers Lvl 4

(AMC 12A 2019 #20) Real numbers between 0 and 1, inclusive, are chosen in the following manner. A fair coin is flipped. If it lands heads, then it is flipped again and the chosen number is 0 if the second flip is heads and 1 if the second flip is tails. On the other hand, if the first coin flip is tails, then the number is chosen uniformly at random from the closed interval [0, 1]. Two random numbers x and y are chosen independently in this manner.

Question: what is the probability that |x − y| > 1/2? (A) 1/3 (B) 7/16 (C) 1/2 (D) 9/16 (E) 2/3

Key idea

Each number is 0 (¼), 1 (¼) or uniform (½). Split into three cases: both fixed, one fixed, both uniform.

Picture

A fixed number sits at an end. Against an endpoint, a uniform number is more than ½ away half the time. Two uniforms are more than ½ apart in two corner triangles of total area ¼.

Solution

Setup. Each number is 0 w.p. ¼, 1 w.p. ¼, uniform on [0, 1] w.p. ½.

Claim. 7/16 (B).

  1. Both fixed (prob ¼): succeed iff one is 0 and one is 1: \(2 \cdot \tfrac14 \cdot \tfrac14 = \tfrac18\).Why: 0 vs 0 or 1 vs 1 gives distance 0.
  2. One fixed, one uniform (prob ½): succeed w.p. ½, contributing \(\tfrac14\).Why: the fixed one is 0 or 1; the uniform one lands in the far half.
  3. Both uniform (prob ¼): \(P(|U - V| > \tfrac12) = 2 \cdot \tfrac12\cdot\tfrac12\cdot\tfrac12 = \tfrac14\), contributing \(\tfrac1{16}\).Why: two corner triangles of the unit square, legs ½.
  4. \(\tfrac18 + \tfrac14 + \tfrac1{16} = \tfrac7{16}\).Why: law of total probability over the cases.

Answer. 7/16 (B). ∎

U4 · Zigzag Subsequence Lvl 7

(Putnam 2023 B3) A sequence y₁, y₂, …, yₖ of real numbers is called zigzag if k = 1, or if y₂ − y₁, y₃ − y₂, …, yₖ − yₖ₋₁ are nonzero and alternate in sign. Let X₁, X₂, …, Xₙ be chosen independently from the uniform distribution on [0, 1]. Let a(X₁, X₂, …, Xₙ) be the largest value of k for which there exists an increasing sequence of integers i₁, i₂, …, iₖ such that X_{i₁}, X_{i₂}, …, X_{iₖ} is zigzag.

Question: find the expected value of a(X₁, X₂, …, Xₙ) for n ≥ 2.

Key idea

Longest zigzag = 2 + number of turning points (interior local max/min). Indicators: each interior point turns with chance 2/3.

Picture

Keep the ends and every turn. Between two turns the sequence is monotone, so nothing else can help. Shown for n = 10: E = 22/3.

Solution

Setup. Values are distinct w.p. 1. \(I_i = 1\) if \(X_i\) (2 ≤ i ≤ n − 1) is a local max or local min of its neighbours.

Claim. \(\tfrac{2n+2}{3}\).

  1. \(a \ge 2 + \sum I_i\).Why: X₁, every turning point, Xₙ alternate.
  2. \(a \le 2 + \sum I_i\).Why: a zigzag peak \(y_{j-1} < y_j > y_{j+1}\) forces the max of the original over positions \(i_{j-1} … i_{j+1}\) to be strictly inside, so it is a local max (valleys: local min). Peaks at j and j + 2 use disjoint ranges, so the k − 2 inner terms need k − 2 distinct turning points.
  3. \(P(I_i = 1) = \tfrac23\).Why: the 6 orders of \(X_{i-1}, X_i, X_{i+1}\) are equally likely; the middle is the max in 2 and the min in 2.
  4. \(E[a] = 2 + (n-2)\cdot\tfrac23 = \tfrac{2n+2}{3}\).Why: linearity (the \(I_i\) need not be independent).

Answer. \(\tfrac{2n+2}{3}\). ∎

2 · Poisson

P1 · Jill Goes Fishing Lvl 2

(MIT 18.600 F2011 Midterm 1 #1) Jill goes fishing. During each minute she fishes, there is a 1/600 chance that she catches a fish (independently of all other minutes). Assume that she fishes for 15 hours (900 minutes). Let N be the total number of fish she catches.

Question: (a) Compute E[N] and Var[N]. (Give exact answers, not approximate ones.) (b) Compute the probability she catches exactly 3 fish. Give an exact answer. (c) Now use a Poisson random variable calculation to approximate the probability that she catches exactly 3 fish.

Key idea

N ~ Binomial(900, 1/600). Many trials, tiny p → Poisson with λ = np = 3/2.

Picture

Rare events over many minutes. The exact binomial 0.12556 and the Poisson 0.12551 agree to 4 decimals.

Solution

Claim. (a) 3/2, 599/400 · (b) \(\binom{900}{3}(\tfrac1{600})^3(\tfrac{599}{600})^{897}\) · (c) \(\tfrac9{16}e^{-3/2} \approx 0.1255\).

  1. \(E[N] = 900\cdot\tfrac1{600} = \tfrac32\), \(\text{Var}[N] = 900\cdot\tfrac1{600}\cdot\tfrac{599}{600} = \tfrac{599}{400}\).Why: binomial mean np, variance np(1 − p).
  2. \(P(N=3) = \binom{900}{3}(\tfrac1{600})^3(\tfrac{599}{600})^{897} \approx 0.12556\).Why: choose the 3 lucky minutes.
  3. \(P(N=3) \approx e^{-3/2}\tfrac{(3/2)^3}{3!} = \tfrac9{16}e^{-3/2} \approx 0.12551\).Why: Poisson(λ = np = 3/2).

Answer. 3/2, 599/400; ≈ 0.12556; ≈ 0.12551. ∎

P2 · Rachel's Ideas Lvl 3

(MIT 18.600 F2012 Midterm 2 #4) Aspiring writer Rachel decides to lock herself in her room to think of screenplay ideas. When Rachel is thinking, the moments at which good new ideas occur to her form a Poisson process with parameter λ_G = .5/hour. The times when bad new ideas occur to her are a Poisson point process with parameter λ_B = 1.5 per hour.

Question: (a) Let T be the amount of time until Rachel has her first idea (good or bad). Write down the probability density function for T. (b) Compute the probability that Rachel has exactly 3 bad ideas total during her first hour of thinking. (c) Let S be the amount of time elapsed before the fifth good idea occurs. Compute Var(S). (d) What is the probability that Rachel has no ideas at all during her first three hours of thinking?

Key idea

Independent Poisson processes merge (rates add). Gaps are Exp(λ), variance 1/λ²; the k-th arrival is a sum of k gaps.

Picture

The 5th good idea = five Exp(½) gaps. Each gap has mean 2 h and variance 4, so S has mean 10 h and variance 20. The sim averages (S − 10)².

Solution

Claim. (a) \(2e^{-2t}\) · (b) \(\tfrac9{16}e^{-3/2}\) · (c) 20 · (d) \(e^{-6}\).

  1. All ideas form a Poisson process of rate 0.5 + 1.5 = 2, so \(T \sim \text{Exp}(2)\): \(f_T(t) = 2e^{-2t}\), t ≥ 0.Why: merging independent Poisson processes adds rates.
  2. Bad ideas in 1 hour ~ Poisson(1.5): \(e^{-1.5}\tfrac{1.5^3}{3!} = \tfrac9{16}e^{-3/2}\).Why: count in time t is Poisson(λt).
  3. \(S = G_1 + \dots + G_5\), \(G_k \sim \text{Exp}(0.5)\) independent: \(\text{Var}(S) = 5 \cdot \tfrac1{0.5^2} = 20\).Why: variances of independent gaps add.
  4. Ideas in 3 hours ~ Poisson(2 · 3 = 6): \(P(0) = e^{-6}\).Why: merged rate 2.

Answer. 2e^{−2t}; (9/16)e^{−3/2}; 20; e^{−6}. ∎

P3 · Harry's Messages Lvl 3

(MIT 18.600 F2012 Final #4) When Harry's cell phone is on, the times when he receives new text messages form a Poisson process with parameter λ_T = 3/minute. The times at which he receives new email messages form an independent Poisson process with parameter λ_E = 1/minute. He receives personal messages on Facebook as an independent Poisson process with rate λ_F = 2/minute.

Question: (a) After catching up on existing messages one morning, Harry begins to wait for new messages to arrive. Let X be the amount of time (in minutes) that Harry has to wait to receive his first text message. Write down the probability density function for X. (b) Compute the probability that Harry receives 10 new messages total (including email, text, and Facebook) during his first two minutes of waiting. (c) Let Y be the amount of time elapsed before the third email message. Compute Var(Y). (d) What is the probability that Harry receives no messages of any kind during his first five minutes of waiting?

Key idea

Same toolkit as P2: merge (3 + 1 + 2 = 6/min), count ~ Poisson(λt), k-th arrival = sum of k Exp gaps.

Picture

Two minutes at rate 6 = Poisson(12). Exactly 10 has chance ≈ 0.1048.

Solution

Claim. (a) \(3e^{-3x}\) · (b) \(e^{-12}\tfrac{12^{10}}{10!}\) · (c) 3 · (d) \(e^{-30}\).

  1. \(X \sim \text{Exp}(3)\): \(f_X(x) = 3e^{-3x}\), x ≥ 0.Why: first arrival of a rate-3 process.
  2. Total rate 6, over 2 minutes λ = 12: \(P = e^{-12}\tfrac{12^{10}}{10!} \approx 0.1048\).Why: merging adds rates.
  3. \(Y\) = sum of 3 Exp(1) gaps: \(\text{Var}(Y) = 3 \cdot 1 = 3\).Why: Exp(1) has variance 1/1² = 1.
  4. Poisson(6 · 5 = 30): \(P(0) = e^{-30}\).Why: no arrival in 5 minutes at rate 6.

Answer. 3e^{−3x}; e^{−12}12¹⁰/10! ≈ 0.1048; 3; e^{−30}. ∎

P4 · Cutting the String Lvl 7

(HMMT Feb 2016 Guts #29) Katherine has a piece of string that is 2016 millimeters long. She cuts the string at a location chosen uniformly at random, and takes the left half. She continues this process until the remaining string is less than one millimeter long.

Question: what is the expected number of cuts that she makes? (Uniform in the statement, Poisson process in the solution. Find the bridge.)

Key idea

Take logs: −ln U ~ Exp(1). The log-length drops by Exp(1) steps, i.e. the arrivals of a rate-1 Poisson process, until it has dropped by ln 2016.

Picture

Multiplying by uniforms = subtracting exponentials. Cuts = (arrivals in [0, ln 2016]) + 1, mean 1 + ln 2016 ≈ 8.609.

Solution

Setup. After k cuts the length is \(2016\,U_1U_2\cdots U_k\), \(U_i\) uniform on [0, 1]. \(E_i = -\ln U_i\).

Claim. \(1 + \ln 2016 \approx 8.609\).

  1. \(E_i \sim \text{Exp}(1)\).Why: \(P(E_i > t) = P(U_i < e^{-t}) = e^{-t}\).
  2. Length after k cuts < 1 ⟺ \(E_1 + \dots + E_k > \ln 2016\).Why: take ln of \(2016\,U_1\cdots U_k < 1\).
  3. The partial sums \(E_1, E_1 + E_2, …\) are the arrival times of a rate-1 Poisson process, so cuts = (arrivals in [0, ln 2016]) + 1.Why: she stops at the first arrival past ln 2016.
  4. \(E[\text{cuts}] = 1 + \ln 2016\).Why: arrivals in an interval of length ln 2016 ~ Poisson(ln 2016).

Answer. 1 + ln 2016 ≈ 8.609. ∎

3 · Normal

N1 · 18000 Die Rolls Lvl 2

(MIT 18.600 F2012 Midterm 2 #1) Suppose that a fair die is rolled 18000 times. Each roll turns up a uniformly random member of the set {1, 2, 3, 4, 5, 6} and the rolls are independent of each other. Let X be the total number of times the die comes up 1.

Question: (a) Compute Var(X). (b) Use a normal random variable approximation to estimate the probability that X < 2900. You may use the function Φ(a) in your answer.

Key idea

Binomial(18000, 1/6) ≈ Normal(3000, 50²). 2900 is 2 SDs below the mean.

Picture

Count in standard deviations. Mean 3000, SD √2500 = 50, so 2900 sits at z = −2: about 2.3% of the time.

Solution

Claim. (a) 2500 · (b) Φ(−2) ≈ 0.0228.

  1. \(\text{Var}(X) = 18000\cdot\tfrac16\cdot\tfrac56 = 2500\).Why: binomial np(1 − p).
  2. \(P(X < 2900) \approx \Phi\big(\tfrac{2900 - 3000}{50}\big) = \Phi(-2) \approx 0.0228\).Why: de Moivre–Laplace; mean np = 3000. (Continuity correction gives Φ(−2.01).)

Answer. 2500; Φ(−2). ∎

N2 · Moments of N(0, 5) Lvl 3

(MIT 18.600 S2014 Final #8) Let X be a normal random variable with mean 0 and variance 5.

Question: (a) Compute E[eˣ]. (b) Compute E[X⁹ + X³ − 50X + 7].

Key idea

MGF: \(E[e^{tX}] = e^{\sigma^2t^2/2}\). Odd moments of a mean-0 normal vanish by symmetry.

Picture

Completing the square. \(e^x\) times the N(0, 5) density is \(e^{5/2}\) times the N(5, 5) density: the curve just shifts right by σ² = 5. So the integral is \(e^{5/2}\).

Solution

Claim. (a) \(e^{5/2}\) · (b) 7.

  1. \(E[e^X] = \int \tfrac{1}{\sqrt{10\pi}} e^{x - x^2/10}\,dx = e^{5/2}\).Why: \(x - \tfrac{x^2}{10} = \tfrac52 - \tfrac{(x-5)^2}{10}\); what remains is a N(5, 5) density, integral 1.
  2. \(E[X^9] = E[X^3] = E[X] = 0\), so the answer is 7.Why: X and −X have the same law, so every odd moment equals its own negative.

Answer. e^{5/2}; 7. ∎

N3 · Two Normals, Mean 1 Lvl 3

(MIT 18.600 F2012 Midterm 2 #6) Let X and Y be independent normal random variables, each with mean 1 and variance 9.

Question: (a) Let f be the joint probability density function for the pair (X, Y). Write an explicit formula for f. (b) Compute E[X²] and E[X²Y²].

Key idea

Independent → joint density and E[product] both factor. \(E[X^2] = \text{Var} + \text{mean}^2\).

Picture

E[X²Y²] = E[X²]·E[Y²] = 10 · 10. The sim averages X²Y² directly.

Solution

Claim. (a) \(\tfrac{1}{18\pi}e^{-((x-1)^2 + (y-1)^2)/18}\) · (b) 10, 100.

  1. \(f(x, y) = \tfrac{1}{3\sqrt{2\pi}}e^{-(x-1)^2/18}\cdot\tfrac{1}{3\sqrt{2\pi}}e^{-(y-1)^2/18} = \tfrac{1}{18\pi}e^{-((x-1)^2 + (y-1)^2)/18}\).Why: independence; N(μ, σ²) density is \(\tfrac{1}{\sigma\sqrt{2\pi}}e^{-(x-\mu)^2/(2\sigma^2)}\) with σ = 3.
  2. \(E[X^2] = 9 + 1^2 = 10\).Why: \(\text{Var}(X) = E[X^2] - E[X]^2\).
  3. \(E[X^2Y^2] = E[X^2]\,E[Y^2] = 100\).Why: X², Y² are independent.

Answer. \(\tfrac{1}{18\pi}e^{-((x-1)^2 + (y-1)^2)/18}\); 10; 100. ∎

N4 · Half an MGF Lvl 5

(MIT 18.600 F2012 Final #9) Let X be a normal random variable with mean 0 and variance 1.

Question: (a) Compute E[eˣ]. (b) Compute \(E[e^X 1_{X>0}]\). (c) Compute E[X² + 2X − 5].

Key idea

Same square completion as N2, but only over x > 0: the shifted density N(1, 1) is integrated over x > 0, which is P(Z > −1) = Φ(1).

Picture

Tilt, then cut. \(e^x\varphi(x) = e^{1/2}\varphi(x-1)\); keeping x > 0 keeps the part of N(1, 1) above 0.

Solution

Claim. (a) \(e^{1/2}\) · (b) \(e^{1/2}\Phi(1) \approx 1.3871\) · (c) −4.

  1. \(E[e^X] = e^{1/2}\).Why: N2's formula with σ² = 1.
  2. \(E[e^X 1_{X>0}] = \int_0^\infty e^x\tfrac{1}{\sqrt{2\pi}}e^{-x^2/2}\,dx = e^{1/2}\int_0^\infty \tfrac{1}{\sqrt{2\pi}}e^{-(x-1)^2/2}\,dx\).Why: \(x - \tfrac{x^2}{2} = \tfrac12 - \tfrac{(x-1)^2}{2}\).
  3. \(= e^{1/2}P(Z > -1) = e^{1/2}\Phi(1)\).Why: substitute z = x − 1; symmetry \(P(Z > -1) = \Phi(1)\).
  4. \(E[X^2 + 2X - 5] = 1 + 0 - 5 = -4\).Why: linearity; E[X²] = Var = 1.

Answer. e^{1/2}; e^{1/2}Φ(1); −4. ∎
