1 · Basic terms

  1. Sample space Ω: the set of all outcomes. Event: a subset of Ω.
  2. A∩B: both happen. A∪B: at least one happens. Aᶜ: A does not happen.
  3. Mutually exclusive: A∩B = ∅. Exhaustive: A₁∪…∪Aₙ = Ω. A partition is both.
  4. Independent: P(A∩B) = P(A)P(B) (see §6).

2 · Probability of an event

  1. If all outcomes are equally likely: P(A) = |A|/|Ω|. This formula only holds under that condition.
  2. P(Aᶜ) = 1 − P(A).
  3. Trap: {red, blue} is not an equally likely sample space for 9 red + 1 blue balls. Label the balls 1–10 instead: P(blue) = 1/10.

3 · Inclusion–exclusion

The same as counting PIE, with |·| replaced by P(·) (divide by |Ω|, or use additivity): P(A∪B) = P(A) + P(B) − P(A∩B), and P(A∪B∪C) = ΣP(A) − ΣP(A∩B) + P(A∩B∩C).

3×2 matrix, rows and columns ≡ 0 (mod 3)

Entries are uniform on {0,1,2}.

Key idea

The two top-left entries determine everything.

Solution
  1. Choose a₁₁, a₂₁ freely. Then a₃₁ ≡ −(a₁₁+a₂₁) (column 1), and each aᵢ₂ ≡ −aᵢ₁ (rows).
  2. Column 2 is then ≡ −(column 1) ≡ 0 automatically. So valid matrices ↔ (a₁₁, a₂₁): 9 of them.
  3. P = 9/3⁶ = 1/81 ≈ 0.01235.

∎

Partial sums of 1..13 never ≡ 0 (mod 3)

Write 1,…,13 in random order. Report p + q.

Key idea

Work with residues: five 1s, four 2s, four 0s. The nonzero residues are forced into 1,1,2,1,2,1,2,1,2, and the 0s go anywhere except first.

Solution
  1. A 0-residue never changes the running sum mod 3, so it can go anywhere except position 1 (where the sum would be 0).
  2. Nonzero residues: starting from sum s ∈ {1,2}, the next residue must equal s. So the sequence alternates 1,1,2,1,2,… (from 1) or 2,2,1,2,1,… (from 2).
  3. Starting with 2 needs five 2s; there are only four. So the order is 1,1,2,1,2,1,2,1,2: 5!·4! labelled ways.
  4. Insert the four 0-residue numbers one by one, not in front: 9·10·11·12 ways.
  5. P = 5!·4!·11880/13! = 1/182, so p + q = 183. (DP-checked)

∎

5 · Conditional probability

  1. P(A | B) = P(A∩B)/P(B), for P(B) > 0. When outcomes are equally likely, this is |A∩B|/|B|: the sample space shrinks to B.
  2. "A before B" lemma. Independent identical trials. Each trial: A with prob a, B with prob b (disjoint), else repeat. Then P(A first) = a/(a+b). Proof: P(A first) = Σₙ (1−a−b)ⁿ⁻¹ a = a/(a+b).

Trigger: "given…", or "one thing before another".

Robot clicks H

A–Z in a row. Each move clicks a uniformly random remaining letter and deletes it and everything to its right. P(H is clicked)?

Key idea

Only the first click inside {A,…,H} matters, and it is uniform over those 8 letters.

Solution
  1. Clicks to the right of H never remove A–H. So until the first click in {A,…,H}, all 8 are present.
  2. Each click is uniform over the remaining letters. Conditioned on landing in {A,…,H}, it is uniform over those 8.
  3. H is clicked ⇔ that first click in {A,…,H} is H: P = 1/8.

6 · Multiplication rule & independence

  1. P(A∩B) = P(A)·P(B | A). Chained: P(A₁∩…∩Aₙ) = P(A₁)P(A₂|A₁)⋯P(Aₙ|A₁∩…∩Aₙ₋₁).
  2. Independent A, B: P(A∩B) = P(A)P(B), equivalently P(A|B) = P(A) when P(B) > 0.
  3. Mutually independent A₁,…,Aₙ: the product rule holds for every sub-collection, not just all n together.
  4. If A, B are independent, so are Aᶜ, Bᶜ: P(Aᶜ∩Bᶜ) = 1 − P(A) − P(B) + P(A)P(B) = (1−P(A))(1−P(B)).

⚠ Course defines independence of n events by the single equation P(⋂Aᵢ) = ∏P(Aᵢ). That is not enough. Counterexample: A = B, P(A) = ½, C = ∅; the full product holds (0 = 0), but A and B are not independent.

7 · Law of total probability

If A₁,…,Aₙ partition Ω, then B = ⋃(B∩Aᵢ), a disjoint union. So P(B) = Σ P(B | Aᵢ)P(Aᵢ). In practice: list the disjoint ways B can happen and add them up.

8 · Bayes

P(Aᵢ | B) = P(B | Aᵢ)P(Aᵢ) / Σⱼ P(B | Aⱼ)P(Aⱼ). This is just P(Aᵢ∩B)/P(B), with the numerator from the chain rule and the denominator from total probability.

9 · Paradoxes

  1. Start from the full, equally likely sample space. Delete what the information rules out. Only then count.
  2. Paths or stories are not equally likely by default: multiply the probabilities along each one.
  3. If someone chooses what to reveal, model how they choose. That rule is part of the information.

Falling frog

From 10, the frog jumps to a uniform point in {1,…,i−1}, until it reaches 1. P(it ever lands on 5)?

Key idea

The frog must land in {1,…,5} at some point. Its first landing there is uniform over those 5 points, and it visits 5 exactly when that landing is 5.

Solution
  1. Positions strictly decrease, and it ends at 1 ∈ {1..5}, so it has a first landing in {1..5}.
  2. Every jump from j ≥ 6 is uniform on {1..j−1} ⊇ {1..5}. Conditioned on landing in {1..5}, it is uniform over the 5 points.
  3. After landing below 5 it can never reach 5. So it visits 5 ⇔ the first landing is 5: P = 1/5.

∎  (Course: induction on f(i) = (1/(i−1))Σf(j), which gives the same answer.)

Trap: "subsets of {2..9} → ½" treats unequal paths as equally likely. For example, 10→1 has probability 1/9, but 10→9→1 has 1/72.

Three prisoners

10 · Reduced sample space

In repeated independent trials, drop the outcomes that change nothing. The subsequence of relevant trials is again independent and identically distributed, with the relevant probabilities renormalised (pᵢ / Σ relevant p). This is the "A before B" lemma from §5 in general form.

11 · Geometric probability

If a point is uniform in a region Ω, then P(A) = vol(A)/vol(Ω). Independent uniform variables give a point uniform in a box. Draw the region, then use areas, volumes or integrals.

1 ≤ y/x ≤ 2

Key idea

The region between the lines y = x and y = 2x inside the unit square is a triangle.

Solution
  1. Inside the square, the region x ≤ y ≤ 2x is the triangle (0,0), (1,1), (½,1). (y = 2x leaves through the top at x = ½)
  2. Area = ½·|1·1 − ½·1| = ¼. P = 1/4.

Crawling ant (max 3 steps)

Each step has an independent uniform time tₙ and distance xₙ. The ant stops at the end of the step in which the total time passes 1, or after 3 steps. P(final position > 1)?

Key idea

Step 1 never stops the ant (t₁ < 1). So it stops after 2 steps (t₁+t₂ > 1) or after 3 steps. Distances and times are independent.

Solution
  1. 2 steps, ending past 1: P(t₁+t₂ > 1)·P(x₁+x₂ > 1) = ½·½ = ¼.

12 · Recursion in probability

  1. First-step analysis: condition on the first move(s) until you are back in the same problem (or its complement), then solve the resulting linear equation.
  2. States: choose the smallest description that determines the future. Write pᵢ = Σ P(i→j)·pⱼ for each state and solve the system. Merge states that are symmetric.

13 · Symmetry I: ad hoc

  1. If the process treats labels interchangeably, every label (pair, ordering, …) has the same probability. If exactly one of k such cases happens, each has probability 1/k.
  2. For i.i.d. continuous variables, ties have probability 0, and all n! orderings are equally likely.

Marbles 3 and 98

100 numbered marbles. Each move draws 2 at random and discards one of them (by a rule that doesn't depend on the labels). (a) P(3 and 98 drawn together on move 50)? (b) On some move?

Key idea

On any fixed move, every one of the C(100,2) label pairs is equally likely to be the pair drawn.

Solution
  1. Relabelling the marbles doesn't change the law of the process, so all pairs {i,j} have the same probability of being drawn on move k.
  2. Exactly one pair is drawn on move k, so each pair has probability 1/C(100,2) = 1/4950. (a) 1/4950 ≈ 0.00020.
  3. Once 3 and 98 have been drawn together, one of them is gone, so the 99 moves are disjoint events: (b) 99/4950 = 1/50 = 0.02.

∎

⚠ Course doesn't state that the discard rule must ignore the labels (otherwise the symmetry fails).

Each of the 48 non-aces lies before all 4 aces with probability 1/5.

Solution
  1. For each non-ace c, in the relative order of {c, 4 aces} c is equally likely to be in any of the 5 places, so P(c before every ace) = 1/5.

36 · Conditional expectation

E[X | A] = Σ x P(X = x | A) = E[X·1_A]/P(A). Always compute the conditional distribution; intuition fails here.

Rolls until 6, given no 5 came first

Key idea

N is the first time a 5 or 6 appears, and that time is independent of which of the two it is. So conditioning on "6" doesn't change the law of N.

Solution
  1. Let N = the first roll showing 5 or 6. Then P(N = n, the face is 6) = (2/3)ⁿ⁻¹·(1/6) = P(N = n)·½.
  2. So N is independent of A = {6 first}, and N | A ~ Geometric(1/3).
  3. E[N | A] = 3. (Not 5: conditioning on A doesn't make the rolls "1–4 or 6 with 1/5 each".)

∎

Alice's tosses, given she beats Bob

Key idea

P(X = n, Y > n) = 2⁻ⁿ·2⁻ⁿ = 4⁻ⁿ.

Solution
  1. P(X < Y) = Σ 4⁻ⁿ = 1/3, so P(X = n | X < Y) = 3·4⁻ⁿ = (¾)(¼)ⁿ⁻¹, a Geometric(¾).
  2. E = 4/3 ≈ 1.33333.

∎

37 · Inclusion–exclusion for waiting times

Each trial produces at most one of the target events i, with probability pᵢ (the events are mutually exclusive within a trial), independently across trials. Let T be the time until every event has occurred. Then E[T] = Σ_{∅≠J} (−1)^{|J|+1} / Σ_{j∈J} pⱼ. Proof: tail sum plus PIE on {T ≥ t} = ⋃ᵢ{i unseen in t−1 trials}, and P(no j ∈ J in one trial) = 1 − Σ_J pⱼ (this uses exclusivity). Each term is a geometric series summing to 1/Σ_J pⱼ.

⚠ Course omits the "mutually exclusive within a trial" condition. Without it, 1 − Σ_J pⱼ is wrong.

39 · Variance

  1. Var X = E[(X − EX)²] = E[X²] − (EX)². SD = √Var.
  2. Var(aX + b) = a²Var X, and Var(c) = 0.
  3. Var(X + Y) = Var X + Var Y + 2Cov(X,Y). For independent (or just uncorrelated) variables the covariance is 0 and variances add. They do not add in general.

  5. Law of total variance: Var X = E[Var(X | Y)] + Var(E[X | Y]).
