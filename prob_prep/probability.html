1 · Basic terms

  1. Sample space \(\Omega\): the set of all outcomes. Event: a subset of \(\Omega\).
  2. \(A\cap B\): both happen. \(A\cup B\): at least one happens. \(A^c\): \(A\) does not happen.
  3. Mutually exclusive: \(A\cap B = \varnothing\). Exhaustive: \(A_1\cup\dots\cup A_n = \Omega\). A partition is both.
  4. Independent: \(P(A\cap B) = P(A)P(B)\) (see §6).

2 · Probability of an event

  1. If all outcomes are equally likely: \(P(A) = |A|/|\Omega|\). This formula only holds under that condition.
  2. \(P(A^c) = 1 - P(A)\).
  3. Trap: {red, blue} is not an equally likely sample space for 9 red + 1 blue balls. Label the balls 1–10 instead: \(P(\text{blue}) = \tfrac{1}{10}\).

Warm-ups

(a) \(P(\text{king})\) from one card. (b) Exactly 2 heads in 3 flips.

Key idea

List outcomes so that each is equally likely.

Solution

Setup. (a) One card from a shuffled 52-card deck: all 52 cards are equally likely. (b) Three fair flips: all \(2^3 = 8\) sequences HHH, HHT, …, TTT are equally likely.

  1. (a) There are 4 kings, so \(P(\text{king}) = \tfrac{4}{52} = \) \(\tfrac{1}{13} \approx 0.07692\).Why: favourable outcomes over all outcomes, valid because the 52 outcomes are equally likely.
  2. (b) Exactly 2 heads means choosing which 2 of the 3 flips are heads: \(\binom32 = 3\) sequences (HHT, HTH, THH). So \(P = \) \(\tfrac38\).Why: 3 favourable out of 8 equally likely sequences.

Conclusion. \(\tfrac{1}{13}\) and \(\tfrac38\). ∎

3 · Inclusion–exclusion

The same as counting PIE, with \(|\cdot|\) replaced by \(P(\cdot)\) (divide by \(|\Omega|\), or use additivity): \[P(A\cup B) = P(A) + P(B) - P(A\cap B),\] \[P(A\cup B\cup C) = \sum P(A) - \sum P(A\cap B) + P(A\cap B\cap C).\]

Sports and drinks

(a) \(P(S) = .7,\ P(B) = .5,\ P(S\cap B) = .4\). (b) Tea .6, coffee .5, juice .4; pairs .30, .20, .15; all three .10.

Key idea

Plug into PIE.

Solution
  1. (a) \(P(S \cup B) = P(S) + P(B) - P(S \cap B) = .7 + .5 - .4 = \) \(0.8\).Why: inclusion–exclusion for two events: \(P(S) + P(B)\) counts \(S \cap B\) twice, so subtract it once.
  2. (b) With \(T, C, J\) for tea, coffee, juice: \(P(T \cup C \cup J) = (.6 + .5 + .4) - (.30 + .20 + .15) + .10\).Why: inclusion–exclusion for three events: add the singles, subtract the pairs, add back the triple.
  3. \(= 1.5 - .65 + .10 = \) \(0.95\).Why: arithmetic. The Venn diagram in the key idea shows the 7 regions adding to 0.95.

Conclusion. 0.8 and 0.95. ∎

4 · Counting in probability

Ask: can I count both all outcomes and the favourable ones, in an equally likely model? If so, \(P = \text{favourable}/\text{all}\).

A and B not adjacent

5 people in a random row.

Key idea

Complement of the block count.

Solution

Setup. 5 people in a random row: all \(5! = 120\) orders are equally likely.

  1. Rows with A and B adjacent: glue A and B into a block, giving 4 units in \(4! = 24\) orders, times 2 orders inside the block: \(48\).Why: each such row comes from exactly one order of the units and one order inside the block.
  2. \(P(\text{adjacent}) = \tfrac{48}{120} = \tfrac25\).Why: favourable over equally likely.
  3. \(P(\text{not adjacent}) = 1 - \tfrac25 = \) \(\tfrac35\).Why: complement.

Conclusion. A and B are apart with probability \(\tfrac35\). ∎

First HH exactly at toss 10

Answer as \(p/q\); report \(p + q\).

Key idea

The last three tosses must be T H H. The first 7 must have no HH, and those are counted by Fibonacci.

Solution

Setup. A fair coin is tossed until two heads in a row (HH) first appear. We want the probability that this happens exactly at toss 10, i.e. tosses 9 and 10 are the first HH.

  1. The first HH is at tosses 9–10 exactly when: tosses 9 and 10 are H, toss 8 is T, and tosses 1–7 contain no HH.Why: if toss 8 were H, tosses 8–9 would already be HH. If tosses 1–7 had an HH, it would come earlier. Toss 8 = T also rules out an HH at tosses 7–8. Conversely, if all three conditions hold, there is no HH before tosses 9–10.
  2. Let \(f_n\) be the number of length-\(n\) strings with no HH. Then \(f_n = f_{n-1} + f_{n-2}\), with \(f_1 = 2\), \(f_2 = 3\).Why: split on the last toss. If it is T, the first \(n - 1\) tosses can be any HH-free string. If it is H, the toss before must be T (otherwise HH), and the first \(n - 2\) tosses can be any HH-free string. \(f_1 = 2\) (H, T); \(f_2 = 3\) (HT, TH, TT).
  3. \(f_3 = 5,\ f_4 = 8,\ f_5 = 13,\ f_6 = 21,\ f_7 = 34\).Why: apply step 2.
  4. The favourable 10-toss sequences number \(34 \cdot 1 \cdot 1 \cdot 1 = 34\), out of \(2^{10} = 1024\) equally likely sequences.Why: tosses 1–7: 34 choices (step 3); tosses 8, 9, 10 are forced (T, H, H).
  5. \(P = \tfrac{34}{1024} = \tfrac{17}{512}\), so \(p + q = \) \(529\).Why: divide top and bottom by 2; 17 is prime and 512 is a power of 2.

Conclusion. \(P = \tfrac{17}{512}\), \(p + q = 529\). ∎

\(3\times2\) matrix, rows and columns \(\equiv 0 \pmod 3\)

Entries are uniform on \(\{0,1,2\}\).

Key idea

The two top-left entries determine everything.

Solution

Setup. A \(3\times2\) matrix \((a_{ij})\) with each entry uniform on \(\{0, 1, 2\}\), independently. All \(3^6 = 729\) matrices are equally likely. We want every row sum and every column sum to be \(\equiv 0 \pmod 3\).

  1. Each row \(i\) needs \(a_{i1} + a_{i2} \equiv 0\), i.e. \(a_{i2} \equiv -a_{i1}\). So \(a_{i2}\) is determined by \(a_{i1}\).Why: for each value of \(a_{i1}\) exactly one value in \(\{0,1,2\}\) works.
  2. Column 1 needs \(a_{11} + a_{21} + a_{31} \equiv 0\), so \(a_{31}\) is determined by \(a_{11}\) and \(a_{21}\).Why: same reason.
  3. Column 2 is then automatically fine: \(a_{12} + a_{22} + a_{32} \equiv -(a_{11} + a_{21} + a_{31}) \equiv 0\).Why: step 1 gives each \(a_{i2} \equiv -a_{i1}\), and step 2 gives the column 1 sum \(\equiv 0\).
  4. So the valid matrices match the free choices of \((a_{11}, a_{21})\): \(3 \cdot 3 = 9\) of them.Why: everything else is forced (steps 1–3), and every choice of the two free entries works.
  5. \(P = \tfrac{9}{729} = \) \(\tfrac{1}{81} \approx 0.01235\).Why: favourable over equally likely.

Conclusion. The probability is \(\tfrac{1}{81}\). ∎

Partial sums of 1..13 never \(\equiv 0 \pmod 3\)

Write \(1,\dots,13\) in random order. Report \(p + q\).

Key idea

Work with residues: five 1s, four 2s, four 0s. The nonzero residues are forced into \(1,1,2,1,2,1,2,1,2\), and the 0s go anywhere except first.

Solution

Setup. The numbers \(1, \dots, 13\) are written in a uniformly random order (all \(13!\) orders equally likely). \(s_k\) is the sum of the first \(k\) of them. We want \(P(\text{no } s_k \equiv 0 \pmod 3)\). By residue mod 3: five numbers are \(\equiv 1\) (1, 4, 7, 10, 13), four are \(\equiv 2\) (2, 5, 8, 11) and four are \(\equiv 0\) (3, 6, 9, 12).

  1. A number \(\equiv 0\) never changes \(s_k \bmod 3\). So it can stand anywhere except in position 1, where it would make \(s_1 \equiv 0\).Why: adding a multiple of 3 keeps the remainder.
  2. Look at the 9 nonzero residues in the order they appear. Their running sums are exactly the partial sums mod 3 (the 0s change nothing, step 1), so these running sums must never be \(0\).Why: step 1.
  3. If the running sum is \(s \in \{1, 2\}\), the next nonzero residue must equal \(s\).Why: if \(s = 1\), adding 2 gives \(0\) (forbidden), so the next residue is 1. If \(s = 2\), adding 1 gives 0 (forbidden), so it is 2.
  4. So the residues must go \(1, 1, 2, 1, 2, 1, 2, 1, 2\) (starting with 1) or \(2, 2, 1, 2, 1, 2, 1, 2, 1\) (starting with 2).Why: apply step 3 repeatedly: after 1 comes 1 (sum 2), then 2 (sum 1), then 1, and so on.
  5. Only the first pattern is possible: the second needs five 2s, but only four numbers are \(\equiv 2\).Why: count the 2s in each pattern.
  6. Number of good orders: \(5! \cdot 4! \cdot (9 \cdot 10 \cdot 11 \cdot 12)\).Why: the five \(\equiv 1\) numbers fill the five 1-slots in \(5!\) ways and the four \(\equiv 2\) numbers fill the 2-slots in \(4!\) ways. Then insert 3, 6, 9, 12 one at a time, never in front: into a row of length 9 there are 9 allowed places (after each element), then 10, 11, 12.
  7. \(P = \dfrac{120 \cdot 24 \cdot 11880}{13!} = \dfrac{34\,214\,400}{6\,227\,020\,800} = \dfrac{1}{182}\), so \(p + q = \) \(183\).Why: arithmetic (\(6\,227\,020\,800 / 34\,214\,400 = 182\)); DP-checked.

Conclusion. \(P = \tfrac{1}{182}\), \(p + q = 183\). ∎

5 · Conditional probability

  1. \(\displaystyle P(A \mid B) = \frac{P(A\cap B)}{P(B)}\), for \(P(B) > 0\). When outcomes are equally likely, this is \(|A\cap B|/|B|\): the sample space shrinks to \(B\).
  2. "A before B" lemma. Independent identical trials. Each trial: \(A\) with prob \(a\), \(B\) with prob \(b\) (disjoint), else repeat. Then \[P(A \text{ first}) = \sum_{n\ge1} (1-a-b)^{n-1} a = \frac{a}{a+b}.\]

Trigger: "given…", or "one thing before another".

Red → diamond; even → \(>3\)

Key idea

Shrink the sample space to the condition.

Solution

Setup. (a) One card from a shuffled deck. (b) One roll of a fair die.

  1. (a) \(P(\diamondsuit) = \tfrac{13}{52} = \tfrac14\).Why: 13 diamonds among 52 equally likely cards.
  2. \(P(\diamondsuit \mid \text{red}) = \dfrac{|\diamondsuit \cap \text{red}|}{|\text{red}|} = \dfrac{13}{26} = \dfrac12\). Their sum is \(0.75\).Why: given red, the sample space shrinks to the 26 red cards, equally likely, and all 13 diamonds are red.
  3. (b) \(P(>3 \mid \text{even}) = \dfrac{|\{4, 6\}|}{|\{2, 4, 6\}|} = \) \(\tfrac23\).Why: given even, the sample space is \(\{2, 4, 6\}\), equally likely; the ones above 3 are 4 and 6.

Conclusion. 0.75 and \(\tfrac23\). ∎

First ace at 27, then 2♥?

Key idea

Given the condition, the first 26 cards are a uniform choice of non-aces, and the 25 cards after position 27 are in uniform random order.

Solution

Setup. A shuffled 52-card deck; all \(52!\) orders are equally likely. \(E\) = 'the first ace is at position 27'. We want \(P(\text{position 28 is } 2\heartsuit \mid E)\).

  1. Given \(E\): positions 1–26 hold 26 of the 48 non-aces, position 27 holds an ace, and positions 28–52 hold the remaining 25 cards (3 aces and 22 non-aces).Why: that is what 'first ace at 27' means.
  2. Given \(E\), each non-ace is equally likely to be among the first 26, and the 25 cards after position 27 are in uniformly random order.Why: swapping two non-aces everywhere, or rearranging positions 28–52, maps orders in \(E\) to orders in \(E\) one-to-one, and all orders are equally likely.
  3. \(P(2\heartsuit \text{ is not in positions 1–26} \mid E) = \tfrac{22}{48}\).Why: 26 of the 48 non-aces are in the first 26 positions, each non-ace equally likely to be one of them (step 2); so \(2\heartsuit\) is there with probability \(\tfrac{26}{48}\) and not there with \(\tfrac{22}{48}\).
  4. If \(2\heartsuit\) is among the last 25 cards, it is at position 28 with probability \(\tfrac{1}{25}\).Why: uniform order of those 25 cards (step 2).
  5. \(P = \tfrac{22}{48}\cdot\tfrac{1}{25} = \tfrac{22}{1200} = \) \(\tfrac{11}{600} \approx 0.018\).Why: multiplication rule: steps 3 and 4.

Conclusion. The probability is \(\tfrac{11}{600}\). ∎

Robot clicks H

A–Z in a row. Each move clicks a uniformly random remaining letter and deletes it and everything to its right. \(P(\text{H is clicked})\)?

Key idea

Only the first click inside \(\{A,\dots,H\}\) matters, and it is uniform over those 8 letters.

Solution

Setup. The letters A–Z are in a row. Each move clicks a uniformly random remaining letter and deletes it together with everything to its right. This repeats until nothing is left. We want \(P(\text{H is clicked at some point})\).

  1. The letters A–H can only be removed by a click on one of A–H.Why: a click on a letter from I–Z deletes only that letter and letters to its right, which are all right of H.
  2. So until the first click that lands in \(\{A, \dots, H\}\), all 8 of these letters are still present. And such a click must happen eventually.Why: step 1; A can only be removed by clicking A, and the process runs until everything is gone.
  3. That first click in \(\{A, \dots, H\}\) is equally likely to be each of the 8 letters.Why: each click is uniform over the remaining letters, and all 8 are present (step 2). Given that the click lands among them, each has the same chance.
  4. H is clicked exactly when this first click is H.Why: if it is some \(X \ne H\) among A–G, then \(X\) and everything to its right, including H, is deleted, so H can never be clicked.
  5. \(P = \) \(\tfrac18\).Why: steps 3 and 4.

Conclusion. H is clicked with probability \(\tfrac18\). ∎

⚠ Course's “1 way to click H / 8 ways to remove it” is only valid because of step 3, which it never states. It also doesn't state the uniform-click assumption.

7 before 11

Roll two dice until the total is 7 (win) or 11 (lose).

Key idea

"A before B" lemma, with \(a = \tfrac{6}{36}\) and \(b = \tfrac{2}{36}\).

Solution

Setup. Two dice are rolled repeatedly. A total of 7 wins, 11 loses, and anything else means roll again.

  1. On one roll: \(P(7) = \tfrac{6}{36}\), \(P(11) = \tfrac{2}{36}\), \(P(\text{neither}) = \tfrac{28}{36}\).Why: 7 comes from \((1,6), (2,5), \dots, (6,1)\): 6 of the 36 equally likely pairs. 11 comes from \((5,6), (6,5)\).
  2. You win on roll \(n\) exactly when the first \(n - 1\) rolls are 'neither' and roll \(n\) is 7: probability \(\big(\tfrac{28}{36}\big)^{n-1}\tfrac{6}{36}\).Why: rolls are independent.
  3. \(P(\text{win}) = \sum_{n\ge1}\big(\tfrac{28}{36}\big)^{n-1}\tfrac{6}{36} = \dfrac{6/36}{1 - 28/36} = \dfrac{6/36}{8/36} = \) \(\tfrac34\).Why: geometric series \(\sum_{n \ge 1} q^{n-1} = \tfrac{1}{1-q}\). This is the 'A before B' lemma: \(\tfrac{a}{a+b}\).

Conclusion. You win with probability \(\tfrac34\). ∎

6 · Multiplication rule & independence

  1. \(P(A\cap B) = P(A)\,P(B \mid A)\). Chained: \[P(A_1\cap\dots\cap A_n) = P(A_1)\,P(A_2 \mid A_1)\cdots P(A_n \mid A_1\cap\dots\cap A_{n-1}).\]
  2. Independent \(A, B\): \(P(A\cap B) = P(A)P(B)\), equivalently \(P(A \mid B) = P(A)\) when \(P(B) > 0\).
  3. Mutually independent \(A_1,\dots,A_n\): the product rule holds for every sub-collection, not just all \(n\) together.
  4. If \(A, B\) are independent, so are \(A^c, B^c\): \(P(A^c\cap B^c) = 1 - P(A) - P(B) + P(A)P(B) = (1-P(A))(1-P(B))\).

⚠ Course defines independence of \(n\) events by the single equation \(P(\bigcap A_i) = \prod P(A_i)\). That is not enough. Counterexample: \(A = B\), \(P(A) = \tfrac12\), \(C = \varnothing\); the full product holds (\(0 = 0\)), but \(A\) and \(B\) are not independent.

Draws without replacement

(a) 5G, 3R: red then green. (b) Ace then queen. (c) Ace, queen, king.

Key idea

Chain rule: each factor is computed on the remaining deck.

Solution
  1. (a) 5 green, 3 red. \(P(\text{1st red}) = \tfrac38\). Given that, 7 balls remain and 5 are green: \(P(\text{2nd green} \mid \text{1st red}) = \tfrac57\). Multiply: \(\tfrac{15}{56} \approx 0.26786\).Why: chain rule \(P(A \cap B) = P(A)P(B \mid A)\); each factor is computed on what is left.
  2. (b) \(P(\text{ace}) = \tfrac{4}{52}\), then \(P(\text{queen} \mid \text{ace first}) = \tfrac{4}{51}\). Product: \(\tfrac{16}{2652} = \) \(\tfrac{4}{663} \approx 0.00603\).Why: after one card, 51 remain and all 4 queens are still there.
  3. (c) Then \(P(\text{king} \mid \text{ace, queen}) = \tfrac{4}{50}\). Product: \(\tfrac{4}{52}\cdot\tfrac{4}{51}\cdot\tfrac{4}{50} = \tfrac{64}{132600} \approx\) \(0.00048\).Why: 50 cards remain, all 4 kings among them.

Conclusion. \(\tfrac{15}{56}\), \(\tfrac{4}{663}\) and about 0.00048. ∎

Ant on an icosahedron

Random walk from A. \(P(\text{at the opposite vertex B after 3 moves})\)?

Key idea

Group the vertices by distance from A: 1, 5, 5, 1. B at distance 3 must be reached by moving one level outward each step.

Solution

Setup. An icosahedron has 12 vertices and every vertex has 5 edges. The ant starts at A and each move goes along one of the 5 edges of its current vertex, each with probability \(\tfrac15\). B is the vertex opposite A. We want \(P(\text{at B after 3 moves})\).

  1. Group the vertices by distance from A: A itself; the 5 neighbours of A (level \(L_2\)); the 5 neighbours of B (level \(L_3\)); and B, at distance 3. From A all 5 edges go to \(L_2\). From each \(L_2\) vertex: 1 edge to A, 2 inside \(L_2\), 2 to \(L_3\). From each \(L_3\) vertex: 2 to \(L_2\), 2 inside \(L_3\), 1 to B.Why: the neighbours of A form a ring of 5, and so do the neighbours of B; the edge counts add up to 5 at every vertex.
  2. To be at B after 3 moves, every move must go one level further out: \(A \to L_2 \to L_3 \to B\).Why: B is at distance 3, and one move changes the distance by at most 1.
  3. The three steps have probabilities \(1\), \(\tfrac25\), \(\tfrac15\).Why: read off step 1: all 5 edges from A go to \(L_2\); 2 of the 5 edges from an \(L_2\) vertex go to \(L_3\); 1 of the 5 edges from an \(L_3\) vertex goes to B.
  4. \(P = 1\cdot\tfrac25\cdot\tfrac15 = \) \(\tfrac{2}{25}\).Why: chain rule; each move depends only on the current vertex.

Conclusion. The ant is at B after 3 moves with probability \(\tfrac{2}{25}\). ∎

Shooting stars

(a) \(P(\text{star in 1 h}) = 0.6\), independent hours. \(P(\text{at least one in 2 h})\)? (b) \(P(\text{star in 1 h}) = 0.8\), with four independent identical 15-min blocks. \(P(\text{star in the first 15 min})\)?

Key idea

Work with "none": the complements multiply.

Solution
  1. (a) \(P(\text{no star in one hour}) = 1 - 0.6 = 0.4\), so \(P(\text{no star in 2 hours}) = 0.4^2 = 0.16\).Why: complement, then the two hours are independent, so the 'none' probabilities multiply.
  2. \(P(\text{at least one in 2 hours}) = 1 - 0.16 = \) \(0.84\).Why: complement.
  3. (b) Let \(p = P(\text{star in one 15-min block})\). The hour is 4 independent identical blocks, so \(P(\text{no star in the hour}) = (1 - p)^4\).Why: no star in the hour means none in each of the 4 blocks.
  4. \((1 - p)^4 = 1 - 0.8 = 0.2\), so \(1 - p = 0.2^{1/4} \approx 0.66874\) and \(p \approx\) \(0.33126\).Why: take the fourth root: \(\sqrt{0.2} \approx 0.44721\) and \(\sqrt{0.44721} \approx 0.66874\).

Conclusion. 0.84 and about 0.331. ∎

7 · Law of total probability

If \(A_1,\dots,A_n\) partition \(\Omega\), then \(B = \bigcup (B\cap A_i)\), a disjoint union. So \[P(B) = \sum_i P(B \mid A_i)\,P(A_i).\] In practice: list the disjoint ways \(B\) can happen and add them up.

Defects and coins

(a) Machines A/B make 60%/40% of items, with 2%/5% defective. \(P(\text{defective})\)? (b) Coins with \(P(H) = .5, .75, 1\), one picked at random. \(P(H)\)?

Key idea

Split on which machine or coin.

Solution
  1. (a) Every item comes from machine A (0.6) or B (0.4), and never both. So \(P(D) = P(D \mid A)P(A) + P(D \mid B)P(B)\).Why: law of total probability over the partition \(\{A, B\}\).
  2. \(= 0.02\cdot0.6 + 0.05\cdot0.4 = 0.012 + 0.020 = \) \(0.032\).Why: substitute.
  3. (b) Each coin is picked with probability \(\tfrac13\): \(P(H) = \tfrac13(0.5) + \tfrac13(0.75) + \tfrac13(1) = \tfrac{2.25}{3} = \) \(0.75\).Why: total probability over which coin was picked.

Conclusion. 0.032 and 0.75. ∎

8 · Bayes

\[P(A_i \mid B) = \frac{P(B \mid A_i)\,P(A_i)}{\sum_j P(B \mid A_j)\,P(A_j)}.\] This is just \(P(A_i\cap B)/P(B)\), with the numerator from the chain rule and the denominator from total probability.

Three bags

Bags (3R,4B), (2R,11B), (8R,1B). A random bag, then a random ball, which is red. \(P(\text{bag 3})\)?

Key idea

The equal priors cancel: the answer is the ratio of the likelihoods.

Solution

Setup. A bag is picked uniformly (\(\tfrac13\) each), then a ball from it. \(P(\text{red} \mid \text{bag 1}) = \tfrac37\), \(P(\text{red} \mid \text{bag 2}) = \tfrac{2}{13}\), \(P(\text{red} \mid \text{bag 3}) = \tfrac89\).

  1. Bayes: \(P(\text{bag 3} \mid \text{red}) = \dfrac{P(\text{red} \mid 3)\,P(3)}{\sum_k P(\text{red} \mid k)\,P(k)}\).Why: numerator from the chain rule, denominator from total probability.
  2. The priors are all \(\tfrac13\) and cancel: \(= \dfrac{8/9}{3/7 + 2/13 + 8/9}\).Why: factor \(\tfrac13\) out of the numerator and every denominator term.
  3. Over the common denominator 819: \(\tfrac37 = \tfrac{351}{819}\), \(\tfrac{2}{13} = \tfrac{126}{819}\), \(\tfrac89 = \tfrac{728}{819}\). So \(P = \tfrac{728}{351 + 126 + 728} = \tfrac{728}{1205} \approx\) \(0.604\).Why: \(819 = 7\cdot9\cdot13\).

Conclusion. Given red, bag 3 has probability about 0.604. ∎

9 fair + 1 double-headed coin

A random coin shows H. \(P(\text{double-headed})\)?

Key idea

Prior times likelihood, then normalise.

Solution

Setup. 10 coins: 9 fair and 1 double-headed (DH). One is picked uniformly and flipped; it shows H.

  1. \(P(\text{DH and H}) = \tfrac{1}{10}\cdot1 = \tfrac{1}{10}\).Why: pick DH with probability \(\tfrac{1}{10}\); it always shows H.
  2. \(P(\text{fair and H}) = \tfrac{9}{10}\cdot\tfrac12 = \tfrac{9}{20}\).Why: pick a fair coin with probability \(\tfrac{9}{10}\), then H with \(\tfrac12\).
  3. \(P(H) = \tfrac{1}{10} + \tfrac{9}{20} = \tfrac{2}{20} + \tfrac{9}{20} = \tfrac{11}{20}\).Why: the two cases are disjoint and cover every way to get H.
  4. \(P(\text{DH} \mid H) = \dfrac{1/10}{11/20} = \dfrac{2}{11} \approx\) \(0.182\).Why: definition of conditional probability.

Conclusion. The coin is double-headed with probability \(\tfrac{2}{11}\). ∎

Disease test

Prevalence 1%, sensitivity 90%, false-positive rate 5%. \(P(\text{disease} \mid \text{positive})\)?

Key idea

The rare disease makes false positives outnumber true positives.

Solution

Setup. \(D\) = has the disease, \(T\) = tests positive. \(P(D) = 0.01\), \(P(T \mid D) = 0.9\), \(P(T \mid \text{not } D) = 0.05\).

  1. \(P(D \cap T) = 0.01 \cdot 0.9 = 0.009\).Why: chain rule.
  2. \(P(\text{not } D \cap T) = 0.99 \cdot 0.05 = 0.0495\).Why: chain rule; \(P(\text{not } D) = 0.99\).
  3. \(P(T) = 0.009 + 0.0495 = 0.0585\).Why: a positive test comes from a sick or a healthy person, never both.
  4. \(P(D \mid T) = \dfrac{0.009}{0.0585} \approx\) \(0.154\).Why: definition of conditional probability. In counts: of 10 000 people, 90 sick people test positive but so do 495 healthy people.

Conclusion. A positive test means disease with probability only about 0.154. ∎

9 · Paradoxes

  1. Start from the full, equally likely sample space. Delete what the information rules out. Only then count.
  2. Paths or stories are not equally likely by default: multiply the probabilities along each one.
  3. If someone chooses what to reveal, model how they choose. That rule is part of the information.

Three coins (HH, HT, TT)

A random coin, a random face shows H. \(P(\text{double-headed})\)?

Key idea

Count faces, not coins: there are 3 equally likely heads-faces, and 2 of them belong to HH.

Solution

Setup. Three coins: HH (heads on both faces), HT, TT. A coin is picked uniformly, then one of its faces uniformly, and that face shows H.

  1. Name the faces: HH coin \(A_1, A_2\) (both H); HT coin \(B_1\) (H), \(B_2\) (T); TT coin \(C_1, C_2\) (T). Each of the 6 (coin, face) outcomes has probability \(\tfrac13\cdot\tfrac12 = \tfrac16\).Why: the coin is uniform, then the face is uniform.
  2. 'The face shows H' is the event \(\{A_1, A_2, B_1\}\): 3 equally likely outcomes.Why: these are the heads faces.
  3. Two of them, \(A_1\) and \(A_2\), are on the HH coin, so \(P = \) \(\tfrac23\).Why: conditioning on an event made of equally likely outcomes: count within it.
  4. The tempting answer \(\tfrac12\) is wrong because it treats the HH and HT coins as equally likely after seeing H. But the HH coin shows H every time and the HT coin only half the time.Why: the observation carries information about the coin.

Conclusion. Given a head, the coin is double-headed with probability \(\tfrac23\). ∎

Children and coins

(a) 2 children, at least one is a girl: \(P(\text{both girls})\)? (b) The older one is a girl: \(P(\text{both})\)? (c) 3 coins, at least one H: \(P(\text{HHH})\)?

Key idea

Remove the ruled-out outcomes from the equally likely list.

Solution

Setup. Two children, each independently a boy or girl with probability \(\tfrac12\). Writing (older, younger), the outcomes BB, BG, GB, GG are equally likely.

  1. (a) 'At least one girl' leaves \(\{BG, GB, GG\}\), so \(P(GG) = \) \(\tfrac13\).Why: remove BB and count within the 3 remaining equally likely outcomes.
  2. (b) 'The older is a girl' leaves \(\{GB, GG\}\), so \(P(GG) = \) \(\tfrac12\).Why: the older child is listed first.
  3. (c) Three coins have 8 equally likely outcomes. 'At least one H' removes only TTT, leaving 7, of which 1 is HHH: \(\tfrac17 \approx 0.143\).Why: same method.

Conclusion. \(\tfrac13\), \(\tfrac12\) and \(\tfrac17\). ∎

⚠ Course leaves this implicit: (a) assumes we learn exactly the event “\(\ge 1\) girl”. If instead a random child is revealed to be a girl, the answer is \(\tfrac12\).

Falling frog

From 10, the frog jumps to a uniform point in \(\{1,\dots,i-1\}\), until it reaches 1. \(P(\text{it ever lands on 5})\)?

Key idea

The frog must land in \(\{1,\dots,5\}\) at some point. Its first landing there is uniform over those 5 points, and it visits 5 exactly when that landing is 5.

Solution

Setup. The frog starts at 10. From position \(i \ge 2\) it jumps to a uniform point of \(\{1, \dots, i-1\}\), and it stops at 1. We want \(P(\text{it lands on 5 at some time})\).

  1. The frog lands in \(\{1, \dots, 5\}\) at some point, so there is a first landing there.Why: positions strictly decrease and the frog ends at 1, which is in the set.
  2. Every jump made before that first landing starts from some \(j \ge 6\), and is uniform on \(\{1, \dots, j-1\}\), a set containing all of \(\{1, \dots, 5\}\).Why: before the first landing the frog is above 5.
  3. So, given that a jump lands in \(\{1, \dots, 5\}\), it lands on each of the 5 points with equal probability. Hence the first landing point is uniform on \(\{1, \dots, 5\}\): each has probability \(\tfrac15\).Why: each of the 5 points has probability \(\tfrac{1}{j-1}\) from \(j\). This holds whatever \(j\) and whatever happened before, so it holds overall.
  4. The frog visits 5 exactly when this first landing is 5.Why: if it first lands below 5, positions only decrease afterwards, so 5 is never reached.
  5. \(P = \) \(\tfrac15\).Why: steps 3 and 4.

Conclusion. The frog lands on 5 with probability \(\tfrac15\). ∎

(Course: induction on \(f(i) = \frac{1}{i-1}\sum_j f(j)\), which gives the same answer.)

⚠ Trap: “subsets of \(\{2..9\} \to \tfrac12\)” treats unequal paths as equally likely. For example, \(10\to1\) has probability \(\tfrac19\), but \(10\to9\to1\) has \(\tfrac{1}{72}\).

Three prisoners

Two of A, B, C will be released. The warden names a released prisoner other than A, choosing at random if both B and C go free. He says "B". \(P(\text{A released})\)?

Key idea

AB forces "B", but BC says "B" only half the time.

Solution

Setup. Two of A, B, C will be released: AB, AC or BC, each with probability \(\tfrac13\). The warden names a released prisoner other than A: with AB he says B, with AC he says C, with BC he says B or C with probability \(\tfrac12\) each. He says “B”.

  1. \(P(AB \text{ and “B”}) = \tfrac13\cdot1 = \tfrac13\); \(P(AC \text{ and “B”}) = 0\); \(P(BC \text{ and “B”}) = \tfrac13\cdot\tfrac12 = \tfrac16\).Why: chain rule with the warden's rule.
  2. \(P(\text{“B”}) = \tfrac13 + 0 + \tfrac16 = \tfrac12\).Why: the three release pairs are disjoint and cover everything.
  3. A is released in the cases AB and AC, so \(P(A \text{ released} \mid \text{“B”}) = \dfrac{1/3 + 0}{1/2} = \) \(\tfrac23\).Why: definition of conditional probability.

Conclusion. Hearing “B” leaves A's chance at \(\tfrac23\): it doesn't drop to \(\tfrac12\), because BC produces “B” only half the time. ∎

10 · Reduced sample space

In repeated independent trials, drop the outcomes that change nothing. The subsequence of relevant trials is again independent and identically distributed, with the relevant probabilities renormalised (\(p_i / \sum_{\text{relevant}} p\)). This is the "A before B" lemma from §5 in general form.

Tennis from 30–30

Alice wins each point independently with probability 0.6.

Key idea

30–30 behaves like deuce. Look at pairs of points: AA wins, BB loses, and AB or BA returns to deuce.

Solution

Setup. Alice wins each point independently with probability 0.6. From 30–30 (and from deuce), the game is won by whoever first gets 2 points ahead.

  1. Look at the next two points. AA (probability \(0.6^2 = 0.36\)): Alice wins. BB (\(0.4^2 = 0.16\)): Bob wins. AB or BA (\(2\cdot0.6\cdot0.4 = 0.48\)): the score is level again (deuce), which is the same situation as now.Why: from level, one point makes someone 1 ahead, which isn't enough, so the game can't end in the middle of a pair.
  2. Pairs of points are independent trials with outcomes 'Alice wins' (0.36), 'Bob wins' (0.16), 'repeat' (0.48).Why: points are independent.
  3. \(P(\text{Alice}) = \sum_{n \ge 1} 0.48^{n-1}\cdot0.36 = \dfrac{0.36}{1 - 0.48} = \dfrac{0.36}{0.52} = \) \(\tfrac{9}{13} \approx 0.69231\).Why: Alice wins on pair \(n\) when the first \(n - 1\) pairs repeat; geometric series (the 'A before B' lemma).

Conclusion. From 30–30 Alice wins with probability \(\tfrac{9}{13}\). ∎

Two 2s and two 3s before the first 6

Key idea

Ignore 1, 4, 5. The relevant rolls form a fair 3-sided die \(\{2, 3, 6\}\).

Solution

Setup. A fair die is rolled until the first 6. We want the probability that exactly two 2s and two 3s appear before that 6.

  1. Rolls of 1, 4, 5 don't affect the event, so delete them. The remaining 'relevant' rolls are independent and each is uniform on \(\{2, 3, 6\}\).Why: each roll is independent, and given that it lands in \(\{2, 3, 6\}\), each of the three has probability \(\tfrac{1/6}{3/6} = \tfrac13\).
  2. The event happens exactly when the first 5 relevant rolls are two 2s and two 3s in some order, followed by a 6.Why: exactly four relevant non-6 rolls come before the first 6.
  3. There are \(\tfrac{4!}{2!\,2!} = 6\) orders of 2, 2, 3, 3, and each specific 5-roll relevant sequence has probability \((\tfrac13)^5 = \tfrac{1}{243}\).Why: arrangements of a multiset; independence.
  4. \(P = \tfrac{6}{243} = \) \(\tfrac{2}{81} \approx 0.02469\).Why: 6 disjoint sequences, each \(\tfrac{1}{243}\).

Conclusion. The probability is \(\tfrac{2}{81}\). ∎

11 · Geometric probability

If a point is uniform in a region \(\Omega\), then \(P(A) = \operatorname{vol}(A)/\operatorname{vol}(\Omega)\). Independent uniform variables give a point uniform in a box. Draw the region, then use areas, volumes or integrals.

\(1 \le y/x \le 2\)

\(x, y\) independent and uniform on \([0,1]\).

Key idea

The region between the lines \(y = x\) and \(y = 2x\) inside the unit square is a triangle.

Solution

Setup. \(x, y\) are independent and uniform on \([0, 1]\), so \((x, y)\) is uniform on the unit square and probability equals area.

  1. \(1 \le y/x \le 2 \iff x \le y \le 2x\) (for \(x > 0\); \(x = 0\) has probability 0).Why: multiply the inequalities by \(x > 0\).
  2. Inside the square, this is the region between the lines \(y = x\) and \(y = 2x\). The line \(y = 2x\) leaves the square through the top at \(x = \tfrac12\), so the region is the triangle \((0,0), (\tfrac12, 1), (1, 1)\).Why: \(2x = 1\) at \(x = \tfrac12\); \(y = x\) reaches the top at \((1,1)\).
  3. Its area is \(\tfrac12 \cdot \text{base} \cdot \text{height} = \tfrac12\cdot\tfrac12\cdot1 = \tfrac14\): base from \((\tfrac12, 1)\) to \((1, 1)\) along the top edge, height 1 down to \((0,0)\).Why: triangle area formula.
  4. \(P = \) \(\tfrac14\).Why: probability = area.

Conclusion. The probability is \(\tfrac14\). ∎

⚠ Course writes the area as \(\tfrac12\cdot1\cdot1 = \tfrac12\) and then uses \(\tfrac14\). The triangle's base is \(\tfrac12\) and its height is 1, so the area is \(\tfrac14\) (step 3).

Two friends, 30-minute stays

Each arrives uniformly in \([0,1]\) h and stays 0.5 h. \(P(\text{they meet})\)?

Key idea

They meet \(\iff |x - y| \le \tfrac12\). The complement is two corner triangles.

Solution

Setup. Arrival times \(x, y\) are independent and uniform on \([0, 1]\) hour; each friend stays for half an hour. The point \((x, y)\) is uniform on the unit square.

  1. They meet exactly when \(|x - y| \le \tfrac12\).Why: say \(x \le y\). The first friend is there during \([x, x + \tfrac12]\); they meet iff the second arrives by then, \(y \le x + \tfrac12\). The case \(y \le x\) is the same with the roles swapped.
  2. The complement \(|x - y| > \tfrac12\) is two corner triangles, \(y > x + \tfrac12\) and \(x > y + \tfrac12\), each a right triangle with legs \(\tfrac12\): area \(\tfrac12\cdot\tfrac12\cdot\tfrac12 = \tfrac18\) each.Why: for example, \(y > x + \tfrac12\) inside the square is the triangle \((0, \tfrac12), (0, 1), (\tfrac12, 1)\).
  3. \(P(\text{meet}) = 1 - 2\cdot\tfrac18 = \) \(\tfrac34\).Why: complement of the two triangles.

Conclusion. They meet with probability \(\tfrac34\). ∎

\(xy \le \tfrac12\)

Key idea

For \(x \le \tfrac12\) every \(y\) works. For \(x > \tfrac12\) you need \(y \le \tfrac{1}{2x}\).

Solution

Setup. \(x, y\) independent uniform on \([0, 1]\); probability = area of \(\{xy \le \tfrac12\}\) in the unit square.

  1. For a fixed \(x\), the allowed \(y\) are \(y \le \tfrac{1}{2x}\).Why: divide \(xy \le \tfrac12\) by \(x > 0\).
  2. If \(x \le \tfrac12\), then \(\tfrac{1}{2x} \ge 1\), so every \(y \in [0, 1]\) works: a vertical strip of length 1. If \(x > \tfrac12\), the allowed \(y\) fill \([0, \tfrac{1}{2x}]\), of length \(\tfrac{1}{2x} < 1\).Why: compare \(\tfrac{1}{2x}\) with 1.
  3. Area \(= \displaystyle\int_0^{1/2} 1\,dx + \int_{1/2}^{1} \frac{dx}{2x} = \frac12 + \frac12\big[\ln x\big]_{1/2}^{1} = \frac12 + \frac12(0 - \ln\tfrac12) = \frac12 + \frac12\ln 2\).Why: add the strip lengths; \(-\ln\tfrac12 = \ln 2\).
  4. \(P = \) \(\tfrac12 + \tfrac12\ln 2 \approx 0.84657\).Why: probability = area.

Conclusion. \(P(xy \le \tfrac12) = \tfrac12 + \tfrac12\ln2\). ∎

Sum of \(n\) uniforms \(< 1\)

(a) \(n = 2\), (b) \(n = 3\), (c) general \(n\).

Key idea

The region is a simplex of volume \(1/n!\). Slice at \(x_n = t\) and use induction.

Solution

Setup. \(x_1, \dots, x_n\) are independent uniforms on \([0, 1]\), so \(P(\sum x_i < 1)\) is the volume of \(\{x \in [0,1]^n : \sum x_i < 1\}\). For \(0 \le s \le 1\) define \(V_n(s)\) = the volume of \(\{x \in [0,1]^n : \sum x_i < s\}\).

Claim. \(V_n(s) = \dfrac{s^n}{n!}\), so \(P = \dfrac{1}{n!}\).

  1. \(n = 1\): \(V_1(s) = s\), the length of \([0, s)\).Why: one variable.
  2. For \(s \le 1\) the upper bounds \(x_i \le 1\) never bind: if all \(x_i \ge 0\) and \(\sum x_i < s \le 1\), each \(x_i < 1\).Why: each term is at most the sum.
  3. Slice at \(x_n = t\), for \(0 \le t < s\): the other coordinates must satisfy \(\sum_{i<n} x_i < s - t\), a cross-section of volume \(V_{n-1}(s - t)\). So \(V_n(s) = \int_0^s V_{n-1}(s - t)\,dt\).Why: volume = integral of cross-section areas (Cavalieri).
  4. By induction, \(V_n(s) = \displaystyle\int_0^s \frac{(s-t)^{n-1}}{(n-1)!}\,dt = \Big[-\frac{(s-t)^n}{n!}\Big]_0^s = \frac{s^n}{n!}\).Why: assume the formula for \(n - 1\), substitute, and integrate.
  5. \(P = V_n(1) = \tfrac{1}{n!}\): (a) \(\tfrac12\), (b) \(\tfrac16 \approx 0.167\), (c) \(\tfrac{1}{n!}\).Why: \(s = 1\).

Conclusion. The sum of \(n\) uniforms is below 1 with probability \(\tfrac{1}{n!}\). ∎

Crawling ant (max 3 steps)

Each step has an independent uniform time \(t_n\) and distance \(x_n\). The ant stops at the end of the step in which the total time passes 1, or after 3 steps. \(P(\text{final position} > 1)\)?

Key idea

Step 1 never stops the ant (\(t_1 < 1\)). So it stops after 2 steps (\(t_1+t_2 > 1\)) or after 3 steps. Distances and times are independent.

Solution

Setup. Step \(k\) takes time \(t_k\) and covers distance \(x_k\); all the \(t_k, x_k\) are independent uniforms on \([0, 1]\). The ant stops at the end of the step during which the total time passes 1, or after 3 steps, whichever comes first. Its final position is the total distance walked.

  1. The ant never stops after step 1.Why: \(t_1 < 1\) (with probability 1), so the time hasn't passed 1, and it has taken fewer than 3 steps.
  2. It stops after step 2 exactly when \(t_1 + t_2 > 1\); otherwise it stops after step 3.Why: the time rule, and the 3-step cap.
  3. \(P(\text{stops after 2 and ends past 1}) = P(t_1 + t_2 > 1)\cdot P(x_1 + x_2 > 1) = \tfrac12\cdot\tfrac12 = \tfrac14\).Why: times are independent of distances; \(P(\text{sum of 2 uniforms} < 1) = \tfrac12\) (previous problem), so \(P(> 1) = \tfrac12\).
  4. \(P(\text{stops after 3 and ends past 1}) = P(t_1 + t_2 \le 1)\cdot P(x_1 + x_2 + x_3 > 1) = \tfrac12\cdot\big(1 - \tfrac16\big) = \tfrac{5}{12}\).Why: same independence; \(P(\text{sum of 3 uniforms} < 1) = \tfrac16\).
  5. The two cases are disjoint, so \(P = \tfrac14 + \tfrac{5}{12} = \tfrac{3}{12} + \tfrac{5}{12} = \) \(\tfrac23 \approx 0.667\).Why: the ant stops after exactly one of 2 or 3 steps (steps 1–2).

Conclusion. The ant ends past 1 with probability \(\tfrac23\) (simulated). ∎

\(a_1 < a_2 < a_3\) with \(a_k \sim U[0,k]\)

Key idea

Volume of the ordered region inside a \(1\times2\times3\) box.

Solution

Setup. \(a_k\) is uniform on \([0, k]\), independently, so \((a_1, a_2, a_3)\) is uniform on the box \([0,1]\times[0,2]\times[0,3]\) of volume 6. \(P\) = (volume of the ordered part) / 6.

  1. For fixed \(a_1 < a_2\), the allowed \(a_3\) lie in \((a_2, 3]\), of length \(3 - a_2\). So the volume is \(\displaystyle\int_0^1\!\!\int_{a_1}^{2}(3 - a_2)\,da_2\,da_1\).Why: integrate the allowed length over \(a_2\) from \(a_1\) up to 2, then over \(a_1\).
  2. Inner integral: \(\big[3a_2 - \tfrac{a_2^2}{2}\big]_{a_1}^{2} = (6 - 2) - \big(3a_1 - \tfrac{a_1^2}{2}\big) = 4 - 3a_1 + \tfrac{a_1^2}{2}\).Why: antiderivative of \(3 - a_2\).
  3. Outer integral: \(\int_0^1 \big(4 - 3a_1 + \tfrac{a_1^2}{2}\big)da_1 = 4 - \tfrac32 + \tfrac16 = \tfrac{24 - 9 + 1}{6} = \tfrac83\).Why: integrate term by term.
  4. \(P = \dfrac{8/3}{6} = \) \(\tfrac49 \approx 0.444\).Why: divide by the box volume.

Conclusion. The three are in increasing order with probability \(\tfrac49\). ∎

12 · Recursion in probability

  1. rec(s) = P(win | the process is in state \(s\) now), from now till it stops. Condition on the next step (total probability): \[\text{rec}(s) = \sum_t P(s\to t)\,\text{rec}(t).\] Stopping states are the base cases: 1 = win, 0 = lose.
  2. State = the smallest description that decides the future. Merge states that are symmetric.
  3. If a step can lead back to \(s\) (a restart), \(\text{rec}(s)\) sits on both sides. That is an equation: solve it, don't recurse.

First to roll a 6

Two players alternate. \(P(\text{the first player wins})\)?

Key idea

Roll: a 6 wins now; anything else makes the opponent the roller, and the problem restarts with roles swapped.

Solution

Setup. Two players alternate rolling a die; the first to roll a 6 wins.

  1. Level: rec = P(the player about to roll wins). Every turn looks the same.Why: the game has no memory; only who is rolling matters.
  2. Choice: the roll is a 6 (\(\tfrac16\)) or not (\(\tfrac56\)).Why: a fair die.
  3. Check: a 6 ends the game, and the roller wins: value 1.Why: the rules.
  4. Move: after a non-6, the opponent becomes the roller in an identical game and wins with probability rec, so the original roller wins with \(1 - \text{rec}\). Therefore \(\text{rec} = \tfrac16\cdot1 + \tfrac56(1 - \text{rec})\).Why: total probability over the roll.
  5. \(\text{rec} = \tfrac16 + \tfrac56 - \tfrac56\text{rec} = 1 - \tfrac56\text{rec}\), so \(\tfrac{11}{6}\text{rec} = 1\) and rec = \(\tfrac{6}{11} \approx 0.54545\).Why: collect the rec terms on one side.

Conclusion. The first player wins with probability \(\tfrac{6}{11}\). ∎

Strictly first to heads

(a) You vs 9 friends. (b) Alice before Bob. (c) Alice \(<\) Bob \(<\) Charlie (first-heads times).

Key idea

One round = everyone tosses. All tails restarts the problem. Any tie or wrong leader contributes 0.

Solution

Setup. In each round every player tosses a fair coin at the same time. A player's 'time' is the round of their first head. (a) You vs 9 friends: you must be strictly first. (b) Alice strictly before Bob. (c) Alice strictly before Bob strictly before Charlie.

  1. Level: rec = P(event | nobody has a head yet). Choice: which players get H this round. Check: all tails means the same situation again; any other outcome decides the event (or, in (c), hands over to a smaller problem).Why: rounds are independent, so an all-tails round leaves the future exactly as before.
  2. (a) Only you H (probability \(2^{-10}\)) wins; all tails (\(2^{-10}\)) repeats; anything else loses (a friend got a head at the same time or earlier). \(\text{rec} = 2^{-10} + 2^{-10}\text{rec}\), so \(\text{rec}(1 - 2^{-10}) = 2^{-10}\) and rec = \(\tfrac{1}{1023}\).Why: multiply top and bottom by \(2^{10}\).
  3. (b) A: H, B: T (\(\tfrac14\)) wins; TT (\(\tfrac14\)) repeats; TH or HH loses (Bob first, or a tie). \(\text{rec} = \tfrac14 + \tfrac14\text{rec}\), so \(\tfrac34\text{rec} = \tfrac14\) and rec = \(\tfrac13\).Why: collect terms.
  4. (c) Only Alice H (\(\tfrac18\)): Alice is now strictly first, and we still need Bob strictly before Charlie. From here that is exactly problem (b): \(\tfrac13\). All tails (\(\tfrac18\)) repeats. Anything else fails (Bob or Charlie got a head no later than Alice). \(\text{rec} = \tfrac18\cdot\tfrac13 + \tfrac18\text{rec}\).Why: future rounds are independent of the past.
  5. \(\tfrac78\text{rec} = \tfrac{1}{24}\), so rec = \(\tfrac{1}{21} \approx 0.04762\).Why: multiply both sides by \(\tfrac87\).

Conclusion. \(\tfrac{1}{1023}\), \(\tfrac13\) and \(\tfrac{1}{21}\). ∎

HH ends on an even toss

Key idea

T: restart with parity flipped. HT: restart with parity unchanged. HH: done on toss 2.

Solution

Setup. A fair coin is tossed until the first HH. \(N\) = the toss number at which it happens. rec = \(P(N \text{ is even})\).

  1. The game opens with T (probability \(\tfrac12\)), HT (\(\tfrac14\)) or HH (\(\tfrac14\)). These three cases are disjoint and cover everything.Why: the first toss is T; or it is H and the second is T or H.
  2. HH: \(N = 2\), which is even. Contribution \(\tfrac14\cdot1\).Why: the game ends at toss 2.
  3. T: one toss is used and the game restarts from scratch. If the rest takes \(M\) more tosses, \(M\) has the same distribution as \(N\), and \(N = 1 + M\) is even exactly when \(M\) is odd. Contribution \(\tfrac12(1 - \text{rec})\).Why: a T can't be part of a future HH, so nothing carries over.
  4. HT: two tosses are used and the game restarts. \(N = 2 + M\) is even exactly when \(M\) is even. Contribution \(\tfrac14\text{rec}\).Why: the T again resets everything.
  5. \(\text{rec} = \tfrac12(1 - \text{rec}) + \tfrac14\text{rec} + \tfrac14 = \tfrac34 - \tfrac14\text{rec}\), so \(\tfrac54\text{rec} = \tfrac34\) and rec = \(\tfrac35\).Why: total probability over the three openings; collect terms. (Simulated: 0.600.)

Conclusion. The first HH ends on an even toss with probability \(\tfrac35\). ∎

Parcel around 5 seats

The holder passes left, passes right, or keeps (\(\tfrac13\) each). Keeping ends the game. You start with it. \(P(\text{you keep it})\)?

Key idea

Only the distance from you matters: 0, 1 or 2.

Solution

Setup. 5 seats in a circle. Each turn the holder keeps the parcel, passes it left, or passes it right, each with probability \(\tfrac13\); keeping ends the game. You start holding it. Measure the holder's distance from you around the circle: the seats are at distances 0 (you), 1, 2, 2, 1.

  1. Level: rec\((d)\) = P(you end up keeping it | holder at distance \(d\)). Choice: keep, pass left, pass right. Check: keep ends the game, with value 1 if \(d = 0\) and 0 otherwise.Why: only the distance matters, by symmetry.
  2. From \(d = 0\): keep (you win) or pass to distance 1 (either direction): \(\text{rec}(0) = \tfrac13 + \tfrac23\text{rec}(1)\).Why: both of your neighbours are at distance 1.
  3. From \(d = 1\): keep (someone else wins: 0), pass toward you (distance 0), pass away (distance 2): \(\text{rec}(1) = \tfrac13\text{rec}(0) + \tfrac13\text{rec}(2)\).Why: read off the circle.
  4. From \(d = 2\): keep (0), pass toward you (distance 1), pass to the other distance-2 seat: \(\text{rec}(2) = \tfrac13\text{rec}(1) + \tfrac13\text{rec}(2)\).Why: the two distance-2 seats are next to each other.
  5. Step 4: \(\tfrac23\text{rec}(2) = \tfrac13\text{rec}(1)\), so \(\text{rec}(2) = \tfrac12\text{rec}(1)\). Step 3: \(\text{rec}(1) = \tfrac13\text{rec}(0) + \tfrac16\text{rec}(1)\), so \(\tfrac56\text{rec}(1) = \tfrac13\text{rec}(0)\) and \(\text{rec}(1) = \tfrac25\text{rec}(0)\).Why: solve from the far side inwards.

13 · Symmetry I: ad hoc

  1. If the process treats labels interchangeably, every label (pair, ordering, …) has the same probability. If exactly one of \(k\) such cases happens, each has probability \(1/k\).
  2. For i.i.d. continuous variables, ties have probability 0, and all \(n!\) orderings are equally likely.

  4. (b) \(P = 99\cdot\tfrac{1}{4950} = \) \(\tfrac{1}{50} = 0.02\).Why: add the probabilities of the disjoint events (steps 2 and 3).

19 · PDF and CDF (continuous)

  1. \(X\) has density \(f \ge 0\) if \(P(a \le X \le b) = \int_a^b f\) for all \(a \le b\). Then \(\int f = 1\), \(P(X = x) = 0\) for every \(x\), and \(f\) can be larger than 1.
  2. \(F(x) = \int_{-\infty}^{x} f\), and \(F' = f\) wherever \(f\) is continuous.
  3. To find a density, find the CDF first, then differentiate. This is usually easier than the "\(f(x)\,dx = P(x \le X \le x+dx)\)" method.

Rain and humidity

Nested points in the disc

\(R_1 \sim U[0,1]\). The second point is uniform in the annulus \(r_1 < r \le 1\). \(P(R_2 > \tfrac12)\)?

Key idea

Given \(r_1\), \(P(R_2 > \tfrac12)\) is an area ratio. Integrate it over \(r_1\).

Solution

Setup. The first point's distance from the centre is \(R_1 \sim U[0, 1]\). Given \(R_1 = r_1\), the second point is uniform (by area) in the annulus \(r_1 < r \le 1\). We want \(P(R_2 > \tfrac12)\).

  1. If \(r_1 \ge \tfrac12\): every point of the annulus is at distance \(> r_1 \ge \tfrac12\), so \(P(R_2 > \tfrac12 \mid r_1) = 1\).Why: the annulus starts beyond \(\tfrac12\).
  2. If \(r_1 < \tfrac12\): the favourable part is the ring from \(\tfrac12\) to 1, of area \(\pi(1 - \tfrac14)\), out of the annulus area \(\pi(1 - r_1^2)\). So \(P(R_2 > \tfrac12 \mid r_1) = \dfrac{3/4}{1 - r_1^2}\).Why: uniform by area.
  3. \(P = \displaystyle\int_0^{1/2}\frac{3/4}{1 - r^2}\,dr + \int_{1/2}^{1}1\,dr\).Why: continuous total probability over \(R_1\), whose density is 1 on \([0,1]\).
  4. \(\displaystyle\int_0^{1/2}\frac{dr}{1 - r^2} = \frac12\ln\frac{1 + r}{1 - r}\Big|_0^{1/2} = \frac12\ln 3\).Why: partial fractions: \(\tfrac{1}{1-r^2} = \tfrac12\big(\tfrac{1}{1-r} + \tfrac{1}{1+r}\big)\); at \(r = \tfrac12\), \(\tfrac{1.5}{0.5} = 3\).
  5. \(P = \tfrac34\cdot\tfrac12\ln3 + \tfrac12 = \dfrac{4 + 3\ln 3}{8} \approx\) \(0.91198\).Why: substitute step 4 into step 3.

Conclusion. \(P(R_2 > \tfrac12) = \tfrac{4 + 3\ln3}{8}\). ∎

Three points, pairwise \(\ge 90^\circ\) apart

Key idea

Fix the first point at 0. The second point is at \(90^\circ + x\) (doubled by symmetry). The third point's allowed arc has length \(90^\circ - x\).

Solution

Setup. Three independent uniform points on a circle, with angles measured in degrees (0 to 360). We want every pair to be at least \(90^\circ\) apart (measured the short way round).

  1. Rotate so that \(P_1 = 0^\circ\).Why: rotation doesn't change the problem, and \(P_2, P_3\) stay independent and uniform.
  2. \(P_2\) must lie in \([90^\circ, 270^\circ]\).   3. Given \(P_2 = 90^\circ + x\): \(P_3\) must be \(\ge 90^\circ\) from \(0^\circ\), i.e. in \([90^\circ, 270^\circ]\), and \(\ge 90^\circ\) from \(P_2\), i.e. outside \((x, 180^\circ + x)\).   4. \(P = 2\displaystyle\int_0^{90}\frac{1}{360}\cdot\frac{90 - x}{360}\,dx = \frac{2\cdot4050}{360^2} = \frac{8100}{129600} = \frac{1}{16}\).Why: \(P_2\) has density \(\tfrac{1}{360}\) per degree; given \(P_2\), \(P_3\) succeeds with probability \(\tfrac{90 - x}{360}\); \(\int_0^{90}(90 - x)\,dx = \tfrac{90^2}{2} = 4050\).

Ferris wait

Key idea

Boarding is possible for \(\tfrac13\) of each cycle. The wait is 0 inside that window, and otherwise the time to the window's next start.

Solution

Setup. A Ferris wheel of radius 1 m has its centre 1 m above the ground and turns once per minute. At time \(t\) the boarding car is at height \(h(t) = 1 + \cos 2\pi t\). You can board when \(h \le 0.5\). You arrive at a uniform random time.

  1. \(h \le \tfrac12 \iff \cos 2\pi t \le -\tfrac12 \iff 2\pi t \in [\tfrac{2\pi}{3}, \tfrac{4\pi}{3}] \iff t \in [\tfrac13, \tfrac23]\) (mod 1).Why: cosine is at most \(-\tfrac12\) exactly between \(120^\circ\) and \(240^\circ\).
  2. So each minute has a boarding window of length \(\tfrac13\), and an unavailable stretch of length \(L = \tfrac23\) (from \(\tfrac23\) to \(\tfrac43\)).Why: \(1 - \tfrac13 = \tfrac23\).

If you arrive in the stretch (probability \(\tfrac23\)), the wait is the time left until the stretch ends, which is uniform on \([0, L]\), with mean \(\tfrac{L}{2} = \tfrac13\).Why: a uniform arrival inside an interval of length \(L\) leaves a uniform remaining time.
  4. \(\mathbb{E}[W] = \tfrac13\cdot0 + \tfrac23\cdot\tfrac13 = \) \(\tfrac29 \approx 0.22222\) min.Why: law of total expectation. The sawtooth figure shows the same thing as an area.

Conclusion. The expected wait is \(\tfrac29\) of a minute. ∎

26 · Tail sum (discrete)

For \(X \in \{0,1,2,\dots\}\): \[\mathbb{E}[X] = \sum_{k\ge1} P(X \ge k).\] Proof: \(X = \sum_{k\ge1} \mathbb{1}[X \ge k]\); take expectations. Use it when "\(\ge k\)" is easy (minima: all \(\ge k\)).

Min of three d100

Key idea

\(\min \ge k \iff\) all three \(\ge k\).

Solution

Setup. \(X\) = the smallest of three independent rolls of a 100-sided die (faces 1–100).

  1. \(X \ge k\) exactly when all three rolls are \(\ge k\), so \(P(X \ge k) = \big(\tfrac{101 - k}{100}\big)^3\).Why: a roll is \(\ge k\) for the \(101 - k\) faces \(k, \dots, 100\); independence.
  2. \(\mathbb{E}[X] = \sum_{k=1}^{100} P(X \ge k) = \sum_{j=1}^{100}\dfrac{j^3}{100^3}\).Why: tail sum; substitute \(j = 101 - k\).
  3. \(\sum_{j=1}^{100} j^3 = \big(\sum j\big)^2 = 5050^2 = 25\,502\,500\), so \(\mathbb{E}[X] = \tfrac{25\,502\,500}{1\,000\,000} = \) \(25.5025\).Why: the sum of the first \(n\) cubes is the square of the sum of the first \(n\) integers.

Conclusion. The expected minimum is 25.5025. ∎

Distance to the base of a triangle

Solution

32 · Recursion in expectation

rec(s) = expected cost from state \(s\) till the process stops. Condition on the next step (total expectation): \[\text{rec}(s) = \sum_t P(s\to t)\,\big(\text{cost}(s\to t) + \text{rec}(t)\big),\qquad \text{rec} = 0 \text{ at the end}.\] A restart puts rec on both sides: \(\text{rec} = c + q\,\text{rec} \Rightarrow \text{rec} = \dfrac{c}{1-q}\).
